## 实质性取舍

1. 保留Python + React/TypeScript、本地模块化单体、一个数据写入者。
2. 放弃一期外部Parquet主存储；采用单一DuckDB事务，减少跨文件数据发布和恢复复杂度。Parquet保留为导出/后续容量迁移路径。
3. 首批跨日量能在股份单位变化后重新预热；自动股份因子校正后置到独立研究，不凭指标更连续就采纳。
4. 假设历史可得的数据允许条件探索，始终不能升级成经证实PIT。
5. 不把付费/身份未知/覆盖不足的源放入免费默认依赖。先资格验证，再决定是否接入；无合格源的功能继续记为未完成。
