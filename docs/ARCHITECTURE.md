## 1. 一套本地内核

- **平台**：通用导入、DuckDB/Parquet、研究计算、HTTP 和 Web 使用同一套 Linux/Windows 代码。通达信客户端调用、Windows原生进程和任务控制保留在专用适配器中，不把 SDK 的平台、位宽或 Python 限制扩散到研究内核。
- **结构**：本地模块化单体，Python **3.14** 后端、React/TypeScript 界面，依赖按现有 lock 文件安装。浏览器只负责交互和图形，统计真值由后端计算。
- **存储**：原字节按内容哈希保存；单一 DuckDB 保存批次、版本、查询和作业关系；Parquet 用于导出。只有主应用拥有数据库写入权。
- **计算**：原价格/金额保留 Decimal；新模型估计在明确边界用 float64，带单位、方法身份和失败原因。性能优化先测量，保留简单参考实现。
- **范围**：不新增微服务、消息平台、指标插件框架、第二套数据库、持久特征缓存或自动清理。国际市场按数据与规则扩展，通用数学不硬编码 A 股交易制度。

早期 Windows 优先的整应用限制已被本轮跨平台决定替代；历史存储简化、单写入者、精度和时间约定继续保留。原始[架构稿](https://github.com/BorongGu/Anatrading/blob/efbf14e76d4bc61bc903a0b82139fa93cd98e485/docs/ARCHITECTURE.md)与[取舍记录](REVIEW_DECISIONS.md)可追溯。

## 3. 原始数据与版本

- 原文件/响应保存原字节、SHA-256、来源/格式版本、实际取得时间和非敏感参数。同内容去重，不原位改写；来源修订生成新批次和版本，旧研究仍指向原输入。
- 格式约定逐项说明字段、数值类型、源单位、时间标签、复权、覆盖、缺失和版本适用范围。用户声明与已核验语义分开；无依据不生成规范字段。
- 股票身份需要证券、市场及有效日期，不能把六位代码当作跨市场永久身份。价格、数量、金额、指数点数及统计对象分别定义。同一证券多个版本不计为多只股票。
- 观察保留来源序号、原 token、原位置、质量原因和重复记录。无法定位日期的行单列，仍进入完整覆盖限制；不会悄悄删掉后称历史干净。
- `research_series.py` 传递已有来源检查：证券身份或复权声明明确冲突的日期组不可参与研究；已隔离/已知负例来源保持失格。原价格和日期槽保留，状态与窗口按坏组规则中断；无关量额缺失不会使有效价格自动失格。
- 已引用数据版本不可变；方法、Schema、规范化、质量、数值上下文和输入选择进入身份。新规则不能重新解释旧对象，迁移须产生新版本并保留旧读取路径。

完整历史分层实体仍保留：原件 `RawObject`、来源定义 `SourceContract`、观察 `Observation`、参考事件 `ReferenceEvent`、数据版本 `DatasetSnapshot`、派生事件 `FeatureEvent`、实验 `ResearchRun`。后几层的完整主数据/时点评价是后续设计，不代表当前 Store 已支持。历史实体细节见原稿及[首批格式约定](contracts/INITIAL_DATA_CONTRACT.md)。

[039](research/039-tencent-action-candidates.md)的 `extract_tencent_action_candidates(raw: bytes)` 只接受现有腾讯日线capture，复用 `validate_capture` 的身份、hash、请求、行形状及640行边界。源行索引6的非空对象必须恰有 `nd/fh_sh/djr/cqr/FHcontent` 五个字符串，原样保留并绑定ordinal、source_date和body定位；空对象另计数，未知形状整份拒绝，不输出部分候选。来源回显身份及strict/legacy运输限制继续传递，不因哈希语法合格而补造运输认证。

候选沿原顺序保留完整上下文，不trim、转数值、按年合并或认定行动日期；固定经济语义未验、覆盖未知、historical_known_at为空。限定实现与来源兼容验收通过；469个源行对象/目标窗343个只属候选观察。模块不读写文件、联网或打开Store，不改旧capture/解码/查询/导出，也不生成复权、现金收益或总收益。后续公告核对需另定有界来源合同；[037研究](research/037-financial-signal-literature-map.md)已完成，[038固定风险核](plans/2026-10-11-source-risk-amplitude.md)暂缓，不创建相关接口或计算框架。

## 4. 精度、单位与空值

1. 原价格/金额采用 Decimal或显式定点；整数股转换须先核实源单位。保留原始 binary32/64 的精确位值及其来源量化；转成 Decimal 不会恢复供应商已损失的信息。
2. 数据库、Arrow/Parquet、API和导出按同一精度/scale约定往返。超精度或溢出明确拒绝/隔离，不静默舍入；源误差与系统新增误差分开。原始精确值通过API字符串传递，画布才转浮点。
3. DuckDB DECIMAL除法会进入近似浮点；精确金额/量参考计算留在Decimal层。[数值说明](https://duckdb.org/docs/current/sql/data_types/numeric)与[Arrow Decimal](https://arrow.apache.org/docs/python/generated/pyarrow.decimal128.html)作为类型依据。
4. 新统计估计注明 `estimate_float64`，拒绝非有限、不可表示和正价下溢。估计结果不反写源价格/金额；突破条件仍用Decimal比较。
5. 零、缺失、非交易/停牌、部分柱、源补值、错误和无法定义分别表达。空结果带原因；零量均价、零分母相对量不可定义，不填零。缺失不能靠插值或删行凑满窗口。
6. 量额分别标明 `interval/cumulative_day/cumulative_session/trade/indicative`。累计量先核锚点、重置和缺口再差分；负差、缺首条和未知重置不给伪增量，虚拟匹配量不当作已成交。
7. 币种、股/手、元/万元、比例与百分比在结果中明示。金额一致性阈值随源精度与成交覆盖变化，不能统一用一分钱；指数不套股票倍率和无定义的VWAP。

[040](research/040-data-gap-next-step.md)的 `conditional_return_report` 接收不可变的价格、标准事件与输入声明；最多20,000价格、19,999事件，日期有序、事件日有收盘、每日一个明确合并的普通事件。方法明确分为不主动买卖且现金不再投、除息收盘碎股再投；股份及后续权益基数分别递推，不共用。前者按事件冻结应收、到期逐笔转到账，后者允许提前使用应收、支付日不再计值。无报价支付日只在下一观察反映分类，不制造价格或收益；未知/复杂事件整次拒算。

价格/金额输入沿既有精确Decimal范围；运算使用独立50位HALF_EVEN，不受全局context影响。现金/应收加减无法保留冻结金额之和时报告 `arithmetic_resolution`，其余比率与估值允许明示精度舍入，不宣称精确有理数。支付先按日排序，再与价格/事件单次合并，总O(T+E log E)、空间O(T+E)，尚无性能资格。合成验收与独立终审通过；声明始终未认证，无文件/网络/数据库操作、原价覆盖或默认服务接入。039候选不会自动转成标准事件，0/15真实原价缺口与旧first30差异仍保留，见[验收](qualification/conditional-return-core.md)。

## 5. 时间与可得性

来源日期、柱开始/结束、事件生效 `effective_at`、源公布/可得 `published_at/available_at`、实际取得 `observed_at`、研究截止 `known_at` 和结构确认 `confirmed_at` 各有用途。收盘标签不证明当时已取得最终收盘值；实际取得时间不能倒填首次公布时间。

当前新增研究只返回 `mode=retrospective`。它按提供的历史版本描述，保留复权、日历、闭合与历史可得性未知的限制。未来严格时点研究需逐次决策同时限制价格版本、主数据、证券池、训练数据和特征确认；不能用实验结束日统一授权过去的信息。

- 信号只能使用当前和过去输入；追加或改写未来行不能改变过去信号。需要右侧柱确认的拐点，确认时间晚于发生时间，不能倒填为当时信号。
- 后续标签在成熟后可更新，信号截止与评价截止分开。固定评价截止的结果必须稳定；跨测试起点的训练标签剔除。
- 有证据的历史时点与带假设的时点研究分开。混合输入继承较弱资格，假设随派生链传播，不因经过模型而升级。
- 当前成员历史回顾只称所选样本。历史动态选股需每个日期的成员/选择规则、入选与排除、退市和分钟缺失；缺数据的入选股票仍留在覆盖分母。

## 6. 本轮算法约定

公式、固定参数、数值阈值、原文阅读范围和专用测试以[026](research/026-causal-signals-and-evaluation.md)为准，竞争任务依据[027](research/027-competitor-workflows.md)。以下是边界摘要：

- **单股**：日线log(close)单侧局部线性Kalman，固定公开参数与Joseph更新；首根只初始化，20根预热；EMA作同尺度基线。EWMA使用原始log收益，冲击使用当期纳入前方差。不平滑未来、不全样本估参、不自动年化。
- **事件**：当前close严格高于此前N组high最大值；完整正OHLC校验不依赖量额。后续h来源记录步的简单价格变化，坏路径/未成熟分别计数；按时间贪心去重。Type-7分位与同资格日期基线，不输出独立样本置信度或成交收益。
- **双股**：先核对不同证券且同一市场，再找共同日期，计算相同起止区间收益；坏组保留为中断。收益相关/beta可含当前区间，价格回归仅用此前窗口；左右角色固定并回显。回归beta是log价格弹性，不能称固定对冲股数；退化残差不会抹掉仍可计算的相关或beta。
- **集合**：首版同一市场，沪/深/京归为CN_A，拒绝与US/HK混用；同一截止必须存在当日价。N+1来源日期组计算N步动量、ddof=1的log收益波动和非正最大回撤。每项真实起点/分母分别报告，按精确动量降序并列名次、稳定身份次序；广度为正动量数/有效动量数。
- **恢复**：坏价/重复日期中断状态，下一有效值显式重启。日历未知时不按自然日间隔自行补柱/重置。源记录步不承诺交易日等距；国际/跨市场关系另需同步约定。

统计相关、价格偏离、平滑和暖机结束不提供预测概率、协整、均值回归或套利资格。分钟Kalman、自动调参、PCA、组合优化和交易PnL留待后续独立研究。

## 8. 写入、进程锁与恢复

- 数据目录仅一个应用进程持有独占锁：Windows保留`msvcrt`，POSIX使用非阻塞`flock`；加锁/初始化失败关闭句柄，POSIX锁文件不删除。只承诺实测本地文件系统，不承诺跨OS网络共享互斥。
- 采集/解码子进程不直接写数据库。原件在同卷暂存并核哈希，唯一写者在同一事务提交批次、引用、版本、幂等结果、覆盖与作业状态。取消在提交前生效，进入提交后报告实际结果。
- 请求幂等身份含来源和请求语义，内容哈希区分源修订。同内容不重复发布；未知刷新/发布保留原作业核对，不靠重启/换数据根发新请求。
- 覆盖按证券/周期/分片记录，只有成功提交才推进。部分失败不能被其它证券最大日期掩盖；回查修订窗口按已测来源规则确定，旧区间未检查范围明确显示。
- 已引用原件缺失/损坏阻止相关版本读取；未引用临时文件不能自动晋级。磁盘满、提交前后崩溃、文件锁、坏对象、WAL和恢复分别测试；原子重命名不等于硬件断电保证。
- 采用离线一致备份：停止新写入、完成/取消在途作业、正常关闭数据库后复制DB与所有引用原件/清单，恢复到新空目录并核对。不完整恢复拒绝打开；崩溃状态不得丢弃WAL。[DuckDB并发](https://duckdb.org/docs/current/connect/concurrency)、[WAL](https://duckdb.org/docs/current/operations_manual/footprint_of_duckdb/files_created_by_duckdb)、[CHECKPOINT](https://duckdb.org/docs/current/sql/statements/checkpoint)
- Authorization、Cookie、登录响应、密钥和短期签名URL不进入原件、清单或日志。客户端适配仅使用明确行情方法，不开放任意方法或账户/交易入口。

### 显式数据库只读

`EvidenceStore(root, checkpoint=None, *, read_only=False)` 保留旧默认路径；`read_only=True` 要求现存根目录与数据库，在原排他锁内检查恢复标记，以DuckDB只读连接打开并用SELECT核对schema版本及六表必要列/类型。容许额外表列，不执行初始化、迁移、attempt恢复或checkpoint；落盘 `running` 原样可读。缺库、结构不兼容或连接失败受控拒绝，释放连接与锁，不改用读写连接修复。允许引擎在内存加载已提交WAL，只有已验证的合成实例取得DB/WAL哈希、长度、mtime与存在性不变证据。

`import_bytes`、`import_file`、共同导入入口与 `backup` 在读取输入、创建目标或重连前报 `read_only_store`。CLI仅 `snapshots`、`attempts`、`query`、`export`、`candle-geometry` 接受 `--read-only`；HTTP和workbench仍沿旧构造。正常导出继续写文件，新只读模式将目标与六个保留路径经 `resolve(strict=False)` 比较，拒绝其本身、子路径与符号链接别名：`research.duckdb`、其 `.wal`/`.wal.checkpoint`/`.wal.recovery`、`.operation.lock`、`.restore-incomplete`，错误为 `export_destination_reserved`；旧默认导出规则不扩展。

锁文件仍可能新建，Windows既有锁分支可能补字节；不承诺整个目录只读、并发读实例或跨OS共享。仅合成库测试，不读取真实库或归因旧first30差异；Windows原生、损坏/截断WAL与中断checkpoint未验。见[计划](plans/2026-10-11-read-only-store.md)。
