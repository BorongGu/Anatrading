# 股票研究路线

更新：2026-10-11。当前以[本轮方案](plans/2026-10-11-research-workflows.md)和[最终编码前复核](reviews/2026-10-11-research-workflows-review.md)为准。首版日线算法、研究 HTTP、界面和 Linux 通用修复之后，第二批内部紧凑读取与分钟 A 纯函数已通过冻结版本自动化回归和限定复核。合成性能复验支持保留紧凑读取。第三批腾讯/新浪有界采集、恢复和格式已实现并通过本地回归及独立复核；40 份旧真实捕获离线入库通过，新命令的真实网络仍阻断。第四批同伴 A 纯函数和可解释筛选只读 API 已通过独立实现复核与后端联合回归，筛选 UI 已接入并通过模型/静态组件、构建及独立实现复核。第五批集合逐源准备通过功能/来源等价与最终回归，正式对照证实相对旧版本的内存/时延改善；+16 MiB筛选增量仍4/18未达，按后验工程决定分阶段保留，原整体条件未通过。浏览器、交互性能及完整来源语义仍待验。

## 要解决的问题

用单股日线、单股分钟、双股日线、多股与明确成员的板块数据，帮助用户完成“判断当前状态 → 找到可确认条件 → 检查历史结果 → 看到反例和风险边界”。A 股优先，国际股票随后按市场补齐数据、日历、币种和交易规则。算法与可验证功能优先，基础设施只解决实际瓶颈。

一套内核支持 Linux/Windows；Windows 通达信适配器独立。仓库为私有，真实行情和个人运行数据留在本地。

## 已实现的首版三条流程

| 流程 | 本轮交付 | 验收条件 |
|---|---|---|
| 个股研究 | 固定参数日线 Kalman 与 EMA 对照、原始收益 EWMA 波动、此前窗口高点突破、成熟后续变化与全日期基线 | 独立手算和参考实现、逐前缀一致、重复/坏价中断、未成熟与跨切点标签计数；未指定测试起点时只作全段描述 |
| 双股对比 | 共同日期区间收益相关/beta、相对强弱、仅用此前窗口拟合的当前价格偏离 | 两侧同起止区间、不填缺日、不跨坏组；左右角色与输入身份正确，退化统计逐项说明 |
| 多股与板块样本 | 同一截止的动量、波动、最大回撤及分项排序，正动量广度 | 不同证券、不回退至各自末日、并列排名可复算；每项有效分母与全部所选数量并列 |

边界：这三条已接入 API/界面的研究流程仅日线；新增分钟 A 仍是独立纯函数。每系列最多 20,000 源行、总请求最多 200,000 行、集合 2–50 个不同证券版本。双股和集合首版仅允许同一市场，沪/深/京属于同一 A 股市场；跨市场同步解释仍待研究。这是请求上限，尚不代表性能达标。具体公式、数值阈值和失败原因见[026](research/026-causal-signals-and-evaluation.md)。

界面先显示结果与图，将原始记录、版本标识和长计算说明折叠。自然中文、清晰字体、窄屏与键盘操作都属于验收；旧请求不能覆盖新选择。

## 第二批已实现的有限扩展

- **内部紧凑读取**：研究只物化所需字段，保留逐请求原件校验、全部 tokens/checks、NULL/未定位行、来源资格、精确 OHLC 和研究身份；公开 query 与 JSON/Parquet 导出不变。见[方案](plans/2026-10-11-compact-research-reads.md)及[独立复验](reviews/2026-10-11-compact-research-reads-review.md)。
- **分钟 A**：固定来源模板和截止下的 1/5 名义分钟同覆盖收益平方和与采样敏感性，仅单日期纯函数；无 HTTP/UI、跨段合计、实时/闭合认证。B 同槽量与 C 日线联动仍为研究候选。见[028](research/028-intraday-research-candidates.md)及[独立复核](reviews/2026-10-11-intraday-candidate-review.md)。

## 第三批：有界取数与真实离线导入

[腾讯日线/新浪分钟接入](plans/2026-10-11-automatic-market-data.md)已实现固定来源请求、捕获格式、持久发送预算、恢复与 CLI。仅显式声明为股票的沪深证券，腾讯日线、新浪 1m/5m 最近窗口；无持续调度、全市场发现或完整历史分钟保证。Windows 当前缺少新采集所需目录安全/同步能力，会在联网前拒绝。

40 份旧捕获以显式 legacy 版本完成首次导入、重复复用与重开逐 token 核对：38,900 原始行完整保留，目标视图为 34,205 行，较早上下文未删除。旧记录未建立新运输保证，数量/金额单位与历史可得性继续未知。新产品首次腾讯日线请求为 `failed_transient/transport_network_error`，0 响应、0 捕获、0 数据版本；计数保留为 1，新浪未发、未重试。没有依据断定限流或具体网络原因。见[来源验收](qualification/public-market-formats.md)、[新命令真实验收](qualification/public-acquisition.md)和[独立复核](reviews/2026-10-11-automatic-market-data-review.md)。

## 第四批：同伴对照与可解释筛选

- **同区间同伴价格对照 A**：[030](research/030-peer-relative-research.md)与[实现验收](qualification/peer-relative-research.md)已完成限定验证。4–50 个固定成员、一个目标和明确起止日，剔除目标后用同伴中位数/等权均值作对照，精确有理数保留；端点缺失不回退或删股重算。目前只有纯函数，无 API/UI。
- **可解释筛选**：[032](research/032-explainable-stock-filters.md)与[独立实现复核](reviews/2026-10-11-explainable-filters-review.md)已接通纯函数及 `GET /api/research/universe-filter`。对已有动量、波动和回撤最多两组条件，组内 AND、组间 OR；保留每个成员和全部条件，结果分入选/排除/待核查，共用一次事实计算和读取。
- **界面与效果**：032 已接入既有多股页面，有限条件、同次基线、三态证据和陈旧请求隔离完成前端模型/静态组件及[独立复核](reviews/2026-10-11-research-ui-review.md)；[界面验收](qualification/research-filter-ui.md)保留真实点击、焦点、窄屏和截图未验。同行业身份、历史行业成分、预测/交易增量与用户研究效率不因测试获得认证。

## 第五批：集合逐源准备

[033](research/033-research-memory-cost.md)的候选B仅改变两条集合HTTP入口的对象生命周期：全部预算后逐源完整读取、完整前缀归一化，跨来源只留header、完整覆盖、末N+1实际窗口及安全错误对。原件校验、源值、公开查询/导出、指标/身份和原失败顺序保持；不裁剪历史、不改Store/SQL，不影响单股/双股或UI。

[完整资源验收](qualification/research-memory.md)包含六配置、120计时+24预热+72独立RSS进程：旧/新36个峰值配对全降，名义20万行配置24对减少68.21%–83.90%，全部12个中位更快，60个旧/新时延对通过。筛选相对集合的+16 MiB门槛18对中4对未达，全部失败保留。根据[独立审查](reviews/2026-10-11-research-memory-review.md)及最终工程决定分阶段保留B；这是后验取舍，原预注册整体保留条件未通过，不改写为全面资源通过。

## 当前验证结果

- Linux Python 全套 2,301 通过、0 失败、49 跳过、1 项 Starlette/httpx 弃用警告（90.33 s）。跳过项为 48 项私有真实样本和 1 项 Windows 原生进程证据。
- 第五批最终运行前后109个src/tests文件哈希一致；前端本片未改，重跑前后54个web源码/测试文件哈希一致。前端128通过、0失败、0跳过（含15项独立反例），同一UI版本的第四批15类Python→TypeScript合成桥接及实现复核证据保持有效，本片TS/Vite重跑通过。JS主包636.49 kB，体积警告保留，真实浏览器仍未验。
- 首版来源冲突/隔离问题已关闭；紧凑读取独立复验 300 项通过，分钟 A 相关 124 项通过，均为全套中的重叠子集。第三批全部 public 测试 455 项、独立对抗 173 项保持原复核范围；这些计数均不与第五批全套相加。033新增独立51项/相关405项已纳入当前全套。
- 033沿用相同真实60配置重跑260次ASGI，240份筛选响应逐字节等同第四批，20次集合与旧参考相同，来源/账本不变。
- 同伴 A 真实 8 例、160 端点对账通过，其中 2 个缺失正确关闭；50 股/200,000 行合成输入单次纯函数约 0.847 s。筛选真实 60 配置/260 次 ASGI/600 个成员配置判定及来源/引用/重复身份全部通过，不是独立市场样本或预测试验。
- 第四批历史[筛选验收](qualification/stock-filters.md)的50 成员、五种合同重异常响应 297,975 B、增量 252,964 B，响应体门槛通过；六配置中位耗时及新增解释层（最多 5.68 ms）通过；首轮耗时对29/30、一次完整复测15/15通过，原失败保留。10×20,000/N20的进程峰值RSS差两次+23.77/+43.49 MiB仍高于+16 MiB，资源部分通过，稳定p95未验。
- [合成性能复验](qualification/research-performance.md#内部紧凑读取复验当前实现)39 次正式 ASGI 请求通过，完整/紧凑响应及来源身份一致，主矩阵与旧基准逐字节相等。两种 200,000 行集合的三次测量中位数分别由 15.298→11.988 s、14.719→12.888 s，有限优化保留条件通过，十余秒等待仍须改善。
- [真实浏览器验收](qualification/research-browser.md)已获用户授权；同环境服务探测成功，但 Chromium 创建页面前遭本地 socket 权限拒绝，支持的提权重试仍失败。页面未加载、界面操作与截图未完成，当前阻断为环境权限。实际网络、并发/尾延迟、峰值内存和浏览器性能仍未验。自动化及 ASGI 结果不证明真实行情兼容或预测价值。

## 接下来的顺序

1. **补齐真实交互与资源验收。** 筛选界面的模型/静态组件与构建已通过，接下来补真实操作及仍开放的筛选RSS增量/稳定尾延迟；033相对旧峰值下降不替代该门槛；同伴 A 保持纯函数，新增 API/UI 需另行设计。在具备浏览器本地 socket 权限且可连通服务的受支持环境中，实测快速切换、左右交换、集合增删、异常与窄屏/键盘操作；在已有最大窗口/集合 ASGI 记录上补实际 HTTP、并发等待和内存记录。之后若修改代码，重跑受影响及最终整套测试。Linux 的通过结果不代替 Windows 原生回归。
2. **完成新取数链路与真实行情核对。** 先查清隔离运输环境的网络要求，在受支持且获授权的条件下补新 CLI 成功链路，不通过自动重试、继承未知代理/凭据或改来源规避失败。40 份旧捕获已证明限定离线兼容；继续核软件导出、单位、复权、时段和覆盖，不据近期窗口推断完整分钟历史。
3. **推进分钟研究集成。** 分钟 A 先核真实源标签、覆盖和边界，再单独审查 API/UI；随后研究日线条件如何关联到当时可见的分钟数据；同槽量能、锚定均价、午休/隔夜/部分柱逐项验证。不把本轮 Kalman 参数直接套到分钟。
4. **扩展多股、板块与国际市场。** 历史成员、退市、公司行动与复权、跨市场时区和币种优先；再研究关系变化、收缩相关/PCA和板块扩散。每个方法与简单基线比较。
5. **验证预测与交易增量。** 预先固定证券与时间区间，隔离训练/验证/最终测试，保存全部尝试，处理重叠样本；再加入成本、成交约束、风险预算、组合和纸面验证。零增量与失效结果完整保留。

034信号诊断已有独立设计决定，但执行仍等待033完成合并后的明确启动；未实现、未跑产品测试，不纳入第五批。

逐笔/报价/盘口、基本面及公告时点仍属完整目标，对应数据到位后独立研究。自动实盘下单不在当前范围。

长期方向详见[031 TradingView 高级能力路线](research/031-tradingview-advanced-roadmap.md)：可解释条件、跨周期判断、历史事件与执行约束、回放与条件通知、组合分析依数据和独立验收分步推进。031是研究路线，不整体授权或证明所有候选已实现；032是其中已单独复核的有限筛选切片。

## 怎样与国内外产品比较

[027](research/027-competitor-workflows.md)记录了本轮读过的官方资料与限制：通达信已有跨股/板块公式，同花顺已有自然语言选股，TradingView 已有扫描与策略模拟，AmiBroker 已有历史探索和滚动样本外，QuantConnect 已有配对研究流程。功能名称本身不足以构成优势。

比较任务固定为：解释一次突破及失败案例；查看同定义事件与基线；解释两股对齐和偏离；比较指定集合并核对日期/成员/覆盖。固定产品版本、权限、输入、截止和公式，测首次正确完成耗时、操作量、数值一致性及解释完整性。完整来源和待核权限见 [027 来源表](research/027-competitor-workflows.md#8-一级来源实际阅读范围与局限)，广覆盖清单见 [006](research/006-domestic-capabilities.md) / [007](research/007-international-capabilities.md)。竞品同任务客户端实测尚未完成。

预测增量另行比较样本外效应、基准差异、失败市场状态与成本后可执行性。没有达到预设标准就保留“尚未证明增量”，不宣称全面超越或保证收益。
