## 成功定义

提供个人可运行的 A 股数据分析工作台，能够追溯每条数据和指标的含义、精度、可用时点及证据。对常用国内外软件建立持续更新的能力对照，独立实现必要功能，以真实数据准确性、可复现性及样本外决策价值证明改进。功能数量、平滑的曲线、单一回测收益均不能单独证明超越。

## 阶段与验证

| 阶段 | 工作 | 必须提供的证据 |
|---|---|---|
| 1 数据基础与工作台 | 同花顺/通达信真实文件、严格 OHLCV 导入、来源账本、日线与分钟图、逐根回放、量价描述 | 来源可查的原文件；字段逐项比对；单位/重复/复权/异常测试；浏览器实际运行 |
| 2 波段与分钟复盘 | 分时季节性量能、锚定 VWAP、多周期联动、事件标注、突破/回撤/缺口/形态条件、成交分布 | 每项有研究卡；重采样守恒；午休/集合竞价/部分 K 线处理；截止时点回放无泄漏 |
| 3 决策证据 | 信号条件筛选、事件研究、基准比较、成本与成交约束、滚动样本外检验、敏感性 | 时点一致的证券池与公司行动；训练/验证隔离；多重试验记录；区间估计及失败案例 |
| 4 日内研究 | 逐笔/盘口数据适配、方向归因、成交量剖面、订单流与流动性 | 数据确实含所需信息；方向分类误差报告；真实回放比对；交易规则按品种与日期处理 |
| 5 中长期与组合 | 市场广度、行业/风格轮动、基本面事件、择时、仓位/相关性/风险预算、组合归因 | 历史成分与公告时点；退市样本；约束/成本后样本外比较；稳健性 |
| 6 竞品覆盖与实证 | 对照常用软件的功能族逐项验收；可复现基准及文档 | 功能覆盖率、数据误差、响应耗时、解释完整性、用户任务完成情况；不能仅以已有代码自评 |

这些阶段是实施顺序，后续范围仍属于原始目标。每一阶段结束都更新事实状态与缺口。

## 数据层级

- 日/分钟 OHLCV：精确记录开高低收与总量；无法恢复柱内交易路径。
- 金额 + 同口径成交量：能计算该区间真实成交均价（受源数据金额精度约束）。
- 逐笔：可计算价位成交分布；主动买卖方向仍取决于数据字段和分类规则。
- 历史盘口/委托事件：可研究挂撤单、队列与流动性热图。
- 复权因子、交易日历、证券状态、流通股本：分别支撑公司行动、缺失判断、可交易性和换手率。

## 技术决策

Python 负责可测试的数据与分析内核，HTTP API 只供本机工作台。React + TypeScript 负责交互；采用成熟开源 K 线渲染库并保留其署名。先把单证券真实数据链路完成，再按证据引入批量存储和计算工具。原始文件在本地保留，十进制字符串通过 API 传递，图形坐标才转为浮点数。
