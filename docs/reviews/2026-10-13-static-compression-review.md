# 061 有界静态表示独立复核

2026-10-13。编码前设计 GO；最终产品代码 GO，独立集成矩阵与最终完整回归条件已满足。仅限 [061 合同](../research/061-bounded-static-compression.md)的本地构建静态 JS/CSS 表示，不代表公开部署、浏览器性能或 Windows 原生验收。

## 编码前要求与处理

清单拒绝重复键、布尔伪整数、越界大小、错误路径/hash/类型、符号链接和非普通文件。目标原件及压缩件在有界读取前拒绝 FIFO 等非普通文件；目标响应加 nosniff，不修改 API 头。文件读取与哈希进入既有线程池，发送不可变 bytes，取消 hash 后重新打开 FileResponse 的窗口。

## 实现审核发现与修正

- 初稿经独立复现，公开 exposed.json 符号链接指向内部清单时返回 200 并泄露清单。修复后 lookup_path 拒绝解析到内部名称的目标；普通公开文件的原 StaticFiles 行为保留。清单、sidecar、目录别名与旧 dist 路径经过回归。
- 初稿构建器缺少 assets/.encoded 父目录及输出/清单符号链接检查。新增 lstat 类型校验；五种链接位置测试确认外部合成哨兵未被覆盖。
- 最终一行 casefold 修正经独立复核，预留路径大小写别名被拒绝。它有助于大小写不敏感文件系统，尚无 Windows 原生运行证据。

Workbench 只替换末尾静态 mount 与 import；API、Store owner、Host/Origin/CSRF 与 no-store 未变。没有 API 中间件、新依赖、全局缓存、React lazy 或新请求框架。先选择表示再处理条件请求；HEAD 与所选 GET 元数据一致；目标 Range/日期验证器/pathsend 的取舍已冻结。
