## 2. 检索方案必须明确的边界

1. **防止只交漂亮图。** 用户必须能查到旧窗口原日期/序号与原价，逐点解释哪一步不同，并允许拒绝最近邻。只展示相似线条、数字排名或“发现相似模式”不够。最近旧区间与端点变化近邻应作为简单参照；主检索按自己的距离优于参照是优化定义的必然结果，不能算实用或预测增量。
2. **不把排名写成充分相似。** 有任意合格候选时就会有最近邻，即使候选全都很远。首片不输出概率、形态类别、胜率或“可靠先例”；不按好看的结果改长度、度量或股票。原始搜索范围与合格/不合格窗口数量必须可见。
3. **时间边界用完整区间。** 查询必须在明确 D 结束且使用固定槽数，D 缺失/无效时不可回退。候选末点须严格早于查询首点，窗口内坏/重复槽不可删后补足。结果之间若贪心去重，规则与并列次序要冻结；去重只减少重复展示，不形成独立统计样本。固定 D 后追加未来不得改旧结果；全序列 Matrix Profile 的旧最近邻会被新数据更新，不能直接复用为此语义。
4. **保留幅度与来源时钟。** `P_j/P_0−1` 能消除价格单位的共同正倍率，同时保留相对幅度；不能把它称为经济持有收益。显示自然日跨度、21 个来源点/20 次变化，不能暗称相同交易日跨度。停牌、缺失和不同节奏仍可能损害可比性。
5. **公司行动和锚点错误必须有反例。** 首价错误会改变整个基准化向量；窗口内部机械除权可能主导匹配。必须保留跳变、原价和最大逐点差，不自动平滑/删点/复权。给出两条源路径完全相同但经济成因不同的例子，证明算法无法识别原因；未知语义不关闭全部算术，也不升级解释。
6. **不为复杂度自造工程。** 单股单查询直接扫描足够：距离计算 O(Nm)，无需全矩阵、FFT、索引或持久状态。全量排序再去重另有 O(N log N)；固定少量结果可采用固定轮数扫描。数值比较、并列、输入/输出上限和独立 oracle 在实现前固定；不为“精确”制造通用审计平台。

## 3. 度量的独立反例

以下为纸面推导，未运行实验；不据此宣称哪个金融度量有效。

- **z 归一化忽略幅度：** `[100,101,102]`、`[100,110,120]` 以及几乎不动的 `[100,100.00001,100.00002]` 的 z 形状相同。零方差无定义；近平坦序列会放大微小噪声。首片不用 z 合理，不能以加 epsilon 修补后称解决。
- **端点、ER、回撤不能确定顺序：** `[100,110,100,110,110]` 与 `[100,110,110,100,110]` 的末端变化、ER 和最大源收盘回撤均相同，逐点路径有两处差异。这个例子说明检索的真实信息增量是时序位置；它没有说明较小路径差意味着未来更像。
- **欧氏仍会偏爱平滑平均路径：** 局部折返稍有错位就可能让“方向节奏相似”的候选输给平坦候选。接受固定同槽比较意味着接受这种失败，必须显示局部差异；不能事后加 CID 或改权重救回好图。
- **DTW 可消除本任务关心的持续时间：** `[100,100,110,110]` 与 `[100,110,110,110]` 可通过一对多对齐得到零 DTW 距离，尽管上涨时点不同。当前任务保留源步时点，所以暂不用 DTW；这是任务选择，不能外推为 DTW 普遍失败。
- **未来完全不受保证：** 两个世界的查询与全部旧历史一致，D 之后分别上涨/下跌，检索结果必须完全相同。即使未来另加旧片段后续路径，也要重新冻结成熟终点、选择范围和验证方式；本片不夹带这些标签。

## 4. 一手资料核读及其作用

- [Yeh 等，Matrix Profile 期刊扩展稿](https://www.cs.ucr.edu/~eamonn/MP_journal.pdf)：§2.1、§4.5—4.6、Table 5。定义使用 z 距离，m/2 排除区只处理平凡匹配；STOMPI 更新既有索引。本文采用更严格的完整区间边界，且不实现 Matrix Profile，不借论文速度数字背书。
- [De Paepe 等，Implications of Z-Normalization](https://dieterdepaepe.github.io/files/publications/Implications_of_Z_Normalization_in_the_Matrix_Profile.pdf)：§3.1—3.4、§3.5 开头和 §4.1。核对相关系数等价、正仿射不变与平坦噪声反例；未通读证明，也未采用其需要噪声信息的修正。
- [Batista 等，Complexity-Invariant Distance](https://www.cs.ucr.edu/~eamonn/Complexity-Invariant%20Distance%20Measure.pdf)：§3.2、§4.1—4.2。原文给出简单路径偏好和事后挑赢领域的风险；分类任务结果不能授予股票检索资格，本轮不新增 CID。
- [Keogh、Lin，Clustering of Time Series Subsequences is Meaningless](https://www.cs.ucr.edu/~eamonn/meaningless.pdf)：§2、§3.1。反例针对滑窗聚类，包含股票与随机游走得到近似中心的比较；不能泛化为所有路径检索无用。
- [Rakthanmanon 等，Searching and Mining Trillions](https://www.cs.ucr.edu/~eamonn/SIGKDD_trillion.pdf)：§1.2、§3.1、§4.1.1。核对一对多对齐、路径约束和平方距离排名。作者另一托管地址读取失败后改读项目首页所链原文；未复现速度或分类结果。
