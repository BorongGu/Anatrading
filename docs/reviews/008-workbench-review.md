| WB-DA04 / P1 | 单worker不固定Store执行线程，关闭及HTTP中断语义有空白 | 接受。一个专用线程拥有Store，open／全部方法／close同通道串行；关闭先拒新任务、等已接受任务结束再close。无长导入实时账本轮询承诺，首版无取消按钮 |
| WB-DA05 / P1 | 两面各自最新Q仍可拼成不同代次的配对导出；代码形式差异可能被误判身份冲突 | 接受。配对代次同时冻结两快照、两个Q、截止和声明，两面都匹配才开放整对导出；一面失效阻断整对。仅比较可比源断言，代码字符串形式不直接决定身份 |
