## 3. 编码前必须关闭的四项

### SE-01：唯一主比较仍缺唯一时间总体

**阻断。** §6定义了唯一权重，§7同时给全目标区间、2026年前段、2026内部检查段及季度；§9直接按“主Δ_main”的正负停做，没有指定哪一个时间总体拥有该身份。相同公式在多个时间总体上使用，仍可能留下选择有利结果的自由。

最小解决：在看标签前明列 `primary_period`、信号日期闭区间、cutoff、cut、purge规则、主支持集合的形成规则以及唯一停止值。建议将2026-01-01～2026-10-09的内部检查描述段作为唯一历史主比较；前段、全段及季度均为诊断，不能替换它。该段已见，不授予OOS资格。作者也可在运行前明确选择全目标区间作为唯一描述主比较，但必须同步说明全段是否保留cut造成的purge，以及后段冲突时如何停止，不能实施时临时决定。

还须写明：季度按signal_date归属，沿用单一全局cut的状态，不在每个季度边界重新purge/去重；端点允许跨季度但不得超过cutoff。跨期支持股票集合变化要附成员清单；可另列同支持集合诊断，但不得以该子集重新产生第二个“主结果”。

### SE-02：按实际精确输入域收窄数值合同

**阻断，修复应减小范围。** 035将“非零精确R转float后为0、溢出、旧入口极值整体抛错”列为尚待冻结的主体兼容风险。实际入口已有强边界：

1. `daily_bars`经 `decimal_value` 接受DECIMAL(38,18)；严格OHLC有效价满足 `10^-18 <= C < 10^20`，任意两个不同有效价差至少为 `10^-18`。
2. `event_study.py:92`实际计算 `float(Fraction(C_end)/Fraction(C_start)-1)`。除法及减1均先精确执行，随后才转float，未先转换两端点，也未做float比值后再减1。
3. 因而非零R满足 `|R| > 10^-38`、`|R| < 10^38`；这些数远离binary64下溢/溢出。20,000行以内的绝对值和小于 `2×10^42`，旧fsum及type-7分位插值同样不会因正常输入越界。普通表示舍入仍存在，幅度不承诺精确。

这些是源码边界与代数推导，没有运行产品。相邻端点先转float可能碰撞，034的log问题也真实存在；它们不能套到035这一精确比值接缝。

最小冻结：

- 新入口只接既有完整Store查询/受同资格约束的合成夹具，先经过strict normalization；不允许裸bars或扩展Decimal值域悄悄成为新公开输入。
- N、L用Fraction或既有exact_sum。数学式 `2*N>=L` 不能直接假定Python Decimal在任意全局context下精确：比较用Fraction，或独立精确求和N+N；零路径单独定义。D=false时ER仍可高，不能把E改写成“向上”。
- 标签sign直接比较原Decimal端点。正常支持域内它应与旧float标签的正/零/负逐条相同；出现矛盾是实现、入口或版本错误，停止该证券新比较并留原输出，不能静默剔除后继续汇总。
- 删除将正常事件按假想float下溢再筛一遍的必要性。若保留防御字段，明确正常支持域预期为0；超域输入在已有输入校验处失败，不构成候选有效事件。旧event_report异常则新连接失败，错误作用域及未执行计数显式保留；不改旧函数、旧响应、旧ID或修旧错误语义。
- `p_s`、`Δ_s`及等权 `Δ_main`可由整数计数形成Fraction；停止判断使用精确有理数的符号，float仅展示。避免用浮点累计消减、四舍五入或epsilon决定“Δ>=0”。这是少量标准库算术，无需新依赖。
- 补一个合法幅度边界：正终点相对极大起点很小时，负R转float可舍入为−1，虽然终点严格大于0。这应标为近似幅度并保留端点/精确符号，不能据显示−100%反推零价，也不能当成符号失败。

### SE-03：旧标签状态、新资格与分母须分层

**阻断。** 035的 `旧valid = comparison_valid + comparison_numeric_invalid` 没覆盖它自己要求的“覆盖未知导致整证券关闭”。旧event_report不会因unlocated coverage自动关闭全部已定位事件；新报告关闭后仍可能存在旧valid。因此当前守恒式在该场景不成立。

最小解决是状态表和完整对账，不增建状态框架：

| 层 | 冻结行为 |
|---|---|
| 旧label_status | 按代码先判终点是否存在；不足h为immature，即使现有路径含坏组。终点存在才判路径invalid，再执行旧比值计算。 |
| 旧evaluation_status | 对选中事件，训练信号且已知label_end>=cut先覆盖为purged，包括label_status本为invalid的情况；未选事件最终为overlap_excluded。两种状态都保留，不能只存最后一个。 |
| 新全局资格 | source rejection、coverage unknown等关闭新条件比较，但不得写回旧event状态；不能把全局来源问题计为numeric_invalid。明确哪些旧计算仍执行，哪些未执行。 |
| 新条件资格 | 在严格B成立的21槽内，滞后11槽天然齐备。正常支持域D/E不应unknown；若仍unknown，记录连接/来源/内部原因并对账，不能当false。 |
| 新比较资格 | 要么将分母恒等式限定在source-admitted证券，再单列全局排除；要么列出互斥的source_unavailable、numeric/internal_failure及comparison_valid。作者选择一种，统一所有表。未执行的计数为null并附原因，不能伪装为0。 |

必须补的组合例：旧valid+新coverage关闭；坏标签且跨cut；坏路径但未来不足h；未选但原标签有效/无效或其终点跨cut；全局失败前后原B/selected不改变；旧入口整体错误不能返回部分成功“完整报告”。

对遗漏成功的计数只在明列的共同成熟可评价集合上形成。至少并列E=true、E=false各自正/零/负及同尺度R分布；A1整体另列。除遗漏正例数量，还给 `positive_E_false/positive_A1`（分母0为null）和条件保留比例；未知标签的遗漏成功数保持未知。这样才能看出降低未上涨比例是否伴随丢掉大部分后来上涨事件。新增比率只是代价说明，不得再选一个最有利比率作为效果主指标。

3. 从同一账本派生A0/A1/A2、季度及逐股计数，不为每个条件/分段重新检测B或去重，不复制三份全行情。源窗口以索引/ordinal/日期和共享源身份定位，避免每条复制完整context。

## 4. 前向观察及推断边界

### SE-05：前向完整前缀必须有固定锚点

**启动前向观察前阻断，旧固定源描述不因此停摆。** “每次使用完整来源前缀”仍不足以约束前向版本：若后续来源是滚动最近640条、补入较早日期或修订历史OHLC，重新从新起点贪心选B可能改变很久以后的selected。有限ER记忆不会使B-only去重的起点影响自动消失。

最小解决：预注册每股基线完整前缀身份和最早槽，前向版本验证该前缀逐槽未改且只追加。若历史被修订、插入或截短，则明确该版本不属于原冻结前向主实验；保留修订版另作描述，禁止拼接不一致价格尺度来维持旧名字。成员停止更新/退出仍保留，截止时不足5槽为未成熟；不换股、不延长截止凑标签。没有可验证的同一锚点，就不宣称该前向实验延续原B-only样本。

前向方案仍只验证源版本条件标签，PIT/closed/known_at资格不能由日期切分自动补齐。允许先完成旧版本小报告，再单独决定是否值得启动2026-10-12～2027-03-31观察；本审查未创建采集、监控或任何未来任务。

### SE-06：固定阈值可研究，负值不能作为成功许可

1/2能作为唯一、易解释、未优化的几何界线；没有最优性、经济意义或外部有效性保证。现有方向消融及E=false补集保留后，问题定义基本合格。新增的是条件描述差异，不能写“ER有独立因果价值”。

B-only去重正确避免按ER重新入场改变机会集合；它仍有背景重叠、跨股共同冲击和选择成员偏差。不上IID显著性/置信区间是合理收窄；目前也无需为了描述表搭建bootstrap。有效事件多不意味着信息足够，M/30及不同信号日期必须与Δ同屏或同段。

035“极少日期/证券”“较多未知”没有机械阈值。**这不应阻止如实输出小样本描述，但不足以批准统计发现、前向升级或产品化。** 不建议现场编造每组20例、提升5个百分点等新胜出门槛。最小处理：明确本轮所有结果都只分为“该固定样本方向不支持 / 该固定样本有描述性负差 / 退化或无法比较”，正向叙述也同时报告支持稀疏性、遗漏代价和分期冲突。任何进一步采集或UI仍须独立决定，不能把Δ<0变成自动继续半年研究的许可。

若整体E退化、主Δ>=0、主与既定分期/同支持权重相反，允许就此停止；无需换指标证明项目进步。若仅负差极小或支持集中在少量日期，也允许结束035，保留既有能力。这不损害长期高级分析目标，反而避免用指标数量替代可验证价值。
