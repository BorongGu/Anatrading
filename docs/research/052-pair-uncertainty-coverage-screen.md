# 052：单对相关的不确定性任务与固定块法覆盖反证

日期：2026-10-13。范围：来源条件统计研究、一次预冻结合成实验；不新增产品、接口或界面。

## 1. 决定与用户任务

**停止本次固定 L=5、B=999、n=60 的同步 stationary bootstrap basic95 版本进入全家庭工程。** 四个预定格的覆盖分别为 89.1%、88.7%、69.5%、67.4%，按事前共同 Monte Carlo 错误预算，四格均有明确欠覆盖。依赖格相对 iid bootstrap 的改善成立，但仍远低于95%；相对 Fisher 的配对差区间均含0。不能将结论泛化为所有 bootstrap 失败，也不能称真实股票的95%覆盖已经验证。

[051全成对双窗描述](051-complete-pair-windows.md)继续提供完整有符号相关、完整成员/失败原因和精确来源端点回查。一次核对共同来源组全部成员对具有批量工作流价值；逐目标[049](049-signed-peer-neighbor-workflow.md)可以重构数值，不抵消这项价值。本研究没有给051新增置信区间、显著性或“关系稳定”标签。

区间可解决的独立任务是：在明确的平稳向量模型下，判断哪些同窗总体 Pearson 参数 `ρ_ij=Corr(X_i,t,X_j,t)` 与输入相容。抽样区间不表示给定输入的算术误差。来源复权、公司行动与历史可得性未知，限制经济收益和PIT解释，但不自动禁止有明确条件的参数研究。平稳、弱依赖和矩条件无法由一次60行诊断认证；合成机制可以按设计保证条件，真实市场另验。

两个窗口的参数差 `Δ=ρ_current−ρ_previous` 是另一任务：单窗区间重叠与否不能代替差异检验；共享价格端点不自动证明依赖或独立，必须建模共同测量误差和跨窗状态。同期相关不证明协整、套利、经济关系、未来稳定或预测收益。两个机制可在已观察120行完全同分布、下一期关系却相反，过去区间不能独自排除这一反例。

## 2. 三条路线与简单强对照

1. **保留描述和来源回查。** 无需总体参数存在；完整展示短窗相关、成员、端点与失败，避免把浏览后的极端值解释为固定关系。代价是不能量化抽样不确定性，回查也不能替代参数推断。
2. **Fisher近似与预定义家庭校正。** `tanh(atanh(r) ± Φ⁻¹(1−α/2)/√(n−3))` 是iid双变量正态参考下的强简单基线，不是任意分布有限样本精确区间。n=60、r=.5的95%算例约为[.282,.669]，仅作公式尺度说明。1225对的一窗可用有效边际区间加Bonferroni，两窗全部单元则为2450；并集界无需各对独立。Holm调整p值不能贴到未调整区间上充当同时区间，BH也不能无条件忽略共享成员依赖。反复换截止、窗口或成员超出一次固定家庭保护。
3. **保留序列依赖的同步块法；自归一化作竞争路线。** 几何块长与循环端点针对序列依赖，但必须同步抽整行向量。固定、自动选择、看结果选块长分别是不同程序。增大B仅减小重采样数值误差，不增加60行信息。自归一化绕开显式长期方差带宽，仍需函数中心极限定理、非退化长期方差与余项条件；递归Pearson早期退化及1225维归一化矩阵由60个递归偏差造成的秩限制需另解。本轮没有实现或模拟自归一化。

机制反例：独立的平稳AR(1)两列、共同a、ρ=0时，乘积影响函数的长程方差膨胀因子为 `(1+a²)/(1−a²)`，a=.8约4.56；这是渐近推导，不能当n60 Pearson精确分布。即使时间上iid，`X=Sε,Y=Sη` 的共同尺度也使乘积方差按 `E(S⁴)/E(S²)²` 膨胀，原变化无自相关不认证高斯参考。非平稳、长记忆、重尾、常量及来源不同步均需明确失败边界。

单对通过也不能升级全家庭：1225对Bonferroni每尾约.0000204，B999无法直接估该尾分位数；全家庭最大统计量校准需另验。以下一次筛查只比较单个预指定pair、单个窗口的三个固定程序，不检验选择后覆盖或两窗差。

## 3. 事前冻结设计与可复核定义

正式执行前完成独立协议/执行器审查，冻结以下设计。早期讨论草案的欠覆盖预算曾为.05/12；正式协议在任何随机结果前将总预算分为.025+.025，以共同保护欠覆盖及配对改善结论。

### 3.1 生成机制、种子与环境

格号s=0,1,2,3依次对应 `(a,ρ)=(0,0),(0,.5),(.8,0),(.8,.5)`；每格M=1000，j=0,…,999，n=60。三方法共享同一数据集。全量4000个数据集，不增样，不因途中覆盖停止。

每个数据集只调用一次 `Generator(PCG64(seed_data)).standard_normal((60,2))` 得到float64、C顺序Z。定义 `W[t,0]=Z[t,0]`、`W[t,1]=ρZ[t,0]+√(1−ρ²)Z[t,1]`；`V[0]=W[0]`，`V[t]=aV[t−1]+√(1−a²)W[t]`。初值直接来自平稳 `N(0,Σ)`，`Σ=[[1,ρ],[ρ,1]]`；创新协方差为 `(1−a²)Σ`，故所有观测方差1、同期相关ρ，滞后协方差 `a^kΣ`。无burn-in、零初值或事后改机制。

- `seed_data=202610130000+1000*s+j`
- `seed_iid=seed_data+1000000`
- `seed_stationary=seed_data+2000000`

每个(s,j,角色)重建独立Generator/PCG64，无共享可变RNG、隐式bit generator或Python hash种子。固定种子命名空间无碰撞，不声称伪随机流有数学独立证明；外层二项推断采用通常的独立重复模拟模型。数据生成后只读，按float64 C序小端字节记录身份hash。跨机器/构建逐位一致性不保证。

Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0；Linux x86_64。单进程、CPU、float64；OMP/OpenBLAS/MKL/BLIS/VECLIB/NUMEXPR线程环境均为1。使用现有依赖，未安装或升级。

### 3.2 三程序与失败政策

Pearson核：中心化副本，`r=Σ(dx*dy)/(√Σdx²*√Σdy²)`。输入、均值、平方和、分母、结果任一非有限或平方和≤0均失败；任一列 `√Σdx² < 1e−13*abs(mean(x))` 记near_constant失败。仅 `1<abs(r)≤1+8*eps(float64)` 可作端点舍入裁剪并记数，超出则失败；有限r=±1单独记边界。

- **Fisher95：** `z=atanh(r)`，半宽 `norm.ppf(.975)/√57`，端点取tanh。不纠偏、不估有效样本量、不先诊断再选法。原r=±1时Fisher失败；非有限或倒置端点失败。
- **iid-pairs basic95：** 一次 `integers(0,60,size=(999,60),dtype=int64,endpoint=False)`，每索引同步抽X/Y整行。
- **stationary basic95：** 固定平均L=5，p=.2。先一次同形状integers得到J，再一次 `random(size=(999,59),dtype=float64)` 得到U，即使J元素不用也照抽。`I[b,0]=J[b,0]`；t≥1时若 `U[b,t−1]<.2` 则 `I[b,t]=J[b,t]`，否则 `I[b,t]=(I[b,t−1]+1)%60`。两列同步，允许59→0与重启抽回原处，无强制末端重启。块长为正整数几何、均值5，最后块截断；每块并非固定5。无预白化、AR拟合或块长选择。

两个bootstrap均B=999，用同一Pearson核。排序后type7分位数：`h=(B−1)q,k=floor(h),g=h−k,Q(q)=(1−g)r*[k]+gr*[k+1]`，q=.025/.975。basic原区间 `[2r−Q(.975),2r−Q(.025)]`，与[-1,1]取交集；不能各自clip端点来伪造非空交集。包含真值端点即覆盖，不加epsilon；宽度为交集长度。

原样本失败时三程序均计未覆盖；任一bootstrap replicate失败或999个r*全部相同时，该方法该数据集整体失败。不可删除、补抽、nanquantile或缩覆盖分母。空交集可算但未覆盖、宽度0；全[-1,1]另记无信息；仅两分位数相同允许零宽并单记。所有覆盖和失败率分母始终1000。可算宽度失败项为NA；另报全M惩罚宽度（失败赋2），这仅为工程指标。配对宽度差仅用双方可算数据集。

### 3.3 共同Monte Carlo预算与正式STOP

对N=1000定义单侧Clopper–Pearson边界：`L(k;α)=Beta.ppf(α,k,N−k+1)`（k=0取0），`U(k;α)=Beta.ppf(1−α,k+1,N−k)`（k=N取1）。二项尾反演的保守覆盖配合并集界，不要求同一数据集内各方法独立。

A：12个覆盖断言共用.025，`α_A=.025/12`；仅 `U(K;α_A)<.95` 判正式欠覆盖。B：8个block对照配对差共用.025；每比较gain/loss两边共四个界，`α_B=.025/(8*4)`。令n11为都覆盖、G为仅block覆盖、H为仅对照覆盖、n00为都不覆盖；四者和1000，`Δ̂=(G−H)/1000`。保守区间为 `D=[L(G;α_B)−U(H;α_B), U(G;α_B)−L(H;α_B)]`。D下界>0为可辨改善，上界<0为可辨变差，含0记不确定。未使用独立两样本公式。

A+B使全部欠覆盖断言和全部配对区间同时正确的Monte Carlo概率至少.95；这不把数据区间变成已认证95%区间。逐项原始95%区间另列，仅描述模拟精度，不能触发正式STOP。

事前规则：任一方法任一格正式欠覆盖即停止其“四格均95%”主张；block任一格失败就不进入全家庭工程，不调L/B/seed续赛。即使未发现block欠覆盖，也必须两个a=.8格对两对照的四个D下界全部>0，且a=0两格无任何D上界<0，才有资格另议独立研究；这仍不授予产品准入。未检出损失不证明非劣，未拒绝欠覆盖不证明达标。实现偏离、资源中断或输出缺失属于INVALID/INCOMPLETE，不可伪作统计STOP。
