## 1. 建议：一个能否定现有模型的小切片

**下一候选为“严格前序的一步误差与经验范围诊断”。** 用户问题是：

> 图上的趋势估计在最近同一批来源观察上，比直接沿用上一收盘价少犯了多少误差？当前这一步超出此前误差范围了吗？这个判断用了哪一段过去、在哪些情况下不能解释？

只做单股日线、一个明确截止、三个固定预测器的配对误差，以及当前一步的前序经验误差范围。允许结论为“Kalman 未优于朴素基线”“范围对急变滞后”“无法评价”。先交付纯计算研究结果，经过独立审查和验证后再决定是否接入现有页面。

这项增量有可观测的评价目标：**下一条来源 log(close) 的误差**。它不声称观测到了潜在真实趋势、不把低误差当作可交易 alpha，也不把经验范围叫上涨概率。已有平滑、突破、路径效率、拐点和同伴差值继续复用。

一步源价误差是有意选择的窄目标。它不能全面评定日线波段信息或长期趋势估计：某平滑器可能一步误差较大，却有另一种需要独立验证的结构/较长跨度用途。本片能反驳把平滑度直接当预测力的说法，不能据一次RW胜出就宣布所有趋势研究无用。若用户任务只需要已有事件回顾且不需要模型误差核查，本片应缩减或停做。

不推荐下一片直接加入以下功能：

- 斜率正态概率或醒目的“95% 趋势置信带”：目前模型方差是固定工程假设，真实潜在趋势没有验证标签。
- 再建一套创新/收益异常分数：两个现有分数已可查看；需要新增的是前序误差参考和同日期朴素对照。
- 自动变化点、趋势重置或“市场进入新状态”：CUSUM/BOCPD 对分布、尺度、阈值和事件时点有新的依赖；当前先衡量已有预测是否失配更容易证伪。

长期方向仍覆盖单股、配对、多股、板块及分钟研究。本片先回答最小问题，避免将未经验证的分数批量传播成选股条件。

### 2.1 固定模型方差的关键限制

令 `P^-_t=F P_(t-1) F' + Q`、`S_t=H P^-_t H'+R`、`K_t=P^-_t H'/S_t`，Joseph 更新为 `P_t=(I-KH)P^-_t(I-KH)' + K R K'`。当前 F/H/Q/R/P0 固定，所以**同段长度和重置位置相同的两个有效价格序列，P/S/K 完全由递推决定，不随价格振幅自动扩大**。这可从本地公式直接推出，未将其归因于论文实证。

因此 `slope ± 1.96 sqrt(P_slope)` 即使在指定线性高斯模型内有解释，也没有经过本样本的市场覆盖校准。`Φ(slope/sqrt(P_slope))` 还额外依赖状态分布假设；它不等于未来涨价概率。当前 P0/R/Q 为工程常数，首值又以第一条观察初始化，不能靠“模型内”三个字省略这些假设。

大创新可以暴露模型与源价不一致，却不能唯一分辨真实信息、价格修订、公司行动、重尾、波动变化和模型滞后。用观测误差经验范围调整宽度，也**不能校准不可观测潜在斜率的符号概率**，二者目标不同。

### 4.1 一个明确的简单 CUSUM 候选，暂不编码

若对现有标准化创新 `z_t=innovation_t/sqrt(S_t)` 做双侧累计，可定义：

```text
C+_t = max(0, C+_(t-1) + z_t - k)
C-_t = max(0, C-_(t-1) - z_t - k)
flag_t = C+_t > h or C-_t > h
```

只用于将来的固定合成比较：`k=0.5,h=5`，初值0，基模型预热后才累计；坏/重复/数值失败清零，触发后下一步从0累计，触发当步值保留。参数是待测工程选择，无股票误报率承诺。单次 `z=6` 可立即越界；持续 `z=1.5` 在第6步越界（严格大于5）。所以它并不自动区分“单次冲击”和“结构改变”。

候选控制图对目标均值变化有意义，波动上升也能增加越界；对 `z²` 再做 CUSUM 将是另一套方法/参数，不附带实现。`z_t` 在正确线性高斯模型下的性质不能赋给固定工程模型生成的真实残差。阈值、重置、双侧监控、连续查看及30股同时尝试都影响误报；单点正态尾概率不能当长期误报率。

将来比较必须先定合成变化类别/幅度/位置、无变化序列误报次数和检测延迟，再评估。若对单跳/方差变化频繁误标均值改变，或对同号计数/当前阈值没有有意义增量，停止；不得以事后挑中的反转图形批准。

### 4.2 BOCPD 的参数与时点陷阱

R1 维护当前 run length 后验，依赖分段似然、段间先验、hazard 和初始化。完整算法每步状态数随历史增长；裁尾是近似控制，需独立的误差/身份合同。当前不为它建立新依赖或通用状态机。

**由原 Algorithm 1 直接推导的核查项：** 若沿用其先预测当前值、随后向增长/重置分支分配质量的索引约定，且 `H(r)=h` 恒定，令 `w_r=P(r_(t-1),x_1:t-1) p(x_t|r)`，则重置质量为 `h sum(w_r)`、总质量为 `sum(w_r)`，所以 `P(r_t=0|x_1:t)=h`。不能把该格直接画成随当前数据改变的“今天变点概率”。有信息的是后验在其它 run length 的分布；换成“当前观察已属于新段”的约定时须重新定义预测分支与事件时间。

这不是认定 BOCPD 无效。它指出直接移植热图/代码易误读；所谓变化位置、首次检出时点和后续修订必须分开。固定 `H=1/250` 也只是平均段长先验，不能因为论文用过250就选为 A 股常数。似然若设为分段零均值 Gaussian/变化方差，则检测对象是尺度，不是涨跌方向；prior 的形状/尺度约定同样须明确。目前没有选择这些先验的独立证据。

## 5. C 的最小因果公式与参数

### 5.1 输入、预热与三个预测器

一个明确证券的完整日线来源前缀，必填严格来源日期截止 D；无自动最后有效日回退，无 ordinal 图窗裁剪。冻结来源、参数与方法身份，固定 `mode=retrospective`。先沿用现有分组/资格与 Kalman/EMA/EWMA 单侧状态一次计算，**不调用全样本拟合或 smoother**。

在同一连续有效段，以 j=1,2,… 编号，`y_j=log(float(C_j))`，`l_j,b_j,E_j` 分别是既有 filtered level/slope/EMA log。对 j 的一步预测只能使用 j−1 的状态：

```text
mK_j = l_(j-1) + b_(j-1)     # 现有状态的下一来源步预测
mR_j = y_(j-1)                # random-walk / 上价延用基线
mE_j = E_(j-1)                # 滞后 EMA 基线
eX_j = y_j - mX_j             # X ∈ {K,R,E}
```

`eK_j` 应与已有 `innovation_j` 数值一致；`eR_j` 应与已有 `log_return_j` 一致。它们是关键独立交叉检查，不可用 `y_j-l_j` 或 `y_j-E_j` 替代：后两者包含当前观察，会人为缩小误差。EMA 不是专为一步预测拟合的最优模型，其价值是现有简单平滑基线的同目标对照。

**生成顺序是合同的一部分：在吸收当前y_j之前，必须从j−1状态生成并保存本步预测中心、事前尺度与前序误差窗摘要，然后才处理当前观察、更新状态和计算误差。禁止用 `y_j−innovation_j` 倒推mK，亦禁止从当前post状态逆推prior。** 这种倒推在实数代数上看似等价，却会引入当前数值的抵消、浮点舍入和隐藏耦合，不能用于证明前序不变性。创新只供事后交叉检查。

当前完整 `series[j−1]` 已包含前一filtered level/slope/EMA、协方差和close，足以按上式独立核对prior；旧公开响应没有显式保存的本步prior记录。正式共享单次遍历的最小候选是在现有更新之前保存一个**私有、只在新诊断启用的prior记录/辅助返回值**，直接捕获 `previous_y`、origin与本步m/S/EWMA pre，再吸收当前值；旧 `signal_report` 公共字段、身份和数值golden保持原样。前一series字段可以验证该捕获，不能把事后从当前结果倒推当作捕获证据。不得为此另实现滤波器或默认扩大公共API。独立测试应探测捕获发生在当前更新前，并验证改变当前有效源价不会改变已保存prior。

共同资格要求预测起点 j−1 已过20条基模型预热，即 **j≥22**。不拿 RW 较早可算的误差增加它的样本数，也不为 Kalman 单独删掉难点。首次60个共同合格历史误差为 j=22…81；**首个完整当前诊断在 j=82**。这是工程初始化与观察量下限，未证明稳态或统计充分性。

| 输出频率/范围 | 单截止纯函数，当前诊断＋至多60条固定证据引用；不输出全历史预测扇形或下一日期目标价 |

### 5.2 严格早于当前的经验误差范围

令 `J_j={j−60,…,j−1}`，所有槽都必须按5.1合格。对每个 X：

```text
qX_j = order_stat_54({abs(eX_s): s in J_j})
lowerX_j = mX_j - qX_j
upperX_j = mX_j + qX_j
outsideX_j = abs(eX_j) > qX_j
MAEpreX_j = sum(abs(eX_s), s in J_j)/60
RMSEpreX_j = sqrt(sum(eX_s*eX_s, s in J_j)/60)
delta_MAE_KR = MAEpreK_j - MAEpreR_j
delta_RMSE_KR = RMSEpreK_j - RMSEpreR_j
```

负的配对差只表示**指定前序窗口中该损失较小**。不能从一项为负选择性省略另一项，不能将误差优势称为方向胜率。与 E 的差同样可复算，但首行优先显示 K/R 原值与差，E留对照项。

当前的 `mX_j,qX_j,MAEpre,RMSEpre` 在看到 y_j 前就能由来源前缀计算；`eX_j/outsideX_j` 需等当前源值可见。当前巨震不能先加入 q 再判断自身是否异常。现有 `ewma_variance_post_j` 只能用于下一步，不得换入当前尺度。

`q=0` 是合法的退化范围，保留 `[m,m]` 与原误差；不加 epsilon、不生成除以0的标准化值。首片不输出 `e/q`。没有60条时 q/前序损失为空并给 `calibration_history_insufficient`；当前一步误差仍可按自身资格显示，不能写成超范围=false。

**float判定以误差域为唯一权威。** 用已计算的 `e=y-m` 判断 `below=e<−q`、`above=e>q`、`inside=其余`、`outside=below or above`。`m±q` 仅为展示估计，标明舍入，不能再用它们重新产生另一套inside真值。例如m=1、u=2^−52、q=0.75u、y=1+u：误差域判定above，但float上界m+q可能舍入到y。该差别必须有独立边界用例；不得靠epsilon统一两套定义。

这是一种**前序经验尺度校准候选**，不改变 Kalman 的状态或协方差，不假定误差正态。0.90指过去绝对误差的选定分位；有限样本、依赖、偏斜、漂移和反复查看使它没有已证实90%未来覆盖。它也未采用 split-conformal 的有限样本修正和固定训练/交换性合同，不叫 conformal 区间。[R2] 对称距离范围不保证两侧各5%超出。

**独立离线评价**再记录每个已实现观察的：范围内/下侧/上侧数、平均宽度、连续越界长度、原始损失，以及共同日期的 interval score：

```text
IS_0.1(l,u;y) = (u-l) + 20*(l-y)*1[y<l] + 20*(y-u)*1[y>u]
本片对称范围的float权威实现：
width = 2*q
IS = 2*q + 20*max(abs(e)-q, 0)
```

分数越小越好，同时惩罚过宽和漏出。[R3] 后两式在实数域与第一式等价，实际float统一按误差域计算，不能用舍入上下界重新评分。固定模型/EWMA范围同样用其半宽替换q，保证相同判定合同；评分溢出只关闭该评分及汇总，不能删除对应观察。本片经验范围未证明为等尾分位，评分只是固定目标的比较工具，不因此获得分布校准资格。不能只比“范围内比例”，也不能在构造q的那60条上报告自证的90%覆盖；评价必须使用每条自己的先前q。新尺度不改变中心，因此不能把范围变宽解释成点预测改善。

主要输出仍是分项和固定证据；IS不成为选股综合分数，也不接现有事件标签、买卖条件或自动模型切换。更换W/p、损失、候选中心、股票、分组和评价日期均登记为新的尝试，包括失败、取消和无增量结果。

## 8. 独立oracle、合成反例与前缀验收

以下是**未来验收规格，未执行**。先由独立实现从源字符串构造60位Decimal log及通用2×2矩阵递推；不能调用产品 `_update`、窗口/分位/配对损失辅助函数。已有026参考可交叉检查，不能把相同函数调用两次当独立oracle。普通有限用例的候选数值容差沿既有研究取 `abs=2e−11,rel=2e−10`，判据为 `abs(actual−ref)≤max(abs_tol,rel_tol×abs(ref))`，须在编码前审查冻结适用范围；不据此承诺全部极端log轨迹通过，非有限/precision_loss仍按失败合同。数值近似比较与严格表示值真值分开。高精度源价oracle不能直接裁决产品float的临界布尔；局部二进制表示值和上下界舍入反例另以独立直接比较验证，不用容差吞掉above/inside翻转。

### 8.1 小手算例与强性质

- 后验偷看反例：给定上一状态 `l=0,b=0`、当前 `y=0.1`、Kalman level gain=0.5，真正一步误差为0.1；用更新后的level算残差只得0.05。新结果必须取前者。此例是局部代数，非现有完整参数轨迹。
- 分位/窗口反例：60个先前绝对误差为54个0.01及6个0.10，q=0.01。当前误差0.02超出；若先把当前并入窗口、挤掉一个0.01，错误q会变0.02并吞掉此次超出。相等时应为范围内；54名定义不能偷换成其它分位算法。
- 配对损失局部算例：三步K绝对误差为[1,1,10]、R为[2,2,2]，MAE分别4与2，RMSE分别√34与2。不得因为K两步更小就报告“K胜率2/3、模型更好”。数字仅检验损失算术，实际窗口仍固定60。
- 区间评分算例：α=0.1、[−1,1]、y=1.5，IS=2+20×0.5=12；改成[−2,2]为4。另在y=0时分别2、4，验证宽带会被惩罚。
- 同有效段长度、不同价格路径的P/S/K相同；不同振幅的实际误差q通常不同。两者有意区别，不能让新q回写旧P。
- 共同正价格倍率缩放应使log中心平移、误差/损失/宽度在数值容差内不变；不把浮点临界布尔不变冒称精确性质。

### 8.2 必须覆盖的合成矩阵

| 场景 | 独立目标/应保留的反证 |
|---|---|
| 常数正价、稳定log斜率、交替涨跌、固定种子的无漂移随机游走 | 零q合法；平滑的视觉优势不能预定为预测优势；已知模拟潜在趋势误差另算，不能和源价误差混为一个目标 |
| 单次永久跳变、单点后恢复、缓慢斜率转向 | 当前阈值不可被当前跳变抬高；随后经验窗会被异常影响，旧大误差离窗时q可能突降，必须记录 |
| 均值不变而方差升高/降低、重尾、相关噪声、偏斜噪声 | 检查覆盖滞后、上下侧不平衡；不能将方差变化认证为趋势反转，不能预填90%实际覆盖 |
| 公司行动式确定倍率边界、历史修订、停牌后跨日跳变 | 源算术/经济解释/历史可得分别输出；不删极值，不按事后证据重写历史可用性 |
| 坏/重复在60窗内、当前D坏/缺、无法定位异常、20/21/22/81/82段长度 | 断点不跨越，首个前序范围严格j82；D不回退，缺失不计范围内 |
| 非有限/极值/平方下溢、源价不同却float/log碰撞、低Decimal全局精度 | 精度/数值失败可见，无伪零、NaN、Infinity或静默夹平 |

确定性强验收：逐前缀批量与逐步结果一致；修改t+1以后源值不改t；**仅修改当前t且保持计算资格的有效价格，也不能改变t的预测中心/前序q/前序损失**，只能改变当前误差与超出；优先对已保存prior做同环境逐字段精确比较，数值近似容差不能掩盖从当前close减innovation倒推造成的变化。修改未来不能让历史错误变点回标。当前价变为非法值，或虽为合法Decimal却触发precision_loss，属于资格变化：可关闭公开当前结果，但内部前序数值不得被改写。图窗起点不重启状态；源版本、未知资格变化与数值前缀不变分别验。

计数守恒按来源槽保留：总槽=预测起点尚未成熟（含正常段j1…21）＋共同一步可评价＋来源/状态不可评价；按明确优先级令三类互斥，precision_loss后缀归第三类。一步可评价中又分前序窗不足/完整。正常82槽须手数为21个起点尚未成熟＋61个一步误差，后者含60个前序窗不足＋1个完整；不能直接汇总旧 `warmup` 字段漏掉j21。三个预测器使用同一共同槽集，逐损失运算失败另有计数；完整范围评价中 inside+below+above=可评价数，缺失不进分母。最终错误枚举及重叠分类须经审查冻结，不能事后使分母好看。
