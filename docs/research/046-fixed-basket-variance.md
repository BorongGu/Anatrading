# 固定股票组的下一段变化幅度对照

日期：2026-10-11。决定：停止本轮固定OAS候选，保留现有功能，不调参或更换收缩目标续赛。

## 结果先说

银行18只、白酒14只及两组半对半混合，共三个固定观察篮子，在21个前向区块上完成比较。独立高精度复核确认：OAS的平均平方误差在三篮子都高于长60区间直接方差与中心化指数加权方差。

相对长60区间直接方差，OAS误差分别高44.7%、35.3%、41.4%；相对中心化指数加权方差，分别高25.7%、31.3%、33.1%。删去任意一个区块后，这六项劣化均不变号。完整数据和数值核验通过，停止依据是未胜强简单方法。

OAS在三篮子都胜过短20区间直接方差；这个有限改善保留，不能据本次失败概括成所有收缩无效。长60区间方法在本次八列中均值最低，同样没有获得市场普遍优势或新增产品功能的资格。

## 要回答的问题

只用最近20个来源区间估计一组股票的变化幅度，多股协方差收缩能否比直接对股票组序列算方差更接近下一段观察值？这关系到用户能否依赖短窗幅度摘要做来源研究和区块核查，不涉及调仓或收益保证。

固定源close为C，定义 `r_it=ln(C_it/C_i,t−1)`。A、B各组等权；M各占一半，未按32只个数等权。`y_t=w′r_t`是数学投影，不能直接称真实持仓的log收益。相同样本上，直接y的样本方差严格等于w′Sw；建立大矩阵本身没有增加这项信息。

目标为起点o之后20个来源区间的中心化样本方差：`v=Σ(y_t−本后段均值)²/19`。每项损失为`(h−v)²`，三个篮子分别比较21块平均损失，不跨篮子合分，也不按未来v归一化。

**该目标不衡量累计下跌。** 若后段每个区间都是相同的非零变化，v仍为0；段内均值漂移则可能增大v。它衡量这段变化围绕本段均值的分散程度，不能换成累计损失、VaR或真实组合风险。

## 固定候选与七个简单对照

最近20行r逐列中心化为X，`S=X′X/19`，p=32，`T=tr(S)`、`Q=tr(S²)`、`μ=T/32`、`F=μI`。

OAS候选C：`δ=min(1,[(1−2/32)Q+T²]/[(20−2/32)(Q−T²/32)])`，`h_C=w′[(1−δ)S+δF]w`。零散布返回0。19是iid Gaussian参照下中心化20行的残差自由度，没有校正市场时间依赖。

| 对照 | 固定定义 |
|---|---|
| B1 短窗直接方差 | 最近20个y的中心化样本方差，除19 |
| B2 标量收缩 | 19/21×B1 |
| B3 仅对角 | Σw_i²S_ii |
| B4 固定半收缩 | (B1+B7)/2 |
| B5 长窗直接方差 | 最近60个y的中心化样本方差，除59 |
| B6 中心化指数加权方差 | λ=2^(−1/20)，前缀权重a_j=λ^(o−j)/Σλ^(o−k)，m=Σa_jy_j，结果为Σa_j(y_j−m)²/(1−Σa_j²) |
| B7 纯目标F | μ||w||²；A/B/M范数平方分别1/18、1/14、2/63 |

B6使用起点前完整有限前缀，与既有原始平方EWMA定义不同。全部方法只用该起点前缀；后段均值仅用于成熟目标。事前筛选要求三个篮子的平均损失分别低于全部七个对照；来源或数值不完整单列，不能与完整未胜混称。

## 来源、时点与选择局限

沿用既有银行18、白酒14的固定成员和来源版本，没有按本候选表现选股。目标边界2024-10-11至2026-10-09，共484个观测日期；32成员全部匹配保存的120来源日期并集。起点为o=60+20k，k=0…20，依次评价随后20区间，最后标签止于480；剩余三个区间不凑新样本。训练20/60区间分别需要21/61个源端点，没有跨缺失凑窗。

原始有效源跳变完整保留，没有用平滑、删点或复权处理降低幅度。复权、公司行动完整覆盖、官方日历、收盘状态与历史known_at/PIT仍未认证；日期并集不能发现全体来源同时漏掉的日子。20份旧捕获的传输证据限制与其余来源差异继续保留。

这是已看过的历史、当前成员和固定来源版本内的开发性前向检验。21个标签块虽不重叠，前一块会成为后续训练，长窗和EWMA共享历史，三篮子也相关；不能当成独立样本或全新确认集。实际误差混合了估计误差、状态变化及后段统计量噪声，未分离出潜在协方差“真误差”。

## 一手依据与最后决定

[Chen、Wiesel、Eldar、Hero：Shrinkage Algorithms for MMSE Covariance Estimation，作者稿§II–III、式(23)](https://arxiv.org/html/0907.4698v1)提供OAS公式；其iid Gaussian、整矩阵Frobenius损失结论不直接授予三个固定投影的市场优势。

[Chen、Wiesel、Hero：Robust Shrinkage Estimation of High-dimensional Covariance Matrices，作者稿§II–III](https://arxiv.org/pdf/1009.5331v1)讨论椭圆模型下的稳健形状收缩；方向归一化删除径向尺度，单凭形状不能估绝对幅度，本轮未把它加入候选。

本轮结论到此为止：停止这个固定OAS候选，保存“胜短窗、未胜强简单方法”的完整负结果；现有功能保持，不自行调整参数、分组、窗口、标签或收缩目标。用户核查效率、经济收益和产品价值均未由本次误差比较获得验证。
