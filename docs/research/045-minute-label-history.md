# 045 · 分钟来源同标签端点记录

2026-10-11；编码前决定与分层验收记录。基线 HEAD `0ae0fa1ab2f48fcdcacf5204cabc472a3b772d78`。本轮只交付现有记录详情中的有限来源检索与精确算术；独立代码复审、最终冻结自动回归及固定十份保存来源的限定兼容核查完成。后续新隔离库的进程内完整Query/历史报告→DTO→静态SSR字段链已核对；附加DB物理字节不变条件失败，两轮失败记录保留。实际socket/网络HTTP、更广来源、浏览器、Windows、用户易用性及预测/交易增量仍须分别验收。

## 研究范围与依据

实际核读本轮分钟上下文提案及独立反方端点审查全文，仓库 AGENTS、Query/Row、RecordDetails、volume_at_time、research_series、intraday_sampling、workbench 与相关合成测试。论文阅读范围继承本轮提案对 Andersen–Thyrsgaard–Todorov 2018-06-18 作者稿及 Jacod 等 2007-12-01 作者稿的记录，不新增已读篇数、不宣称复现。原文分别为 https://www.kellogg.northwestern.edu/faculty/todorov/htm/papers/tod.pdf 与 https://www.stat.uchicago.edu/~mykland/paperlinks/JLMPV.pdf 。周期模型及预平均的目标、规则采样和噪声假设不适用于本次字面端点列表的资格认证。

目标：在同一快照、同一来源周期内，用户于所选来源日期明确输入两个不同规范时钟标签 a < b，核对当天和此前最多五个来源日期的同名端点。简单基线就是六行端点原值列表。首版无计数、排名、百分位、概率、评分、模型或新研究面板；不运行十二卡人工实验。

## 公式、参数与限定

每个来源日期精确匹配 a、b，保留全部候选原始标签、规范标签、close 精确字符串、ordinal、locator 和原检查。若各端恰有一个可用正 close，r = Fraction(Cb) / Fraction(Ca) − 1；幅度为 abs(r)。Decimal 仅解析原字符串，差比使用 Fraction；显示八位小数，独立带符号 half-even 舍入，权威值为约分分子/分母。未知价格单位只在“两端共用价格尺度”的明确条件下计算，数量单位无关。

名义时钟差直接由 a、b 计算，不依赖时段模板；14:57→15:00 为 3 个标签分钟。午间两端亦可列值及名义差；不认证连续交易时长、柱数、内部路径、波动率或成交收益，不补缺标签，不按分钟归一化。

固定五来源日期规则：完整上下文按可读来源日期排序，在所选日期之前取最后五日，再匹配端点；当天排除，坏日保留，不以更早有效日替换。不足五日明示不足。可读日期但坏时钟的日期占窗；同日期不定位时钟的记录阻断该日端点唯一性。日期完全不可读且可能影响窗口时返回降级的可读日期列表，完整性未知，绝不宣称已确定此前五日期。可靠定位于窗口外的坏记录不污染窗口内结果。

上下文截至 b；若用户截止早于 b，选择无效。查询先验证显示 query_id，然后去掉 ordinal 范围读完整上下文，沿用 owner 与 20,000 行预算，预算超限明确失败，不另建 Store。端点候选保留全部重复项，响应 UTF-8 JSON 上限 2 MiB；超出返回稳定 `response_limit`，不静默截断。保留 snapshot_id、batch_id、query_id、context_query_id、raw_sha256、manifest.versions、metadata、source contract；结果身份纳入方法、日期、a/b、固定截止和五日期规则。未知日期的新行不能假定未来；可定位未来追加不能改变固定截止成员与值。不同版本身份允许变化。

## 失败条件及独立审查答复

1. 接受审查的更小任务：两明确端点无需六槽完整或人工实验先通过；删除同槽风险认证与计数。
2. 接受日期/时钟歧义闸门：日期集合未知返回 `unresolved_dates`；可读集合不足为 `insufficient`；各端缺失/重复/时钟唯一性未知逐日置空比例并保留来源，不捏造完整窗口。
3. 接受精确数值限定：缺失/非法/非正 close、close 结构失败、身份/市场/复权/价格尺度/标签明确冲突、来源隔离阻断合格比例。检查 batch 与 metadata，不能仅看端点；无关量和非 close 的 OHLC 失败不自动阻断除法。
4. 接受解释边界：未知柱边界、时区、闭合、阶段、历史首次可得时点在界面说明，可继续字面来源算术；不会升级为真实同一时段或盘中可用证据。已知标签变化须披露并阻断合格匹配，不靠 unknown 避开。
5. 接受复用边界：复用 Query/Row 与 workbench 全上下文读取；不复用非负数量格式器、CLOCKS 或网格资格，不改既有数量及分钟研究语义。
6. 接受验收范围：纯函数后立即接已有详情与请求绑定；单元/API/DTO/SSR/type/build 合成证据。此前浏览器路线被拒绝，本轮不重试或绕路；真实数据库/行情、网络/浏览器、预测与交易验证未跑。
