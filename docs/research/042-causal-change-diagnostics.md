# 042 · 因果变化诊断：哪些新观察支持重新检查旧参照

2026-10-11。原方法选择稿及最终缩减决定；以下原设计保留为未实施候选。核读 AGENTS、034、037、041及对应决定、现有单股界面；读取时 HEAD `83f9a9a8a5e5fab5fdb3c29ccfd7de0b33e1085c`。本文不改变034负结果、038暂缓或041功能；“因果”仅指使用当时前缀，不指识别经济原因。

## 1. 决定与用户能多看见什么

**唯一值得进一步设计的候选：固定旧参考＋滚动新观察的证据比较。自动变化报警、三分类和潜在趋势概率继续暂缓。** 用户问题收窄为：“近期来源变化与我沿用的旧区间有何不同；是多条观察共同支持，还是主要由少数点推动；要不要重新核对这个参照？”

操作设想：选旧参考截止A和研究截止D → 核对两段实际日期/来源步数 → 同时看位置差、各自中心化尺度和逐条支持/反例 → 点开贡献观察，决定继续使用参照或转查来源/公司行动。固定A后逐步推进D，保留每一步当时可见的结果。用户事后选A属于回顾性审查，不能当实时预警记录。

现有界面已展示斜率、EWMA波动、模型偏离和收益冲击；重画这些量、再加“异常分”没有新增信息。本候选的增量只在于**明确比较哪两段、差异由哪些原始变化支撑、后来增加了几条不同观察、相反证据是什么**。不同日期不等于统计独立；支持数量不转成置信度。若现有原价图与指标已能同样清楚、快捷地完成这项判断，就不新增功能。034未接UI的误差审计也不因本稿自动解冻。

### 先固定被监测对象

取来源变化 `r_t = log(C_t/C_(t−1))`。位置上移可表现为持续变化方向改变，却不等于价格上涨：从−2%到−1%也叫位置上移。永久价格台阶在log价上是水平变化，在r上仅是一根脉冲；固定滤波器的创新还可能带出多步尾迹。首片不能用同一“趋势变化”标签兼指三者。

仅凭OHLC不能保证分清错价、真实重估和机械表示改变：两个生成世界可给出完全相同的OHLC前缀，一个是记录污染，一个是真实成交路径；跳变当日还无法知道随后保持或回落。即使后来回落，也不能证明先前错误。没有来源修订、独立报价/成交、公司行动等额外证据时，只报告观测结构；真实风险点完整保留，不因稳健降权而删除。

### 实质不同的路线与取舍

| 路线 | 真正新增与失败条件 | 决定 |
|---|---|---|
| 固定参考＋滚动均值/中心化尺度/不同观察计数 | 小、可复算；短窗噪声大，长期旧参考会过时，均值和尺度受大点影响 | **先设计此基线**；以任务解释价值决定是否做 |
| 已知分布的似然比CUSUM | 累积弱而持续的偏离；已知前后分布、分段独立等假设下有明确误报/延迟目标[R1] | 暂不产品化；合成比较的简单累计竞争者，不拿最优性授予股票阈值 |
| 稳健分段或非参数顺序检测 | 可降低极端点影响或减少分布形状假设；仍需阈值、重复查看及参考估计处理[R2–R4] | 没有基线失效证据就不增加；非参数不等于无假设 |
| 离线分段、平滑后回标 | 帮助事后描述全段；会借未来改善定位，末端另有延迟 | 可作后见参照，不能与实时首次发现混比；037/041已有阅读不重复建设 |

## 2. 最小设计边界与足以推翻它的例子

以下是供评审的有限规格，尚未冻结：旧参考为A结束的60条r；A之后最多观察60步；近期窗最多10条r，未满10时显示实际数量与“观察仍少”。60/10仅是可检查的资源选择，未由股票或论文证明充分；编码前只定一个版本，不并行搜索窗口。

参考B固定，近期窗W_t滚动。对每窗报告均值μ和中心化均方差 `v = Σ(r−μ)²/n`，不称无偏总体方差估计；位置差为 `μ_W−μ_B`。尺度原值并列，`v_B>0`才可显示比值，零尺度不加epsilon。另列W中高于/等于/低于μ_B的不同来源变化数量及每点日期/原价/r。每点对均值差的有符号贡献 `c_i=(r_i−μ_B)/n_W`，合计恰为位置差；显示最大绝对贡献点及其余抵消项，不用最大原始幅度代替，不除以接近零的总差制造百分比。它是加法分解，不是经济因果归因。

**允许的表述：**“10条中8条高于旧平均；均值差为…；两段各自中心化幅度为…；最大绝对贡献点在…”。“持续趋势已确认”“方差状态已切换”“这点是噪声”均超出证据。当前点突出而后续尚未到达时，明确无法判断是否孤立。将来若改用中位数/MAD，须另说明对象、并列值和零值；它不会自动解决下列反例。

1. **滑窗伪持续。** 单个大跳可留在10个重叠窗口中；连续10次窗口越界仍可能只来自一条观察。持续性对照应采用不同原始r的k-of-m同侧计数，不能数窗口报警或创新尾迹。
2. **均值与尺度混杂。** `E[(r−μ旧)²]=Var(r)+(μ新−μ旧)²`。围绕旧中心的平方偏离不能直接叫波动变化；围绕近期中心也有混合期反例：`0,0,a,a`的两个稳定段内方差都为0，整窗v为a²/4。MAD同样可能被混合段抬高。
3. **滚动旧参考会忘记。** 原位置0、以后恒为δ，若旧参照也滚动W步，第k个新点对旧均值的偏移为 `δ[1−(k−1)/W]`（1≤k≤W+1）。告警消失可以只是参考追上，不能叫恢复。固定参考避免此语义混用，但过时成本须可见。
4. **误报随重复查看累积。** 仅作纸面反例：已知零中位数、独立连续对称变化下，10点中至少8点同号的单窗概率为 `2(45+10+1)/1024 = 10.94%`；它根本不是可靠告警阈值。估计旧中心、相关性和反复查看使这个数也不能直接用于股票。

**时点与成本：** 同一来源版本、固定A及固定D，追加/改动D之后数据不得改变旧输出。坏/重复/缺组不删后凑窗，不自动重置A；来源修订另立版本。新D可改变当前摘要，已经保存的旧D记录不回写。单次源载入O(N)，60步逐窗直接算约O(60×10)，无需新依赖、扫描加速或持久检测状态；具体数值与资源上限仍须实现前审查，本文未测性能。

## 3. 怎样评价、何时停；本次新增一手阅读

**当前主目标是解释任务：** 用户能否正确指出两段差别的原始支持与反例，并知道哪里不能下结论。与现有图表/波动/冲击页做同片段对照，观察错误判断、操作量和用时。首份纸面样例若只增加一排数字、不能帮助定位支持点，或诱发更多真实状态断言，停止。它没有触发规则，故不能报告检测延迟、误报率或“检测通过”。

**若负责人另行决定研究自动提醒，先冻结以下评价约定，再编码：**

- 同一固定参考和有限监控期限，比较单点越界、不同r的k-of-m滚动计数与一个固定替代分布的CUSUM；不能先引入BOCPD再找弱基线。先定“额外核读一次”的可接受频率、漏掉持续变化后可接受的等待，以及方向误标尺度变化的代价；这些是用户任务的资源选择，不能由论文代填。
- 主比较在相同的**期限内至少一次误报预算**下进行。各方法的预热等待、参考估计误差、双侧/多通道监测一并计入；不以每条股票分别达标冒充整体预算。校准与评价合成随机种子分离，每次重抽参考，冻结后不得按世界重新选阈值。ARL、单步尾概率、期限误报概率分别列出。[R1、R3、R4]
- 可知真值世界至少包括：无变化的iid与重尾；持续均值移位；纯尺度升/降；真实价格台阶；单点错价及反向恢复；缓变/短段/末端变点。另以相关、波动聚集、成串污染和均值＋尺度同变挑战假设。真值来自生成机制，混合/不可辨情形允许不分类；不能只用候选模型擅长的世界。
- 保存真实变化τ、首次触发T和任何回顾定位τ_est。T<τ计提前误报，不计负延迟；先冻结提醒/重启规则，提前误报路径不得悄悄剔除。联合报期限内检出率、漏检/右删失、已检出延迟T−τ、无变点曾误报比例及重复提醒数；不能只平均成功检出的延迟。追加未来不得修改旧触发；离线方法若使用h步未来，计入至少h步可用延迟。未触发留未触发，不移回τ_est制造零延迟。
- 简单计数与复杂法同预算下没有清楚的检出/延迟收益，或稳健化漏掉重要短段、纯尺度变化被频繁叫方向变化，就不增加复杂度。没有可接受代价时停在描述任务；完成一轮预定反例比较后交负责人决定，不自动扩窗/换股追胜。

**真实数据边界：** 独立原价15条缺口不阻止以上合成设计、算术开发、前缀检查和冻结来源的描述。复权/公司行动、日历、闭合与known_at未核时，不能认证真实经济收益、潜在趋势真值、市场误报率或实时可得性；补齐价格也不会自动提供真状态。034原30股固定Kalman一步误差败给RW的结论保持原样，本稿不换评价目标为它翻案。

## 4. 最终决定与编码前边界（2026-10-11）

独立价值审查否决新增独立042面板、60/10参考选择、贡献诊断与报警。旧参考单点污染、9正1大负、同汇总不同顺序反例说明新增数字不自动增加判断价值；034负结果、038暂缓和041边界保持原样。批准的唯一替代为现有日线固定记录详情中的“相邻来源变化”核对，目标是直接查明哪两条原价对应现有 log_return。

- 复用 SingleResearch 已校验的完整前缀 signal_report；用当前 query_id、snapshot_id、截止日期与源序号/日期绑定详情，不从分页或显示序号窗口计算。App 仅保留既有结果引用，新增请求与算法均为零。
- 展示前后实际来源日期、源序号、精确收盘字符串及现有 float64 log_return。间隔只列自然日跨度，不填空日、不除天数、不年化；交易日历/覆盖与经济收益资格保持未知。数值沿用 log(float(C_t))−log(float(C_prev))，原价字符串不转浮点展示。
- 坏/重复日期组、首条、重置和数值失败保留原理由；不能跨越坏组拼接。未载入、请求失败/失效与无法定位明确缺失；变更来源、截止或参数立即清空，旧响应不得覆盖新选择。
- 验收：合成端点精度、跨日期间隔、零变化与缺失、重复/无效/重置、截窗仍取完整前缀、身份错配与旧响应防护；SSR检查实际文案及精确字符串。重跑受影响研究与界面测试和构建。浏览器路线已被拒绝，不重试或绕过；视觉、用户效率、Windows、真实数据、性能与预测价值未验。
