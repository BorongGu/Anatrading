# 027 · 竞品研究工作流与可验证差异化

调研与资料访问：2026-10-11。状态：官方公开资料核查与产品研究提案；未完成竞品客户端同任务实测，也不构成任何信号有效性证明。本文只补充研究，不修改产品代码。

关联方案：[股票研究工作流与跨平台实施方案](../plans/2026-10-11-research-workflows.md)。既有广覆盖矩阵见 [006 国内能力](006-domestic-capabilities.md)、[007 国际能力](007-international-capabilities.md)。本文聚焦用户给定的单股日线、单股分钟、双股日线、多股日线及板块成员日线五种任务入口，不宣称穷尽所有厂商、套餐或插件。

## 1. 结论与证据等级

**下一阶段应交付从输入到研究判断的完整工作流：结构与状态 → 可确认条件 → 历史条件结果 → 反证与失效边界。** 指标数量、自然语言选股、配对计算、板块统计及回测按钮已有成熟产品，不能单独作为差异化依据。

本文明确区分：

- **文档事实**：原厂公开页面描述过的能力和限制。访问成功不代表当前客户端、账户权限、交易所数据或算法输出已经实测。
- **设计推断**：根据这些能力与本项目用户任务提出的实现顺序和差异化假设。没有资料不能推出竞品缺少某能力。
- **待验证**：套餐、具体版本、数据时点、性能、任务完成负担及样本外预测增量。本文没有安装、登录、付费、请求私人数据或下单。

“计算正确”“能完成用户任务”“有样本外决策增量”是三个独立结论。公开教程、营销绩效、单次回测以及代码测试通过均不能替代后两者的验证。

## 2. 代表产品的实际能力与边界

### 2.1 TradingView：图表、扫描与策略验证

**文档事实。** 当前 Pine Screener 可以扫描自选清单及指数成分，指数来源上限为 4,000 个标的；可以使用自编、内置和社区指标。明确限制包括每次一个指标、最近 500 根计算、最多五次 `request.*()` 调用、固定支持周期，以及不支持策略等类型。[S1]

不能沿用“Pine 只能扫描自选股”的旧判断。一个指标内部可组合多个条件，因此“每次一个指标”也不等于只能筛一个条件。

策略文档已有费用、滑点、限价成交假设及低周期细化。默认撮合会根据 OHLC 假定柱内路径；低周期明细仍受覆盖范围限制，不能恢复所有真实成交。其存在已经说明“有回测、能计成本”属于基础能力。[S2]

**设计推断。** 可争取的优势是将跨证券、板块和长窗口事件证据接到同一研究问题上，并显式给出 A 股数据与执行边界。它必须通过同任务操作与结果比较验证，不能写成 TradingView 无法编程实现。

### 2.2 AmiBroker：可定制探索与滚动样本外

**文档事实。** Exploration 提供自定义条件、数值列、历史多次命中、CSV 导出和多证券关系散点；文档包含 MAE/MFE 与收益关系的用途。自动 Walk-forward 提供训练段优化、后续样本外验证、滚动或锚定区间。[S3][S4]

**设计推断。** 可解释筛选、关系图和滚动样本外均应视作成熟基线。Anatrading 的候选优势是减少编程、参数组装和跨页面操作，将失败案例与证据不足作为默认输出。不能声称事件报告或样本外检验本身是新功能。

### 2.3 QuantConnect：从统计假设到算法

**文档事实。** 官方 PCA 与配对研究教程展示收益序列、PCA、对数价格协整检验、价差及平稳性检验，再转入算法。[S5]

**边界。** 教程展示方法和研究流程；其示例资产、研究窗口及交易环境不能直接迁移为 A 股有效性证据。高收益相关不能推出协整，某个窗口通过检验不能保证关系持续。

**设计推断。** 适合借鉴假设、诊断、验证的顺序。本地导出数据、清楚的失效条件、无需先写策略代码的使用流程，以及 A 股可交易性处理才是本项目应验证的具体价值。

### 2.4 通达信：公式、跨股与板块统计

**文档事实。** 官方函数已包括跨证券指标 `CALCSTOCKINDEX`、板块横向统计 `HORCALC/INSUM`、涨跌家数及跨周期引用。`REFX/BACKSET/ZIG` 等明确标注为未来函数，跨周期引用也提示可能使用未来数据。`COST/WINNER` 是限定日线的成本分布函数，其说明未完整公开内部估计过程。[S6]

**边界。** 函数可自编或调用，不代表所有底层函数透明；文档中的“获利盘”描述不构成对真实持仓分布的观测。公式端量的单位不能直接套用到本地 SDK 或其他数据品类。跨股/板块计算不是空白市场。

**设计推断。** 可争取每个结构同时显示发生、确认及失效时间，并把当前状态接入相同定义的历史事件样本。相关优势需要与固定版本、公式、输入和预热范围的实际任务比较。

### 2.5 同花顺、东方财富与 Choice：筛选和多源信息已成熟

**文档事实。** 同花顺官方产品说明已有技术面、基本面、消息面自然语言选股及监控提醒。自然语言入口本身不构成差异化。[S7]

东方财富帮助描述多条件筛选、自编公式、基本面与技术面叠加以及 L2 资金类功能。L2 指标对数据的要求不能用普通 K 线替代；营销描述不能作为辨认投资者身份或真实意图的证据。[S8]

Choice 帮助描述条件表达式、指标计算、统计、历史序列、板块范围和模板导出。财务历史报告期序列不自动等于相应历史日期当时已知的财务版本。[S9]

**边界。** 这些页面含旧版资料或未标发布日期。本文不保证当前套餐、字段权限、模型算法和历史版本完整性；也未验证它们是否已经提供本文提出的完整工作流。

**设计推断。** 应将条件出现后的效应大小、失败范围和可复算性作为同任务比较内容，不能只比较界面上的条件数量。

### 2.6 聚宽：保留访问限制和待核项

**实际观测。** 本轮官方 API 主站返回“非中国大陆地区暂不支持访问”。搜索索引中的历史官方资料可作为后续 API 核查线索，不能升级为当前版本和套餐的核验结果。未绕过地区限制。[S10]

当前 API、历史成员、停牌处理、复权与历史可得性均保留待核，不因本轮无法访问而判定产品不具备这些能力。

## 3. 数据能支持哪些研究结论

以下是输入可识别性和实现设计边界，不是对任何供应商专有算法的等价复现声明。

| 输入 | 可以直接研究 | 额外要求与不能据此推出的内容 |
|---|---|---|
| 单股日线 OHLC | 价格结构、趋势/区间、回撤、波动、缺口、突破及失败、后续价格变化 | 不明复权和公司行动会混入机械跳变；未知日历时只能称来源记录步，不能承诺交易日跨度 |
| 同口径日线/分钟 OHLCV | 相对量、量价响应、量能收缩/扩张、同时间槽量能 | 量价状态不等于主动资金、吸筹、出货或交易者身份 |
| 金额与同口径数量 | 区间成交均价、跨区间累计/锚定均价 | 单位与经济含义必须成立；仅用典型价格乘量属于近似计算，不能冒充真实成交均价 |
| 双股/多股日线 | 相对强弱、共同日期区间收益相关、beta、条件排名、横截面离散度 | 停牌/缺日不可用填充制造同步性；价格拟合残差不自动是协整或可套利价差 |
| 明确成员的板块样本日线 | 样本广度、等权表现、领涨持续性、扩散与集中 | 今日成员回看过去存在选择偏差；历史成员和市值权重分别需额外数据 |
| 流通股本/权重的时点版本 | 换手率、市值加权统计 | 最新股本/权重不能无条件回填历史 |
| 逐笔成交、报价或订单事件 | 对应粒度的价位成交分布、方向分类、盘口/撤单研究 | 每种分析另需匹配字段和分类契约；OHLCV 无法唯一还原这些信息 |
| 公告、财报、新闻及发布时间 | 财务质量、估值、事件前后研究、消息催化线索 | 报告期、正文日期与首次可得时间分别核验；量价本身不能确定“为什么上涨” |

## 4. 优先级矩阵

P0/P1/P2 表示产品研究顺序，不代表已经获准编码或获得有效性结论。具体第一轮范围以关联方案的评审决定为准。

| 优先级/研究功能 | 用户输入与问题 | 主要输出 | 可量化验收/比较指标 | 额外数据需求 |
|---|---|---|---|---|
| P0 单股结构与失效 | 单股日线：当前趋势、区间或突破如何确认和失效？ | 状态、关键位置、确认延迟、失效条件与反证 | 手算一致性；历史确认结果前缀不变；错误分类/不可计算计数；完成任务时间 | 闭合与 OHLC 语义；交易日解释另需日历；量能确认另需合格数量 |
| P0 条件事件研究 | 信号及日线：条件出现后结果有何改变？ | 命中、成熟/无效计数、后续变化分布、基线、失败样本 | 均值/中位数/分位数；有效样本数；条件减基线的效应量；测试段结果；重叠与切点隔离 | 超额比较需基准；可成交策略评价另需执行规则、成本和公司行动 |
| P0 分钟节奏与日线联动 | 单股分钟及日线：动作是否异常，日线条件何时确认/否定？ | 同时间槽相对量、开盘区间、量价响应、日线/分钟时间线 | 历史基线无当日未来量；闭合时点一致；相对固定时点观察的增量 | 时段/闭合语义；真实均价另需合格金额与量 |
| P1 双股关系诊断 | 两股日线：相对领先是否持续，原关系是否破裂？ | 相对强弱、收益相关、beta、过去窗口拟合残差偏离 | 对齐遗漏数；有效配对数；无关系/共趋势/突变反例；样本外增量 | 同口径价格；协整与结构变化检验需独立研究合同；交易另需借券等条件 |
| P1 多股比较 | 多股日线：哪些更强、波动更小，是否重复暴露？ | 分项排名、排名变化、相关聚类与入选原因 | 排名复算；有效/缺失覆盖；后续 Rank IC、分组差异、换手与成本敏感性 | 全市场结论需时点证券池；组合风险需明确权重 |
| P1 板块扩散 | 板块成员日线：多数确认还是少数拉动？ | 广度、等权表现、离散度、领涨集中与持续性 | 分母复算；成员覆盖率；加入板块确认前后的消融与样本外差异 | 历史成员；市值加权另需当时权重 |
| P2 交易情景与风险 | 日线/分钟及可选持仓：触发、失效与不利变化如何对应风险？ | 可编辑条件情景、历史不利变化、组合边际暴露 | 约束前后差异；跳空/柱内路径不确定计数；预算计算一致性 | 精确仓位需用户预算/持仓；成交评价需费用、规则、流动性与公司行动 |

## 5. 每项研究的最小合同与失败条件

### 5.1 单股结构：先定义事实，再评价价值

优先少量精确定义的规则，如此前窗口高点突破、收盘重回区间和已确认摆动点。趋势估计应与简单 EMA 等基线并列；Kalman 等模型名称不赋予额外预测资格。发生日期、当时可确认日期以及失效条件必须分开。

验收至少包括上涨、下跌、区间、跳空及失败突破；必须有手算或独立参考实现。改变未来输入不能改变过去已经确认的结果。不能把“形态成立”直接映射为未经校准的买入概率。

### 5.2 条件事件研究：让负结果成为正常输出

固定事件、窗口、去重与分区，再计算后续 1/5/10/20 个来源记录步的价格变化；没有合格日历时不得称交易日收益。未成熟标签不参与数值统计，不能依据后来成败决定历史事件是否入样。

首版可以只做描述性分布，不给独立样本置信区间。扩展统计推断时，必须处理同证券事件重叠、同日横截面相关性、多个试验及跨训练/测试边界的标签。市场/行业匹配基线属于独立扩展；仅有全日期基线时不能称已控制全部市场状态。

效应接近零、样本少或测试段反转都应完整显示。未证明增量时输出“暂无证据”，研究模块依然可以通过计算与任务验收。

### 5.3 分钟量价：控制时段、锚点和日线泄漏

同时间槽量能只能使用之前交易日的可用历史。上午研究不能引用当天最终日线高低收、总量或完整当日均价。午休、集合竞价、部分柱与缺失时段必须显式处理。

锚定均价须同时记录锚点和选择锚点的可知时间，不能回看未来后挑选漂亮锚点再声称当时可执行。缺金额时可以提供显式命名的价格加权近似，或暂时关闭该结果。

### 5.4 双股：分开比较、偏离和均值回归假设

收益相关使用两侧相同起止日期的收益区间；价格协整是另一假设。过去窗口回归用于当前偏离时，不得让当前观测进入拟合窗口。

必须测试无关系、共趋势但不协整、近零残差尺度、零方差、缺失/重复日期及结构突变。第一轮关联方案只提供相关、beta、相对强弱与偏离，不输出协整、均值回归或套利结论。没有对应资格及借券/执行数据，不把统计双边头寸写成可执行承诺。

### 5.5 多股与板块：范围和分母也是结论的一部分

所有标的绑定同一截止日期；缺当日价不能回退成各自最后可用日再混合排名。所选数量、可计算数量、遗漏数量及各指标分母同时报告。

原始分项优于未验证的混合神秘分数。仅有几只用户选择的股票时，结论限制为所选样本。板块名称须由用户明确提供，不能从相似走势自动认定行业身份。今日成员的历史回顾必须常驻显示选择偏差限制。

### 5.6 情景与风险：不把描述性标签伪装成成交收益

跳空可能越过失效价；同根 OHLC 同时触碰两个条件无法唯一确定先后。结果必须返回路径不确定或有依据的保守区间。账户仓位、风险预算和可交易规则缺失时，只提供研究情景。

MAE/MFE 等描述性路径统计与止损/止盈模拟分开。成本仅在定义好交易决策、委托时点和执行模型后进入策略评价，不能对收盘到收盘标签随意扣费后称净策略收益。

## 6. 与现有方案对齐的实际首批切片

已有价格通道、ATR、量能、路径效率、确认拐点、分钟聚合及当前池筛选等基础，具体基线以关联方案的实际审计为准。本轮不重复发明同类指标，也不因尚未有全市场主数据而无限推迟合格输入上的描述性研究。

1. **单股日线判断与事件闭环。** 复用合格来源记录和已确认结构；按研究合同加入趋势/波动估计并显示简单基线；固定此前 N 根最高价突破，展示当前条件、所有历史命中、成熟后续变化、全部有效日期基线与失败样本。第一轮无参数搜索、无成交收益承诺；显式给定时间切点才使用测试段/样本外措辞。
2. **双股比较闭环。** 两份日线按明确共同日期对齐，展示相对强弱、共同区间收益相关与 beta、过去窗口拟合的价格残差偏离；同步展示遗漏数和退化原因。协整与均值回归留待后续独立方法研究。
3. **多股与板块样本闭环。** 从已导入、身份明确的不同证券版本中选择有界集合，使用同一截止日期，给出动量/波动/回撤分项和有效覆盖。板块先复用同一集合流程，明确标为所选板块样本，不生成虚假的历史行业指数。
4. **分钟联动闭环。** 第一轮改善既有分钟分析入口；后续将日线候选事件和分钟确认放在同一截止时点，逐项补齐时段、金额和量能合同。暂不新增分钟 Kalman，避免用未经独立研究的模型扩大范围。

这些切片对应现有 F05/F06/F09/F11/F12，并逐步进入 F13/F14。它们不要求新增通用指标插件平台、任务队列或复杂缓存架构。必要的查询与响应优化应服务实际研究任务，不能替代业务输出。

## 7. 怎样证明差异化，而非仅声明优势

### 7.1 同数据同任务基准

冻结产品版本、可用权限、源文件、周期、调整口径、时间截止和公开计算定义；无法取得相同数据时单独说明不能归因于算法的差异。选择实际任务，而非功能名称计数：

- 找出一个日线突破，说明确认及失效条件，并列出历史相同定义事件。
- 比较事件后续变化和基线，查到至少一个失败样本及未成熟事件。
- 比较两股并解释缺失对齐、相关性与偏离的区别。
- 比较指定股票集合，检查是否混入不同日期或重复证券。
- 解释一个所选板块样本上涨时的广度、集中度及覆盖限制。

记录用户完成率、首次正确完成耗时、交互步骤、需要编写/修改的代码量、数值一致性、所需解释字段覆盖率，以及结论误读。测试输入、预期问题和评分规则应预先固定；本文不预填获胜结果。

### 7.2 预测增量另立验证

固定训练、验证、最终测试区间和证券范围；保留全部尝试；报告条件效应、排名信息、消融、成本敏感性与失败市场状态。校准概率时另检查可靠性和适当评分；首版描述性分析不输出此类概率。

预先明确对用户有意义的效应与所需样本量，不以单一显著性阈值或最好的一段收益判定通过。比较应包含简单基线，必要时控制市场/行业共同变化。没有达到研究证据门槛就保留“未证明增量”，不把功能可用写成收益优势。

### 7.3 工程验收与研究验收分开

前缀不变性、手算、错误输入、响应体积和运行耗时用于工程验收；真实软件导出兼容需要用户提供或有权使用的真实样本。合成数据只证明边界行为。研究准确性、实用性和预测增量分别记录，沿用关联方案的规模限制及测试计划。
