## 1. 问题、阅读与范围修正

问题限定为六种指定生成机制、有限前窗秩、固定线性预测及两块留出损失：连续位置交互是否值得保留，简单二分、价格遗漏和来源尺度代理能否阻止误晋级。平滑正例天然有利于连续形状，故单格恢复不够；真实机制使用不可见潜在分位，拟合只见20点经验秩。结果不代表一般条件分布检验。

本项研究实际阅读以下作者原件的指定部分；本公开记录依据该次阅读与后续协议、实现审查、运行及独立审计整理，文档整理阶段没有重新通读论文：

## 2. 隔离的纯输入约定

研究名称 `raw-source-quantity-rank-research-v0`。纯计算只接显式冻结数组，不读文件/Store/数据库、不联网、不持久化；本次调用方只生成合成输入。真实输入读取需另定范围及独立复审。

每序列固定数据集/版本、证券/序列、来源/格式/格式版本；记录含来源日期、整数位置、唯一ID、字段路径、原数量与收盘token、字段状态及实际取得时间（可未知）。顺序与声明位置一致；缺口留占位，不排序、去重或跨身份混窗；重复ID/日期/位置按歧义处理，混合身份整体失败。只需收盘，不编造OHLC；实时累计快照不能替代历史位置。

- ASCII十进制字符串，最多64字节、整数部分最多31位、小数最多18位；数量 `0≤X≤10^30`、价格 `0<C≤10^30`。拒绝符号、空白、指数、逗号、非有限和非ASCII数字，保留前导零与原拼写。missing、invalid_syntax、out_of_budget、ambiguous_position、valid_zero分别记录。
- 用整数系数/10的幂精确表示与交叉相乘比较；`1`、`1.0`、`01.00`数值相等。前20位置 `t−20…t−1` 中位数是排序后第10/11值的精确平均；`b_t=1[X_t>m_t]`；`q_t=(2L+E)/40`，L/E分别为严格较小/相等数，保留整数分子。零中位数合法，不加epsilon、不计算量比。
- 当前或前窗任一数量坏值使该特征失败，不向前凑20条。数量坏位置k影响k…k+20；删除已有价格C_k影响回报k/k+1、标签k−1/k及本价格特征k…k+21。单独延后下一标签可见性不改变当期特征。追加未来不改旧特征。
- `r_t=(C_t−C_(t−1))/C_(t−1)`先精确成有理数，仅统计边界正确舍入至binary64；原token不覆盖。`y_t=r_(t+1)`在下一位置成熟，不跳过缺价。共同队列及价格单独队列均须每块4096行，任一计划内排除使实验INVALID。
- 最后位置12417只供价格标签，数量null、`not_generated_terminal`，不进入决策或此前数量窗口。C0保留原token `100`；其余生成价格固定12位。紧凑系数、固定生成规则及共享清单可无损恢复本次合成token/成员；真实不同词法不能用数值重建替代原文。

单位、覆盖、股份基础、调整、闭合、日历、历史可得性各自保留unknown。q仅称所保存源数量的前窗相对位置，不命名为活动度，不纳入金额、A/V、换手、VWAP、去噪或交易建议。

## 3. 冻结生成与模型

6格×8重复，共48路径。c=0…5，j=0…7；两个PCG64流分别seed `202610130000+1000c+j`、`202610230000+1000c+j`，各仅一次生成12417个int64整数J/K，区间[0,10000)，无补抽。`u=(J+0.5)/10000`，`e=.01√3·[2(K+.5)/10000−1]`。t=0…12416；C0=100、r0=0，预热负下标回报为0。

`p_t=min(1,mean(|r_(t−4)|,…,|r_t|)/.02)`，`h=2p−1`；`a_t=(.12r_t+d_t r_t)+e_t`。按C_t→r_t→p/特征→a→C_(t+1)顺序生成；将binary64 a的十进制字符串转精确有理数，乘C_t(1+a)，最近偶数量化至12位小数；后续反馈重新由源token求实际r。数量流的未来值不进入特征。

| c | 机制 | d及源数量X |
|---|---|---|
| 0 | 强阶跃 | `.70(2·1[u>.5]−1)`；X=1000+J |
| 1 | 强平滑 | `.70 sin(π(u−.5))`；X=1000+J |
| 2 | 弱平滑 | `.15 sin(π(u−.5))`；X=1000+J |
| 3 | 独立零增量 | d=0；X=1000+J |
| 4 | 价格历史代理 | d=.70h；X=1000+floor(10000p) |
| 5 | 尺度/制度代理 | s=floor(t/13) mod 2，d=.70(2s−1)；V=1000+J，t<8321时X=V·100^s，其后X=V·100^(1−s) |

价格代理主基线已含h/h·r；制度格只翻转源倍率映射，潜在量和价格制度不改。周期13避免必然b=s的结构性退化，但不保证实际满秩。正弦使用标准库math.pi/sin，浮点归约与操作顺序绑定执行构建，不保证跨平台逐位相同。

预热t=0…127；训练128…4223（4096）；4224只作标签成熟间隔；H1=4225…8320、H2=8321…12416，各4096行。最后训练标签先于首留出决策成熟；此后不重拟合。H1/H2相邻且有依赖，不能称独立样本。当前价格/数量同时可见只是假设。

- Z恒预测0；Bp列为 `1,r_t,|r_t|,mean(|r_(t−20)|…|r_(t−1)|),h_t,h_t r_t`。
- Bm在Bp后加b、b·r；Bq加q、q·r。无时间号、原量水平、制度、全样本标准化或特征选择。
- 非截距列仅用训练均值及ddof=0标准差；OLS固定NumPy lstsq、rcond=1e−12。零/非有限尺度、秩不足、非有限数或标准化矩阵奇异值比>10^8均INVALID；无删列、ridge或修复后假装成功。
- c4额外比较删掉h/h·r的弱Bp与其Bq；c5额外比较Bp加z/z·r（z=2s−1）及其Bm/Bq。这些为机制审计，已知制度不是真实可用预测器。共184次OLS，Z/尺度变换不拟合。
- 主损失MAE、保护损失MSE；各块与固定4个1024行子块全报，保存逐点绝对/平方损失及可重建的全部配对差。`g(A,B,H)=1−MAE_A/MAE_B`，零分母INVALID，不按子块挑赢家。

## 4. 数据前晋级规则及修订

E(A)：H1/H2各自相对Bp和Z的MAE改善≥2%，两块MSE均不高于Bp和Z，且8个子块中至少6个MAE严格优于Bp。

Q：E(Bq)，且每块相对Bm的MAE改善≥0.5%、MSE不高于Bm。S：E(Bm)，且每块相对Bq的MAE改善≥0.5%、MSE不高于Bq。2%、0.5%及计数是资源选择门槛，未校准为显著性、覆盖或总体误报率。

六项须同时满足：

1. c1的Q≥6/8。
2. c0的E(Bm)≥6/8且Q≤1/8；S全量描述。
3. c2的Q≤2/8。
4. c3、c4各自E(Bm)或E(Bq)并集≤1/8，且Q≤1/8；c4只用完整控制判定。
5. c5至少6/8路径有同一候选Bm或Bq在H1相对Bp改善≥2%、H2恶化≥2%；不能跨候选拼接。Q必须0/8；加制度控制后，Bm/Bq相对制度价格基线两块均改善≥2%的并集≤1/8。
6. 全部合同、尺度、数值、资源与输出完整性检查通过。

**原阶跃门槛要求S≥6/8，已在任何研究随机数/结果产生前改为E(Bm)≥6/8，Q上限不变。** 独立解析参照中，20点经验中位二分/连续秩对潜在阶跃的解释方差约0.69255/0.68182，差距很小，不能据植入阶跃要求二分必然达到0.5% MAE胜差。此参照使用uniform-iid替代条件，不能冒充实际反馈DGP结果。修订与理由在最终冻结协议中记录；种子、强度、窗口、样本与其他门槛未变。实际S=4/8，**若沿原门槛会STOP**，不能隐去这条反事实。
