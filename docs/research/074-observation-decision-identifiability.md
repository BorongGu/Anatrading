## 1. 自评、优先问题与当前决定

近期工程改善了历史描述和报告可靠性，尚未补成金融增量。接下来最先要回答的问题是：**对一个明确决策，现有观测是否足以确定相关目标；增加的信息能否改变简单基线给出的行动？** 先声明目标、信息截止、可选行动、损失及最小有用改善，再选方法。源记录下一次变化与可执行价格变化须分别定义；当前没有理由替用户发明交易目标。

本轮实际完成两项理论判断：收盘共变中确有无法恢复的分项，但该分项未必影响所选损失；即使记录领先相关恰为1，也可能没有执行时仍可用的信息。这使“数据缺什么”进一步收窄为“缺失内容是否影响本次判断”。

优先顺序：

1. **决策门槛先行。** 若只研究固定收盘二次风险，保留总收盘协方差；若只核查两段源价变化，复用023；若只描述共同变化，复用036/043/051。已有结果能回答时停止新候选。
2. **需要预测时，再过时点与目标门槛。** 仅对一个预选配对、一个连续时段跨度，明确是源记录预测还是可执行变化。先检验观测/可得/执行时点及价格含义是否足以区分相关机制，暂不估计领先参数。
3. **只有前两项通过，才考虑一次独立评价。** 候选、强简单基线、损失、最小改善、缺失与重叠处理及真正未触碰的合格时序样本共同冻结，并另行审查。本文不启动取数或评价。

当前没有已建立的额外分时风险决策，也没有合格的未触碰预测证据，故两条路线均 **NO-BUILD**。独立理论比较已经给出下文边界；此时再造一个玩具世界、换指标或重写协议不会增加决策证据。停止这些候选，等待能改变门槛的新决策或资料；该停止不扩大成整个项目或所有方法无效。

## 2. 新结论一：缺失分项与决策充分性不同

对同一来源、相同有效日期支持及共同中心化/分母，令

```
g_i = log(O_i / C_i,previous)
s_i = log(C_i / O_i)
r_i = g_i + s_i
Cov(r_A,r_B) = Cov(g_A,g_B) + Cov(g_A,s_B)
             + Cov(s_A,g_B) + Cov(s_A,s_B)
```

两个交叉项不可省略。取任意非常量有限序列z，使两资产r均为z：世界I为g_A=g_B=z、s_A=s_B=0；世界II为g_A=z、s_A=0、g_B=−z、s_B=2z。两者收盘序列可以完全相同，开盘段共变却为Var(z)与−Var(z)。逐段指数化可构造正价，H/L可包住各自端点。这个见证只要求**收盘观测相同**，不声称两世界OHLC相同，也不证明真实市场存在这类结构。

但固定数学暴露w、仅以 `Var(w′r)=w′Cov(r)w` 为损失对象时，总收盘协方差已经充分确定这一实现量。四项分解不能改善该同一量；该结论不外推至尾部损失、未来风险预测或可交易组合财富。若真实任务分别约束开盘段/盘中段，才需要相关分项及交叉项。

日线O只能支持来源端点分解；异步开盘不认证同步组合风险。开盘错价u会把g推高u、s压低u，而r不变，恰可伪造抵消结构。源O不等于论文的早盘VWAP或报价中点，价格尺度、公司行动、覆盖与端点时间仍需独立核验。

**相对既有研究的增量：** 023已说明单股开盘/实体分解和VWAP不可恢复；043已否决无任务增量的PCA。本节新增双股四项恒等式及“不能恢复分项，却足以回答特定损失”的严格限制，没有重开023入口或PCA。

## 3. 新结论二：记录领先不识别可执行领先

取独立同分布、非退化、均值0的 `ε_t∈[−a,a]`，0<a<1；M_0>0，`M_t=M_(t−1)(1+ε_t)`。M为正鞅，信息集为 `F_t=σ(ε_1,…,ε_t)`。两个世界都报告 `A_t=M_t, B_t=M_(t−1)`：

- **D，观测延迟：** 两资产当前可执行价均为M_t；B记录已旧一期，但供给标签未揭示年龄。
- **L，价格延迟：** 当前可执行A为M_t、B为M_(t−1)，B记录及时。

完整报告路径及其任意确定性OHLC聚合相同；报告简单变化满足 `r^A_t=r^B_(t+1)=ε_t`，总体相关恰为1，对数变化也逐项相等。任何只使用这些报告的检验，在D/L下分布相同，无法一致区分二者。

然而在F_t已知时，D下一期可执行B简单变化的条件均值为0，L为已知ε_t。若L中的信号冻结在t，入场推迟至t+1、出场至t+2，结果变成ε_(t+1)，在t的条件均值又为0。历史相关仍为1；在t+1更新信号属于另一项实验，不能替换原冻结信号。

这是未知观测年龄/执行语义下的构造性边界。准确事件时间可排除这个特定旧数据解释，但最后一笔成交仍不保证信号收到后有该买卖报价。L刻意采用理想延迟价格，若无成本且可自由买卖/做空会有一步套利；它不是无套利市场模型，不能据此宣称市场机会。使用乘法鞅避免把零均值log变化错误当作零均值简单变化。

**相对既有研究的增量：** 037§11已有HY、前值填充表观滞后和同OHLC不同柱内关系；072已有同观测不同潜在机制。本节新增“相同记录、不同可执行目标”的证明，以及固定信号被延迟耗尽的结论。没有发现真实领先，也没有再次执行037反例。

## 4. 实质不同的方法比较：何时值得继续

- **实现风险测量：** 双尺度/realized kernels针对给定噪声模型下的同期间潜在积分方差；028同覆盖1m/5m RV已能做来源网格敏感性核查。分钟采样本身未被论文禁止，但任意vendor OHLC不自动合格。更低估计、两法一致都不能认证去噪，也未证明下一期风险预测增量。保留简单RV；未来风险目标还须对比持久性、长窗和EWMA。
- **共同成分解释：** Bai的共同成分与旋转不唯一的因子不同；大面板、强因素及时间不变载荷等假设不能给有限选股面板自动冠上行业/市场经济含义。先用直接同伴、036固定映射及043双组OLS，已有充分答案时不升级潜在因子。
- **变化/不确定性检测：** BOCPD的段内iid、似然和hazard与有界适应序列的时间一致推断是不同承诺。后者可约束平均条件期望，不能据边际超限率推出条件超限率；同一个随机Z每天重复即为反例。重叠窗口也会把一件事数成多次报警。没有容忍误差/核查成本时保留原始成熟计数，不重开042报警面板；若目标成立，复杂法须在相同全监控误报预算下比较漏检/延迟。
- **领先估计：** 固定同支持的滞后相关描述源记录关系；HY估积分协变差，shifted-HY在另有条件的模型中估时间移位，三者不能当同一评分排名。无延迟信息的观测模型须保留共同冲击及不同观测时间、陈旧值/时钟误差；独立打乱两资产会删去所需零假设。仅由同批bars校准的模型仍只是敏感性分析，拒绝一种模型不排除所有观测机制。

不依赖合格行情仍有价值的是**目标与假设的独立理论比较**：检查简单方法是否已经充分、两机制是否观测等价、追加哪种证据才打破等价。本轮已完成这两项及数学复核。尚无新的实际损失/行动要求，不能把“继续研究”写成又一次相同证明或先上复杂模型；出现新的明确决策后，才有对应的下一次独立比较。

## 5. 什么证据能改变 NO-BUILD

**可证伪目标：** 对事先声明的决策，新增信息应允许与现有基线不同且更低损失的行动。若目标在所有与当前观测相容的机制中已相同，或既有输出足够，候选失败；若目标不同但无法核验新增信息，资格失败。通过可识别性只允许下一步评价，不等于预测有效。

最低可观察证据按目标区分：

- **分时来源风险：** 先有确实依赖分项且现有023/036/043不能回答的决策；再有同一预选配对/固定小组的前收/O/C、共同支持、价格/调整含义及不可变版本。同步风险另需同步端点证据。日线OHLC足以做源O分解，不能换成VWAP/报价分界；单个日期不够估协方差。
- **源记录预测：** 核验 `event_time`、`interval_end`、`available_at`及修订版本；输入必须在决策d前已可得，未来目标在成熟后可靠重建。具名观测流、无成交/旧值/缺失区分、时钟误差和竞价/午休/停牌边界必须对应所选跨度。时间误差与所称lag同量级时不能忽略。
- **可执行目标：** 在上述基础上增加 `executable_at`、买卖报价、可执行数量、适用成本/约束和可辩护延迟；逐笔成交本身不够。需能区分观测延迟与相关执行延迟，目标从可行入场起算。入场已晚于信息被吸收时，该固定信号失败。

任何经验晋级还需真正未触碰的时序段，长度由冻结损失的精度/功效目标决定；一条合格记录仅核查格式，不证明持续性。源预测对比零变化/持久性、目标自身历史、共同信息/测量对照；交易目标另含不行动与相同约束基线及成本。评价同一批合格决策的配对损失，保留弃权、缺失、共享冲击和重叠依赖，禁止选最优pair/lag/延迟事后救回结果。

上述证据当前未建立。034固定Kalman、035 ER、046 OAS、047三邻居读数及058数量秩的原STOP保持，均不扩大为全部同类方法无效。复用历史不能改名为独立确认样本；实采/旧历史NO-GO保持，不新取数、读旧库/原始捕获或重试已受阻浏览器。
