## 可选复现（尚未在本次归档执行）

为保存本目录原件，先把整个目录复制到临时位置，再在副本执行：

```sh

```

两个脚本无仓库导入、网络或额外依赖。文件位置由脚本所在目录解析；输入在脚本和协议中完整给出。标签脚本是限定合成检查，未作为产品API，不认证任意调用参数、一般解析器或来源资格；平滑脚本仅为两世界构造反例。
