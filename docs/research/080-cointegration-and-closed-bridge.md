## 1. 完整闭桥的负斜率是机械性质

含截距OLS的W个训练收益残差e_t满足sum(e_t)=0。令C_0=0、C_t=sum(e_s,s=1..t)，则C_W=0。取完整W个转移，拟合含截距的 `ΔC_t=k+λ C_(t−1)+η_t`，t=1,…,W。设D为滞后累计值C_0,…,C_(W−1)的中心平方和，残差非零时D>0。由平方差恒等式：

```
C_t²−C_(t−1)² = 2 C_(t−1)ΔC_t + (ΔC_t)²
sum C_(t−1)ΔC_t = −sum e_t²/2
λ_hat = −sum e_t²/(2D) < 0
```

这一负号不需要真实均值回复或未来反馈。全零残差使D=0、回归未定义；有限精度只近似闭桥，不能忽略容差和退化。W≥2只是代数条件，实际收益OLS还需足够自由度产生非零残差。

完整闭桥的前后累计列互为循环移位，中心平方和都为D。Cauchy–Schwarz给sum(e²)≤4D，所以AR系数ρ=1+λ满足−1≤ρ<1，**不保证0<ρ<1**；即使为正，也不能据机械闭桥认证真实OU或未来稳定。独审纠正了讨论中“完整设定ρ可能低于−1”的过宽说法，最终采用上述范围。

必须包含C_0→C_1与C_(W−1)→C_W的全部W转移。丢首行、加滞后或换索引时恒等不直接适用。独审实际核对Avellaneda–Lee附录：X_1…X_60的AR回归使用n=1…59，舍去X_0→X_1；不能把本定理直接套到其59转移估计量，更不能据此否定论文全部结果。双方均未核其代码。

最简单的独立创新世界也会出现训练闭桥：r_t=μ+ε_t，ε独立同分布、零均值、非零有限方差。冻结训练均值后，下一期残差条件均值为−训练ε均值，未由前一累计偏离产生恢复力；用已知μ则未来创新条件均值为0。训练投影不能充当未来回归证据。

## 2. 真协整也不保证差分回归估得协整向量

总体反例（推导，未运行模拟）：e_t、v_t为互相独立的iid零均值过程，方差s_e²、s_v²均正且有限。令x_t=x_(t−1)+e_t+v_t，y_t=βx_t+e_t，β≠0。x、y为I(1)，y−βx=e为I(0)，但差分OLS总体斜率为：

```
b_Δ = β + s_e²/(s_e²+s_v²) ≠ β
```

用b_Δ累积差分残差仍含非零随机趋势。收益回归与水平协整回答不同问题；收益因子反转可以继续作为待检验规则，却不能凭训练残差图取得协整资格。

log价格增量的累计残差为 `logP_t−logP_0−t a_hat−b_hat(logQ_t−logQ_0)`；收益截距累积为时间趋势，不能直接当水平回归常数。简单收益和没有此log恒等，也不同于复合收益；077的LOO收益因子并非天然可交易的固定股数价格水平。

