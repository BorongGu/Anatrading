## 4. 对研究与实施顺序的含义

1. **先复现可识别的任务。** DC01/04/05 的公开公式和批量结果可在真实 K 线合格后对账；DC07 的历史账本、DC10 的成本敏感性可为既定 F13/F14 提供方法参照。图形/数值相同、操作时间缩短、预测增量、成本后价值分别出结论。
2. **L2 类指标不能由低频柱唯一还原。** DC02/08/09 依赖订单/成交关联与专有分类；普通成交量或价格涨跌只能产生明确标注的代理。若只有品牌指标导出，可验证兼容与稳定性，无法证明捕获了某类投资者真实持仓或行为。
3. **时间问题至少分三种。** 已完成历史值受未来数据改变；当前未闭合柱持续变化；供应商修订/复权锚点变化。前者需因果审计，后两者需闭合状态与新快照记录。固定输入快照、事件版本与锚点后才进行前缀不变性检查。黑盒历史输出没有日志时不能断言“不重绘”。
4. **平台回测按钮不能代替本项目验收。** Choice 的自由历史交易、文华的期货主连链、QMT 的回调时序、PTrade 的底仓回转各有不同输入/执行假设。复权收益、现金分红、配股、股数、费用须按同一账本解释；同一根柱的最高/最低顺序不由 OHLC 唯一确定。
5. **自动化出口按具体产品决定。** 已有明确入口的是 TQ、iFinD、Wind Client API、Choice API、QMT；权限和真实数据质量仍逐项验收。普通同花顺、东方财富、大智慧、博易的外部接入未知处继续保留；不能以对外 API 缺证据否定其本地导出，也不能用网页版私有请求替代授权闭环。

通用实测记录须包括：产品全名/版本/券商封装、插件/API 版本、账号权限类别（不记录密钥）、源/证券完整身份、日期/周期、时区与交易阶段、复权方法/锚点、单位/精度、预热与填充、输入哈希、输出原值、可用时点和差异原因。当前第三方历史样本只覆盖其自身格式，不能代替以上产品当前版本验收；原始行情与账户材料仅放私有目录。
