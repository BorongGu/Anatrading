# 062 双股历史相关与 β：编码前冻结显示合同

2026-10-13。独立反方审查现有 `pair_research.py`、`research-model.ts` 与 `CrossResearch.tsx` 后冻结；只展开已有计算，不引入新估计器。旧双股摘要只取最后共同日期，可能掩盖中间关系反向。合成反例中两条路径最后相关/β均约1，中间一条为−1，另一条为1；历史逐行显示可揭示这个差异，不构成预测验证。

## 数据与数学边界

复用既有共同日期交集及对数收益，最近 lookback 个共同区间包含当前区间。相关为协方差除以双方标准差，β为 A 对 B 的协方差除以 B 方差；常量 A 可出现相关不可算、β为0。相邻窗口重叠，区间未必为一天。资格、价格回归、来源限定、研究身份和历史可得性不变。相关不等于协整、均值回归或预测；不混用051/059简单变化的两60窗合同。

## 冻结交互与验收

- PairResults 原内容后新增默认折叠“历史相关与 β（N）”；空序列也保留面板与明确空提示。
- 全部共同日期最新到最早，每页50条，上下页边界禁用；null、预热、无效行全保留。
- 列顺序：共同记录日期、相关窗口起止、有效共同区间 n_returns / lookback、相关与其独立原因、β A对B与其独立原因、覆盖原因与记录原因。null显示—，真零保持0.000；有覆盖警告的有限值仍显示。
- 表直接读取当前报告；新报告对象（包括同一analysis_id）回到第一页，同引用身份字段（method/analysis、依序snapshot/query、cutoff/lookback及显示lookback）变化也重置；同引用内容字段更新可见，缩短数组时夹紧页码。每次只取当前页，不全序列排序/扫描。
- 继承既有请求身份核验与 Generation/AbortController；改参数、重载、错误或卸载时旧结果移除，过期请求不能复活。折叠/重复开关不取数，无独立请求、缓存、导出或跳转。
- 先冻结预期再对比：纯分页完整性、边界与无突变，静态内容及实际ReactDOM＋已安装jsdom的重复展开/折叠、翻页、报告替换、原地更新/缩短及父请求中断/过期完成。最终运行全前端、构建及受影响后端。

原pair API没有051的2MiB响应硬限；保留每源20,000行与现有DTO限制，仅控制表DOM最多50行。无依赖变更，不读取旧Store、私有行情或捕获。真实浏览器已知socket权限阻断不重复尝试；本轮Windows原生、浏览器截图、真人效率、实源兼容及金融效果未验。长期TradingView高级分析目标保留，本片只补齐可核查的历史入口。

## 固定反例的复核输入

窗口5，共16个日期（2026-01-01起），双方起始价格100。B的15个对数变化为 `[0.01,-0.02,0.03,-0.04,0.02]` 重复三次；A甲全部同B，A乙前三个5步块分别取 `+B,-B,+B`。各价格为前价乘 `exp(当步变化)`；这是合成float64估计边界，非精确市场价格。原核在1月6/11/16返回A甲相关/β约1/1/1、A乙约1/−1/1。两者最后摘要相同，中间反向可由历史表读到。反例不改变原资格与估计公式，也不宣称真实数据增量。

## 独立验收后窄范围修订：目录资格失效

首次独立ReactDOM验收保留了旧父组件的目录移除/所选版本改为非日线、待处理响应等失败。App目录刷新可在切入双股后迟到，故冻结补充验收：当前A/B必须仍在现有daily目录，失格当次渲染隐藏报告，effect清除状态并中止请求，提交入口和异步完成再核对当前资格。移除→恢复后旧请求也不得复活。只复用原isDailySnapshot与ID，不增加metadata哈希或资格体系。直接给PairResults注入与report不一致的cutoff并非真实父onChange路径，单列调用者边界；没有取消按钮不计失败，参数变更/卸载负责中断。
