## 1. 结论与真正新增的问题

**保留一个最小候选：一对明确股票、一次固定拟合、一个固定后段的来源变化解释误差审计。** 它回答：

> 我在指定历史截止冻结的 A 对 B 关系，放到随后固定的同端点区间，是否比“不使用 B”或“直接以 B 的变化解释 A”少出错？哪些区间贡献了差异，哪些区间根本不能比较？

这和“现在两股的相关系数多大”“A 比同行强多少”“下一步价格怎么走”分别是不同任务。当前相关很高，旧斜率仍可能已经不合用；逐日重估得到的小残差也没有回答固定旧映射在这个后段的误差。本片可以提供“旧映射在这个后段仍有解释增量”的反证，**无法给两只股票颁发稳定、可信、协整或套利资格**。

保留候选的价值在于冻结同一解释并列出反证，尚无用户判断增量或市场有效性证据。若用户要的是“经济关系在何时真正断裂”，现有公司行动、日历及历史版本资格不足，应先补数据；不得用这里的来源误差替代该答案。

本片不延续 035 的突破筛选条件，不改 ER 阈值，也不从其失败后继续搜索新选股信号。034 的单股前序预测误差可提供工程经验，但此处使用的是**同时期 B 的已观察变化**，没有下一期预测语义。

## 6. 唯一候选的精确数学任务

### 6.1 一次拟合、一个后段

令 `fit_end=d0` 为可靠日期并集中的确切双侧合格端点。F 是 `(d_-60,d_-59]` 至 `(d_-1,d0]`，共60区间、61日期槽；E 是 `(d0,d1]` 至 `(d19,d20]`，共20区间。合计81个不同日期位置。

两侧完整源按可靠日期取并集；缺失、重复、坏槽保留，不能先取合格交集。训练窗口不扩展凑样本，锚点不回退。E 不足20时只列已有位置；已有20而任一区间失败时，主汇总为空，不能用19个好区间重算。`evaluation_cutoff>d20` 不扩展后段。

来源资格和失败优先级以计划 §3—4 为准。复用既有来源反证与端点规则；实际单侧缺日阻断所用区间，两侧共同缺标签仍无法由并集发现，日历保持unknown。不新增事件输入/过滤：已知公告只留离线验收旁注，停牌仍有OHLC也不能获得交易资格；公司行动覆盖始终unknown，仅允许有条件来源描述，不能认证经济收益。

### 6.2 精确变化、OLS 和两个固定基线

```text
x_j = B[d_j] / B[d_(j−1)] − 1
y_j = A[d_j] / A[d_(j−1)] − 1
mx = sum_F(x) / 60; my = sum_F(y) / 60
Sxx = sum_F((x_j−mx)^2)
Sxy = sum_F((x_j−mx)(y_j−my))
beta_F = Sxy / Sxx
alpha_F = my − beta_F × mx

P_j = my + beta_F × (x_j−mx)
M_j = my
U_j = x_j
e_Pj = y_j−P_j; e_Mj = y_j−M_j; e_Uj = y_j−U_j
MSE_k = sum_E(e_kj^2) / 20
MAE_k = sum_E(abs(e_kj)) / 20
ΔMSE_PM = MSE_P−MSE_M; ΔMSE_PU = MSE_P−MSE_U
ΔMAE_PM = MAE_P−MAE_M; ΔMAE_PU = MAE_P−MAE_U
```

close 属完整正 OHLC、DECIMAL(38,18) 域；变化、系数、映射、误差、MSE/MAE和差全部由源十进制精确值定义，用 Fraction 计算。`Sxx=0` 才使 P 不可拟合；Sxx 极小但非零不截尾、不正则化、不因 beta 巨大另改模型。训练 X 的 min/max 和 constant 事实如实列出，不把有非零方差解释为信息充分。

F 资格完整而仅 X 常数时，M/U 可保留固定完整 E 的结果，P 与两个相对差为空。F 本身来源/路径失败时，不偷偷单独用 A 的干净子样本拟合 M；三模型比较全部为空。E 内模型样本始终完全相同。

统计单位分别为 `source_relative_change`、`source_relative_change_squared`、`source_change_beta`；alpha/误差与 MAE 是来源相对变化，beta 为无量纲来源变化映射斜率。没有合格总收益、对冲股数或收益中性语义。

### 6.3 只审计这个后段，不能给未来许可

P 使用 E 中同时期 B 的已观察变化，最早须等该区间四端点与 F 均可得才能计算；它不是区间开始时的预测。下载后的历史仍为已见来源，无历史首次可得认证。冻结参数不能把其升级为真正未见样本外预测。

主报告仅含 P/M/U 的 MSE、P 对 M/U 的精确差方向、60/20完整性、两段日期及来源限制。MAE与对应差始终保留在固定敏感性明细中，不按结果挑损失。删除默认 RMSE、均值/中心RMS分解、标准化分数与方差评分。训练/后段 X 的 min/max、constant、后段超出训练 min/max 的计数仅作输入范围背景；不据此删行或认定结构破坏。

输出采用12位有效数字、half-even科学计数展示，另给精确 `sign`。所有优劣由内部精确差判定，展示舍入后的两个损失即使相同，也不覆盖非零差的符号。不输出巨长分子/分母，不调整Python全局整数转字符串限制；静态整数界、格式和输出上限见计划 §2/§5。

唯一允许的比较措辞是“在这一个固定后段，P 的某项误差高于/等于/低于该基线”。正差不能证明结构破坏，负差不能证明关系稳定或授予未来沿用许可。相关、协整、失效概率、断点日期、显著性、未来买卖建议都不输出。
