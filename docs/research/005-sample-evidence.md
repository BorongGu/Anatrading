## 负面证据

同一 mootdx 版本中名为 `sh688001.day` 的 fixture 有 5,156 条记录；按 A 股股票股数口径，全部记录的金额/数量落在 OHLC 区间之外。文件名本身无法证明数据的品种身份和单位，此样本不能作为合格股票真值。

该版本 `sh688001.lc1` 有 2,880 条，初步检查报告 1,451 条量额价格区间冲突、414 条零量；`.lc5` 有 144 条，70 条冲突。未经同源客户端对照和单位核验，不能凭记录能解码就称可用于准确均价研究。

## 这些检查实际证明了什么

- 已取得具有真实行情内容、通达信格式标记的公开历史文件，发现了合成 CSV 很容易漏掉的混合分隔符和身份/口径问题。
- 原型能解析上述日线和文本分钟格式；原始字段、错误与零值可保留。
- 检查采用实验阶段的一分钱容差（原生金额另加 float32 编码容差），**该阈值尚未通过源精度和交易类型审查**。211 条异常是该实验口径下的结果，不能直接称为软件错误；零异常也不能称为数据完全正确。
- 当前未完成独立实现逐字段对照、分钟汇总与对应日线的覆盖核验、当前客户端版本导出、同花顺真实文件或官方 API 对账、完整交易日历核验。

因此这些样本只提供格式与异常发现证据。G1 仍需同版本真实客户端/API对账，不能把第三方历史样本的通过范围扩大为品牌全版本兼容。
