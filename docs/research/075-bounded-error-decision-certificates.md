## 1. 新问题与同一世界比较

074区分了可恢复目标和决策充分性；本次问：**无需恢复唯一参考价格，能否证明一个比较在所有允许误差下成立？** 这是条件研究问题，不建立用户的交易目标。

项目推导：给定非空紧误差集E、固定行动A/B及连续损失差 `Δ(e)=L(A,e)−L(B,e)`，A在每个允许世界严格优于B，当且仅当 `max_{e∈E} Δ(e)<0`。紧性与连续性保证最大值达到；缺少可达性时，逐点严格负值未必给出严格负的上确界。两个行动必须用**同一个e**比较，分别比较各自最坏损失不能证明这种支配。

- **直接代入：** 对源记录量排序，回答明确的来源描述；不能自动升级为参考价格结论。
- **稳健支配：** 只有每个允许世界都保持严格顺序才确认；保守证书失败只表示证书无结论，不能断言反转可行。
- **弃权/补证：** 当前最简单基线是保留源描述、暂不作参考价格判断。没有核查和等待成本，不能宣称弃权的损失最小；报告弃权也不等同于空仓。
- **Minimax与minimax regret：** 依声明的损失在歧义下选行动，不识别真实世界。例如纯示意增量收益g∈[−1,3]，行动收益g、维持现状收益0：maximin选现状，限定确定性行动的minimax regret选行动（最坏遗憾1对3），稳健支配不选任何一方。这些任意单位不代表股票收益。

## 2. 固定路径、中心化标准差的充分界

两序列使用同一固定n≥2个区间；每条观测log价格y有n+1个正价端点对应的有限log值，参考log价格为 `x=y−e`。D取相邻差，`H=I−11′/n` 中心化，定义这段路径按总体分母计算的标准差 `s=‖HDy‖₂/√n`。参考价格含义、共同支持与尺度须事先明确。

**前提：独立证据支持整窗同时成立的 `|e_t|≤ε`。** 每个相邻误差差分至多2ε，故 `‖De‖₂≤2ε√n`；H是正交投影，不增加二范数。对 `HDx=HDy−HDe` 用三角及反三角不等式得：

```
|s_reference − s_observed| ≤ 2ε
max(0, s−2ε) ≤ s_reference ≤ s+2ε
[max(0, s−2ε)]² ≤ variance_reference ≤ (s+2ε)²
```

必须先截非负下界再平方；2ε界定标准差误差，不能直接当作方差误差。这里“总体分母”仅指固定有限路径的除数n，不是统计总体方差认证。

对A/B，`s_B−s_A > 2(ε_A+ε_B)` 足以证明参考路径方差A严格小于B。同一ε时门槛为4ε；等号不足以认证严格顺序。若标准差除数改用n−1，单条误差容差变为 `2ε√(n/(n−1))`，比较门槛同乘该因子，并使用该分母的观测标准差。

这些一般是外界：端点误差使相邻变化误差相连，不能擅换成独立收益误差盒。共同/共享误差限制可收紧可行集；上述充分界仍适用。等ε时gap/4给出保守认证半径，严格排序要求ε小于该值；它一般不等于精确失效半径，某些特例可以相等。未通过充分界不证明顺序能反转。

手推见证（未执行）：观测log端点A=(0,.010,0)、B=(0,.011,0)，对应s为.010/.011；参考路径交换这两个中点后顺序反转，每条端点误差均至多.001。指数化给出正价。这允许两条独立选择的误差路径，不能证明两资产强制共享同一误差路径时仍会反转。

推导无需iid、Gaussian或时间独立假设；只陈述固定路径，不认证未来风险、连续时间积分方差、无偏有效价格估计或可交易表现。它没有修改[063](063-close-price-dispersion.md)的价格水平离散量、既有EWMA或任何产品口径。

## 3. 什么信息才允许使用这个界

E必须指明参考量、尺度、支持、版本/时点、幅度、同时覆盖及跨资产联合限制，且由独立依据支持：

- 已知舍入规则只界定相对其未舍入输入的误差；tick大小不能界定陈旧程度或距有效/可执行价格的误差。
- 与认证且语义匹配的参考逐项对账，可确定被检查窗口的差异；历史最大差异不自动约束未来。
- 时间戳误差上界还需价格移动限制才能导出价格误差界；跳跃使单有时间界不足。
- 买卖报价直接定义报价；把潜在有效价格限制在报价内是额外假设。多vendor一致可能共享上游错误。
- 精确存储和哈希证明保存一致性，不能证明市场准确性；逐点概率覆盖也不能直接当整窗同时覆盖。

只约束参考价格为正而不限制误差时，参考log路径可有零或任意大方差，排序无信息。数值精度不能修补未知公司行动/调整或执行语义。015的源算术、040的财富口径及068对**给定精确OHLC**兼容路径的紧界保持原范围，均没有提供本节所需的市场误差界。
