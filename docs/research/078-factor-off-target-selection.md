## 1. 删除一项与重新拟合分别比较

复用077同一确定性60×10训练、5×10验证收益面板。令R_i为验证5日简单收益和，F_i为同期LOO因子收益和，训练参数alpha_i、beta_i、v_i=SSE/(60−2)固定，s_i=sqrt(5v_i)。

```
full       z_i = (R_i−5alpha_i−beta_i F_i)/s_i
factor-off u_i = (R_i−5alpha_i)/s_i
u_i−z_i = beta_i F_i/s_i
```

factor-off保留因子模型的截距与残差尺度，仅隔离显式beta项；它不识别整个因子拟合流程的效果。真正截距模型重新拟合mu_i=训练mean(r_i)=alpha_i+beta_i×训练mean(f_i)，v0_i=sum((r_i−mu_i)²)/(60−1)，其分数为(R_i−5mu_i)/sqrt(5v0_i)。两者不可互换。

另保留删截距、删尺度、R_i/s_i及原始简单和作为本轮机制对照，共七变体。分数分解线性，排序和截断成员非线性，不能把换名数当成唯一可加的经济贡献。未用未来收益挑参数、阈值或控制政策。
