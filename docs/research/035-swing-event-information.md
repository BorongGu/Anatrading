## 1. 结论：保留一个可被否定的问题

建议下一步仅审查以下候选：

> 同样是收盘突破此前 20 个来源组高点，且突破前 10 步收盘净变化为正，前段路径较单向的一组，在后续 5 个来源组结束时“价格未高于突破收盘”的比例是否更低？这会漏掉多少后来上涨的事件？

使用已有 ER 路径效率，只增加一个固定条件 `ER >= 1/2`，取值截止在**突破前一来源组**。不新增平滑器、综合评分、自动调参或通用事件引擎。优先做一份可审的离线事件对照，先验收输入、配对和反例，再考虑是否值得接现有界面。

本候选试图为用户提供一个具体背景：面对同一类突破，把此前净向上但反复折返与此前较单向的路径分开，同时看两组的全部失败、成功和不可评价记录。它不能预先保证有帮助；两组无差别、方向相反、分组过稀或已有页面已足够，均可结束本片。

034 的独立真实验收摘要已给出重要负结果：固定 30 股、2024-10-11～2026-10-09 来源版本上，Kalman 一步源价误差的 MAE/RMSE 每股均差于 RW；三组 RW 经验范围的平均 interval score 均略差于既有 EWMA。这里只承接该报告结论，没有重算、选股或读逐事件未来价来挑条件。该结果限制一步任务的预测优势，不能外推成所有趋势描述或波段用途无价值。也不能以波段用途为理由继续宣称已发现优势。最终对外记录以 [034 验收](../qualification/forecast-diagnostics.md) 的发布版为准。

本片名称中的“信息”只表示待研究的条件分布差异与反例解释，不表示因果作用、可交易 alpha、上涨概率或收益建议。未来 5 来源步末价是一个小跨度观察任务，尚不能覆盖完整波段的入场、持有、退出问题。

## 5. 固定事件、背景和标签合同候选

### 5.1 来源索引和共同资格

按同一冻结日线来源的日期分组排序，i 为组位置；bad/duplicate 仍占槽，原 ordinal 保留。每个证券单独索引，绝不将 30 股压成一条共同日历后再数步。采用 026 的 OHLC 正值、包含关系、来源身份/调整冲突规则；无定位异常使完整历史覆盖未知，整证券的新条件比较关闭，失败及已有可审源记录继续保留。

没有记录的日期不补柱、不补0、不猜停牌；每条背景/事件/标签保留实际首末日期、来源步数及自然日跨度。即使 5 步跨了更久，也只表示 5 个来源组。未经核实的复权、公司行动、closed、known_at/PIT 保持未知；已知未处理公司行动附范围和证据，源价格算术可保留，经济解释关闭，禁止删机械跳变美化结果。

### 5.2 固定突破与样本选择

```text
U_i = max(H_(i-20), ..., H_(i-1))
B_i = [C_i > U_i]                       # 当期及此前20组均通过共同资格
S_i = B_i 中按i从早到晚的贪心选择
下一事件仅当 new_i > last_selected_i+5 才被选择
```

**先在完整来源前缀的全部 B 上选 S，再计算/分组背景、分时间段和标签状态。** 报告起点以前的来源上下文也参与既有选择；报告区间起点不重开一份去重状态。不能先删 ER 不符合或后来失败/无效的事件，再在余下事件上重新去重。这样是“既有选中事件中的背景信息研究”；它不模拟一套过滤后重新入场的策略。所有 B 的 `selected/evaluation_status` 保留，未选事件只能作为重叠依赖的附录，不能成为另一套获胜主结果。

### 5.3 仅在突破前一组取背景

```text
N_i = C_(i-1) - C_(i-11)                 # 10次相邻来源变化，11个价格
L_i = sum(k=i-10..i-1, abs(C_k-C_(k-1)))
D_i = [N_i > 0]                         # 最简单的前段方向基线
ER_i^- = abs(N_i)/L_i                    # L>0；L=0沿已有ER=0约定
E_i = [ER_i^- >= 1/2]                    # 唯一新增条件
A0 = S                                  # 原始选中突破
A1 = S AND D                            # 消融基线：只看前段净方向
A2 = S AND D AND E                      # 候选：只多一个ER条件
```

N、L及E统一用标准库Fraction精确运算；对 `D=true`，E等价于 `2*N>=L`。一般E仍为 `2*abs(N)>=L`且L>0，D=false的单向下跌仍可E=true。不能在任意全局Decimal context下直接做乘2再声称精确；不用显示四位小数或float阈值。`L=0`时N=0、D=false、ER=0、E=false，保留 `zero_path_convention`。在 B 可算的严格21组内，背景11组天然具价格资格；来源获准且连接正确时D/E必须有布尔值。全局来源关闭时不计算；若出现意外缺值/索引不一致，整证券新比较失败，不能作为false或按行剔除。旧事件状态原样保留，详见§6.3。

ER 不依赖源价的共同正倍率缩放；N和L同比例变化。不承诺跨不一致复权边界不变，也不称其估计了“真实噪声”。方向 D 的加入是为了避免把高 ER 的下跌路径混为向上背景；A1/A2只差一个条件。A0/A1的差异只作方向消融背景，不另选一个“优胜模型”。

事件 i 的当日跳升有机会机械抬高包含 i 的 ER，因此使用 i−1是问题定义。更改合法当前 C_i 且仍保持 B=true，N/L/D/E必须完全不变；事件后的任何数据更改也不能改变这些字段。固定来源前缀单侧计算不能自动证明当时收盘价已能获得。

### 5.4 只采用既有5步标签

```text
R_i,5 = C_(i+5)/C_i - 1
Y_i = 1[C_(i+5) <= C_i]                 # “后5来源组末价未上涨”
sign_i = positive / zero / negative      # 用原Decimal价格精确比较
```

沿途 `i..i+5`全部通过原事件 OHLC/唯一性要求、终点不晚于 evaluation cutoff 才可评价。不足5组为 immature；足够组但有坏组为 invalid；标签跨训练切点为 purged。遵循既有优先级，不压缩坏组找更远端点。零价不作 −100%，零变化与负变化分别计数。

保留既有 `price_change` float64估计供分布汇总，sign直接比较原Decimal端点。审查SE-02要求按**实际支持域**缩减数值设计，本修订接受：新入口只接受经strict normalization的完整Store查询或同合同合成输入；合法价格为DECIMAL(38,18)，`10^-18 <= C < 10^20`，不同价差至少`10^-18`。旧实现先做 `Fraction(C_end)/Fraction(C_start)-1`，再转float，所以非零R满足 `10^-38 < abs(R) < 10^38`。它不会在合法域内变成0、下溢或溢出；最多20,000项的绝对和小于`2×10^42`，旧fsum和type-7加权插值也在float范围内。正常舍入仍存在，幅度属于估计。

**删除额外的“数值有效事件筛选”。** 合法域中旧float标签的正/零/负必须与精确端点比较相同。若不相同、非有限或连接不一致，视为入口/实现/版本错误，整证券新比较失败，保留已完成的旧报告及原因，不静默丢行重算。超域价格依既有输入校验成为无效组，不能作为一个先有效后下溢的候选。旧event_report整体抛错时新连接失败，未执行计数为null，不输出部分成功的完整报告。

合法负R可在float中舍入为−1，例如极大正起点与`10^-18`正终点；这仍是**近似幅度**，精确sign为negative，绝不能据显示−100%反推端点为0。原始正端点和来源资格保留。N/L、计数比例、Δ_s及等权Δ_main均为Fraction；**停止判断取精确Δ_main的符号**，float/百分比仅展示，不用epsilon或显示舍入裁决。

本文只比较源收盘价。没有实际成交价格、费用税、滑点、涨跌停排队、库存/交易约束或公司行动总收益，故 `Y`不能叫亏损概率，`1-Y`不能叫胜率，R不能当实盘盈亏。

## 6. 基线、唯一主比较和分母

### 6.1 每条事件的最小见证

绑定：证券及当前成员清单哈希、snapshot/query/原件哈希、方法与参数、报告起止/截止、源身份和资格；事件日期/ordinal/index、U/C、selected、前一来源日期及ER十一组定位、精确N/L/ER、D/E的三态与原因、标签首末日期/跨度、原标签和评价状态、价格符号。未知事项显式在来源/历史可得性层保留。

A0/A1/A2不复制三份全行情或三次递推。每个 B一条见证，条件为附列；分布和表从同一账本派生。旧 UI最后100行限制不能决定实验样本，失败记录全部可核。

### 6.2 比较顺序

1. **原始基线 A0：** 与既有20/5的 B-only选中事件逐条、计数和R分布对齐。先保留旧完整前缀选择，再按相同signal_date报告范围汇总；不能拿目标两年汇总直接对比旧整前缀总数。唯一主范围精确等于旧`partitions.test`，其全可算日期基线直接复用，注明含事件日且标签重叠；它不是随机/独立对照。前段/全目标段/季度仅从事件账本给诊断，不另外制造每日期基线明细；旧完整前缀baseline不得贴成这些时期的基线。
2. **简单方向 A1：** 保留前10步净向上的选中突破。报告A0中D=false和D=unknown全部条目，不能只显示筛后的结果。
3. **主比较：** 在每股A1的共同可评价事件内，将E=true与E=false分成两组，比较“5步未上涨比例”；A2正是前一组。`Δ_s=p_s(Y=1|A1,E=true)−p_s(Y=1|A1,E=false)`。任一组无合格事件时该股Δ_s=null。唯一主汇总为两组都有支持的股票的等权平均 `Δ_main=sum(Δ_s)/M`，同时显著列M/30覆盖；M=0时为空。这是对具备两组支持的固定成员子集的描述，不能外推未支持股票或市场。事件数加权合并值仅为构成诊断，不可替换主汇总。
4. **必须并列的代价：** 同一共同可评价集上的A2保留数/A1数、被E排除的后来正变化数、`positive_E_false/positive_A1`（分母0为null）、E=true/E=false/A1的正/零/负计数及同尺度R均值/中位数/既有分位数。另给全部选中事件上的条件保留数，但未知标签的遗漏正例数保持未知。不得仅报“筛选后比例提高”而隐藏漏掉的正变化事件；代价比率不成为第二主指标。

这里的两个E组不是同一事件的两种结果，无逐事件处理效应、随机分配或因果比较。ER相关于波动、突破幅度、证券、市场阶段等；本片不加一串控制变量后声称识别了ER的独立因果价值。只比较A2与A0会混入方向条件的作用，因此A1和它的E=false补集必留。

### 6.3 分母守恒

先保留两个旧状态，再加独立的新资格。来源结构校验与normalization成功后，无论新来源资格是否获准，都恰好调用旧event_report一次，原B/selected不因新资格而改写。完整状态优先级为：

| 层 | 固定顺序及范围 |
|---|---|
| 旧label_status | 先查i+5是否存在；不足为immature，即使已存在的未来槽有坏组。终点存在才查全路径invalid，合格才valid |
| 旧evaluation_status | 未选事件为overlap_excluded；选中且训练信号的已知终点>=cut为purged，即使旧label_status=invalid；其余沿label_status |
| 新来源资格 | source_rejection或coverage_known=false使整证券source_unavailable。旧报告仍保留；新N/L/D/E、分组分布/差值不计算 |
| 新连接资格 | 获准来源的每个B固定连接i−1的11槽；预期全部可算。意外索引/符号/数值不一致使整证券comparison_failed；不得保留部分主比较成功 |
| 新比较资格 | 来源获准、连接通过且旧evaluation_status=valid才comparable；其余旧状态逐项保留。全局不可用与内部失败覆盖新资格，不覆盖旧状态 |

旧入口整体失败时只保留输入身份/已取得coverage及错误码，旧事件和后续计数均为null；新N/L/D/E未执行也为null，不能写0。若旧入口成功且后续新比较关闭，**旧计数和资格归类可精确对账**，按旧valid数填全局排除列；`comparable=0`、`condition_computed=0`是可知的资格计数，不等于执行过D/E计算。新计算次数/分组统计仍为null。来源关闭和连接错误理由不混成numeric_invalid。

对旧入口成功的证券，每个报告范围保留以下恒等式；旧状态×新资格交叉表以旧evaluation_status五类及新资格三类（admitted/source_unavailable/internal_failure）列齐：

```text
candidate_dates = rule_computable + rule_unavailable
raw_B = overlap_excluded + selected_B
selected_B = valid + immature + invalid + purged
旧evaluation_valid = comparable + source_unavailable_valid + internal_failure_valid
selected_B = condition_computed + condition_source_unavailable + condition_internal_failure
以下条件分解仅适用于来源admitted且连接成功：
condition_computed = D_true + D_false
D_true = E_true + E_false
同一comparable集：D_true = E_true_positive + E_true_zero + E_true_negative
                        + E_false_positive + E_false_zero + E_false_negative
```

状态×条件是交叉表，不能把它们相加充当同一互斥分类。所有整证券关闭保留在30成员覆盖清单；跨股报告列成功/来源关闭/输入或连接失败成员及来源哈希，M只取成功且主时期两E组均有comparable事件者。无事件、仅一类条件、全零标签都是有效研究结果，不能补造0%的估计。组合反例见实施计划：旧valid+coverage关闭、坏路径+未来不足、坏标签+跨cut、未选+各种label状态须逐项对账。

来源关闭的小例：旧selected=3，其中valid=2、immature=1，则 `comparable=0/source_unavailable_valid=2/internal_failure_valid=0`、`condition_computed=0/condition_source_unavailable=3/condition_internal_failure=0`；旧状态×新资格仍守恒。D_true/D_false、E两组及其正零负统计全部null、Δ=null，**不对未执行D/E套用条件分解恒等式**。这里的资格0可以已知，D/E数值仍未计算。

显示原始全部B与选中S数量、标签日期实际跨度、唯一信号日期数和来源缺日说明。被选事件后来坏/未成熟时不回头替换，也不把空白算作没有失败。
