# 因果信号、双股关系与集合研究：首轮算法合同

日期：2026-10-11。对应 [研究工作流方案](../plans/2026-10-11-research-workflows.md)。本文先于产品编码编写；参数和边界已按方案末尾的**反方答复候选合同**统一，仍以独立复核解冻为实施前提，不能称为经过 A 股收益优化的默认值。参数若在评审中变化，须同步修改本文、实现和测试，不能依据测试段结果倒调。

## 1. 目标、证据和首轮范围

首轮交付四种可解释计算：单股单侧趋势/波动/冲击、固定突破事件及后续来源价格变化、双股有限窗口关系、同日截止的多股强弱和观察池广度。每项附输入身份、时点、参数、有效样本数和失败原因。已有通道、TR、量能、路径效率及确认拐点作为简单对照，避免只增加相近指标数量。

证据分三层，分别验收：

1. **数学和程序性质**：公式实现、数值边界、因果时点、前缀不变性、复杂度。通过测试可以支持这些结论。
2. **模型内统计性质和外部经验**：Kalman 在指定线性状态空间假设下的估计；海外历史动量/配对研究；协方差收缩的模型和渐近性质。它们的假设和研究对象必须保留。
3. **本工具在目标数据上的决策增量**：真实来源兼容、未来价格信息、成本后可执行收益，均须另外验证。平滑、拟合好、统计显著和能赚钱是不同结论。

**首轮不实现**正式协整检验、均值回归资格、套利交易、自动股票交易、组合优化、HMM、PCA、全市场配对搜索或参数优化。固定突破评价是价格条件关联，既无因果识别，也无成交账本，不能称策略收益或给投资建议。

## 3. 共同数据与时点合同

- 原始价格/金额仍为 Decimal 和精确字符串，原件不修改。统计内核在显式边界转 float64；禁止反向覆盖原数据。输出注明 `estimate_float64`。超出可表示范围、非有限、下溢为零的正价格均给数值原因，不输出 NaN/Infinity。
- 使用冻结版本、证券、周期、来源标签、原序号和截止。按同一个来源标签分组并排序；重复保留为无效组，不取最后一条，不当成两根柱。无定位的异常不能悄悄排除后授予完整覆盖资格。
- 单股序列允许来源观测序号作为离散时间。日历未知时，20 根称“20 个来源观测”，不写 20 个交易日；不凭来源日期间隔补柱、补零或推断停牌。
- 坏价格/重复组是连续链的断点，不能跨过后拼接收益或递推；下一根合格值显式重置。无法给异常定位时，报告覆盖未知；首轮不对受影响整体授予时点/覆盖资格。具体可描述子集与拒绝范围须保留在响应中。
- 首轮新增 Kalman 仅日线。日线按连续合格来源组运行，日期有空缺只披露日历/覆盖未知，不假装间隔相同。没有交易日历就不能识别未记录的缺日。分钟继续使用既有算法；分钟 Kalman 的周期、午休、隔夜、缺柱和重置另行研究，不能把本轮日线参数直接认证为分钟参数。
- 本轮只声称“以已给定来源观测为条件的单侧计算”。闭合、历史当时可得、复权与公司行动未知仍独立展示。收盘标签不自动证明真实当时已可获知最终 close。
- 同一参数和来源前缀下结果必须一致。屏幕裁剪不能重新初始化递推；需要从该连续段起点计算，或从严格绑定版本/参数/起点的可靠状态继续。cutoff 之后任何数据不得参与初始化、参数估计或填补。

## 4. 单股：固定参数局部线性 Kalman、EMA 与原始收益波动

### 4.1 固定候选参数及单位

所有值公开固定，首轮无 MLE、EM、全样本拟合和在线调参。

| 参数 | 首轮候选 | 单位/含义 |
|---|---:|---|
| 观察 y | log(close) | 无量纲自然对数；正价格 |
| 状态 x | `[level, slope]` | level 为 log 价格；slope 为每个合格来源观测的 log 变化 |
| F | `[[1, 1], [0, 1]]` | 一个离散观测步 |
| H | `[1, 0]` | 观察 level |
| R | `1e-4` | log 价格的模型观察误差方差；标准差 0.01；不是实测微观噪声方差 |
| Q | `diag(1e-6, 1e-8)` | 每步 level、slope 的模型过程方差；slope 项单位含每观测步 |
| P0 | `diag(R, R)`，即 `diag(1e-4, 1e-4)` | 初始 level、slope 的模型不确定性 |
| 初态 | `[y_first, 0]` | 第一根只初始化，不再对同一观察更新一次 |
| warmup | 前 20 个连续合格价格 | 计数含初始化柱；前 20 根显示估计但标 `warming_up`，不产生趋势结论；第 21 根起结束该标识，不证明稳态或模型校准 |
| EMA 半衰期 | 10 | `a=1-2**(-1/10)`；初值为 y_first；内部参数边界 1–252 |
| EWMA 半衰期 | 20 | `lambda=2**(-1/20)`；内部参数边界 1–252；仅公开工程基线 |
| 标准化分母保护 | 正且有限 | 零分母/非有限标准化为空并给原因；不把数值地板当真实风险 |

首轮仅日线，固定对角参数不开放 HTTP 矩阵输入；内部 R 正且有限、Q 非负且有限。返回 segment_id、warmup 与 reason。参数身份包含周期、固定参数和重置规则，不声称日线来源日期等于统一交易时间。

### 4.2 单侧递推

从第二个连续合格观察开始：

```text
x_pred = F @ x_prev
P_pred = F @ P_prev @ F.T + Q
innovation = y_t - H @ x_pred
innovation_variance = H @ P_pred @ H.T + R
K = P_pred @ H.T / innovation_variance
x_t = x_pred + K * innovation
A = I - K @ H
P_t = A @ P_pred @ A.T + K * R * K.T
ema_t = (1-a)*ema_prev + a*y_t
```

协方差使用 Joseph 更新。所有中间量检查有限；创新方差必须正；P 须对称且半正定到明确浮点容差。允许消除对称舍入误差；显著负方差或非有限不能继续递推。失败返回 `numerical_failure` 并断链，下一合格柱重新初始化。不得静默将大负方差截成零。

输出 filtered level/slope、EMA、模型创新及 `innovation/sqrt(innovation_variance)`。前两根状态没有凭空的置信度升级；warmup 中仍可显示数值，但须带初始化标识。level 可转换成 `exp(level)` 供图上显示，溢出时只关闭价格尺度展示，原 log 估计与错误仍保留。

不调用平滑器。不得将参数在全样本拟合后生成的 filtered 序列说成历史无泄漏。slope/sqrt(P_slope) 只能称模型内标准化斜率，不能当成真实涨跌概率；首轮优先显示 slope 和不确定性原值，不给“买入/卖出”分类。

### 4.3 EWMA 的 pre/post 区分

`r_t = log(C_t) - log(C_prev)` 只在同一连续段内定义，使用原始 close，而非滤波后的 level。第一根价格无收益；第一条有效收益设 `v_post = r_t*r_t`，此时 `v_pre`、收益冲击分数均为空。此初始化是公开约定，不能拿整段未来样本方差初始化。

从下一条有效收益开始：

```text
lambda = 2**(-1/20)
v_pre_t = v_post_prev
return_shock_t = r_t / sqrt(v_pre_t)     # 仅当 v_pre_t>0 且标准化结果有限
v_post_t = lambda*v_pre_t + (1-lambda)*r_t*r_t
sigma_post_t = sqrt(v_post_t)
```

`v_pre_t` 是看见当前 r_t 之前的尺度；`v_post_t` 已含当前收益，可作下一观测的模型尺度。首轮不减去全样本均值，明确零均值二阶矩 EWMA 约定。若历史收益全零，v=0 是真实计算结果，标准化冲击为空并报 `zero_scale`；当前非零冲击仍进入 post variance，不能因无法标准化而被丢掉。

模型创新分数与收益冲击分数不同，界面名称分开。若显示告警，候选阈值 `abs(score)>=3` 仅是模型尺度倍数，不是校准的尾部概率或异常交易认定。大幅有效跳变保留，禁止自动删点、截尾、修改原价。价格有效性和估计稳健性分开处理。

波动为每来源观测尺度；无可靠日历/频率时不乘 sqrt(252)、sqrt(240) 等年化系数。显式坏行/重复断点同时重置收益、EMA、Kalman 和 warmup；不跨段计算一条伪普通收益。

### 4.4 复杂度和专用验收

固定二维状态、EMA、EWMA 单次 O(T)，状态工作内存 O(1)，保留输出 O(T)。不为每行复制全部历史成员。

- 手算至少前三步，包括首柱不双重更新、首条收益初始化和第三柱 pre/post。
- 对固定 F/H/Q/R/P0，与独立矩阵参考及 statsmodels filtering 对照；约定首柱初始化差异必须消除后比较。
- 恒定价、稳定斜率、反转、单次跳变、波动聚集；异常冲击进入原始风险，不能只剩一条漂亮曲线。
- 零/负价、非有限和浮点范围、重复、缺标签、未记录日期间隔不被伪装为完整交易日历、全部零收益、低全局 Decimal context。
- 逐前缀一致；任意修改未来行不影响此前状态；选中中间图窗不改变相同来源行；reset 后与独立新段计算一致。
- 价格整体乘正常数时，log level/EMA 平移，slope、收益、波动和创新保持到数值容差的不变性。
- P 有限、对称、半正定；每次失败有原因，无 NaN JSON。合成潜变量样本分别报告误差与反转延迟，不以单一平滑度证明有效。

## 5. 固定突破事件与来源价格后续变化

### 5.1 固定事件

首轮默认 `lookback=20`，范围候选 2–252；评价默认 `horizon=5`，只允许 1/5/10/20 个来源记录。用户改参数是新的研究配置，记录身份；首轮不自动选最优 lookback/horizon。

令 i 为同一来源中排序后的标签组位置。事件条件为：当前组 OHLC 有效、此前恰好 N 组均有效、`close_i > max(high_(i-N), ..., high_(i-1))`。相等不触发；当前 high 不参与历史上界；不足 N 组为空。历史坏组、重复不能跳过补满 N。突破比较用 Decimal，不经过 float 舍入。合法性为 OHLC 价格均正且 low<=open/close<=high；缺 volume/amount 不阻断价格计算。复用已有价格通道的基本校验，避免两套同名突破定义。

`signal_at` 为当前来源标签。若真实闭合与 known_at 未核实，只写该来源条件下的事件，不宣称真实盘中当时可交易。当前突破与已经成熟的历史评价分区展示，禁止借后续价格筛选“更成功”的事件。

### 5.2 描述标签和成熟

`label_i,h = close_(i+h)/close_i - 1`，同时保留起止标签和实际跨越的来源组数。可额外显示 `log(close_(i+h)/close_i)`，不要混用算术均值与 log 均值。

- h 表示**后续 h 个来源标签组**，无日历时不称 h 个交易日。截止之后的组不能参与。
- 当前与未来端点及沿途 h 个组须通过固定价格/唯一性要求，所有标签价严格为正，零端点报 invalid_price，不能按 −100% 纳入；异常不跳过，标 `invalid_label_window`。缺乏足够未来组为 `immature`，无效与未成熟分别计数。
- cutoff/as-of 之前第 h 个后续来源组存在且全窗合格时才成熟；不能把数据结束前未成熟事件当 0。
- 标签属于来源 close 的事后变化，未经成交可得性、费用、税、滑点、公司行动和持仓约束，不称 PnL、胜率或交易回报。正标签比例称“后续价格上涨占比”。

### 5.3 时序切分、purge 和重叠

时间切点由用户显式提供 `test_start`；未提供时只输出全段描述性事件研究，不用“样本外”字样，不按未来样本长度自动生成切点。评价 `asof` 由明确 cutoff 或冻结查询终点确定，写入报告。

训练事件起点早于 test_start 且标签终点也严格早于 test_start 才可入训练统计；终点 `>=test_start` 的训练标签计入 `purged_cross_boundary`。测试决策日期 `>=test_start`，终点须不晚于 asof。逐标签检查区间，不能拿随机行划分或固定比例切数组冒作无泄漏；有切分也不据描述统计宣称“样本外有效”。

严格向前切分没有测试段之后再入训练的样本，因此首轮不需要后侧 embargo。未来若采用双侧或组合 CV，才按信息/事件区间另定义 embargo；不能把 gap 当成自动泄漏保证。[TimeSeriesSplit 官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)只定义索引 gap，不提供本项目事件成熟语义。

每个 horizon 独立按信号日期贪心保留最早事件，之后事件必须 `new_i>last_selected_i+h`。是否保留不看未来标签是否赚钱/有效/成熟；不能因选中标签后来无效而回头替换。按全信号序列固定选择后再分区，不在切点凭空取消既定重叠排除。报告原始事件/重叠排除/选择后有效/未成熟/坏标签/purge 等计数。不报独立样本标准误、t 值或置信区间。基线保留全部合格日期，其标签可能相互重叠，须明示依赖。

### 5.4 输出与验收

每段报告：候选日期数、规则可算数、事件数、成熟有效数、未成熟数、无效数、purge 数、重叠数；有效标签的均值、中位数、分位数、正变化比例；突破前窗可计算且标签成熟/路径有效的全部起点（包括事件日期）的同 horizon 价格变化基线和样本数。基线采用相同切分和标签质量规则，为非随机描述性对照，不能把今天仍存在的股票池称历史无偏市场基准。

分位数首轮采用明确线性插值规则：对升序数组，位置 `(n-1)*q`，邻近两点线性插值；n=0 返回空，n=1 返回该值。均值用稳定求和；计数之和可审计。事件与基线差异只作描述，不能据观察到差异声称统计显著或因果效应。

测试：手算突破/相等/双侧异常；前史缺失；末 h 根未成熟；终点恰等 cutoff/test_start；训练越界排除；未来变化不影响历史事件但能改变新成熟标签；坏组不压缩；全部无事件；全零标签；非重叠选择不依赖结果；计数守恒。事件检测可用单调队列 O(T)，标签校验用无效计数前缀 O(T)，结果 O(T)。

## 6. 双股：有限滚动关系，首轮无协整资格

### 6.1 对齐及窗口

仅日线。两个指定数据版本采用相同 cutoff，按精确来源日期对齐；记录各侧无定位、重复、无效、仅一侧存在日期和最终共同日期数。不填充、不插值、不以最新各自日期拼成同步观测。

来源共同日期不一定连续交易日。以相邻共同日期算收益时，明确为“共同日期区间收益”，附端点和跳过的各侧来源日期数。共同日期中的坏/重复组是窗口断点，不能删除坏组后假装完整。仅一侧有日期属于对齐缺口，首轮须披露；若窗口跨该缺口，标 `unequal_source_coverage`，不授予普通逐日关系解释。界面不能只画一条干净相关曲线掩盖缺口。

候选 `lookback=20`，范围 5–252。log 价格拟合使用**当前之前的 W 个共同价格观察** `[t-W,t)`，当前 t 不入拟合。相关/收益 beta 使用截至当前 t 的最近 W 个共同区间收益，**包含当前区间**，需要 W+1 个连续共同价格槽。分别返回实际 `n_prices`、`n_returns` 和各自区间，不混用包含边界。左右方向固定 Y=left、X=right；首轮须为可识别的不同证券及相同市场，未知/不同市场不授予同步资格。

### 6.2 明确公式

令历史价格 x_j=log(B_j)、y_j=log(A_j)，历史均值 x̄、ȳ；采用中心化稳定求和，避免 `sum(x²)-sum(x)²/n` 的消减误差。

```text
Sxx = sum((x_j-x_mean)**2)
Sxy = sum((x_j-x_mean)*(y_j-y_mean))
beta_log = Sxy/Sxx
alpha_log = y_mean-beta_log*x_mean
e_j = y_j-alpha_log-beta_log*x_j
residual_scale = sqrt(sum(e_j**2)/(W-2))
deviation_t = (log(A_t)-alpha_log-beta_log*log(B_t))/residual_scale
```

这是此前窗口 OLS 相对于当前观察的偏离，没有正态/平稳保证，不是协整 z-score。log β 是弹性，不是固定股数对冲比。交换 A/B 会改变 OLS 结果，必须在响应和界面标清方向。

截至当前的最近 W 个区间收益 `a_j=y_j-y_(j-1)`、`b_j=x_j-x_(j-1)`；收益相关为中心化 cross-product 除以两侧中心化平方和乘积的平方根；收益 β 为 `S_ab/S_bb`。分别命名 `return_correlation`、`return_beta`、`log_price_beta`，不混淆。相对强弱为 `(A_t/A_base)/(B_t/B_base)-1`，base 是首个共同有效日期，返回该日期与两侧原始基准价格；显式坏组后该比较基准可保留，但滚动窗口不可跨坏组。它是相对归一化价格变化，不是两腿可交易组合收益。

### 6.3 失败安全和验收

- W 个有效历史价格不足、当前不成对、无效/重复窗口，返回各自原因。
- X 的样本方差 `Sxx/(W-1)<=1e-12` 时价格回归不可算；任一收益样本方差 `<=1e-16` 时相关不可算，收益 β 在其 X 方差不合格时不可算。残差标准差 ≤1e−10 视为近完美/退化拟合，不输出巨大的 deviation；这些是数值资格阈值，不是经济风险阈值。残差尺度退化只关闭 deviation，保留仍有定义的 beta/相关；不得整行全抹空。
- 中间非有限、相关超出 [-1,1] 超过 1e−12、负平方和超出舍入容差均失败。仅末位舍入可夹回数学范围，不掩盖算法问题。
- 不输出 p 值、半衰期、均值回归概率或“套利”。未来要正式 EG，需 OLS 残差的专属临界值；动态 Kalman/Huber β 后不能套同一标准 p 值。
- 合成共同趋势＋平稳偏离、高相关但非协整、两个独立随机游走、关系突变、完全线性/恒定序列、缺口、交换方向、未来修改、缩窗复算均覆盖。
- 先采用易审计的有界 W 中心化计算，O(TW)，首轮 W≤252、行数受 API 总预算约束；给 5k/20k 实测。若优化到滚动累计，必须保留独立中心化参考、定期重基及相同误差门槛，不能为了 O(T) 引入严重消减误差。

## 7. 多股和用户定义板块：观察柱动量、波动、回撤、广度

集合为用户选择的 2–50 个可识别且不同证券的导入日线版本及可选名称，首轮不推断行业/历史成分。拒绝同证券多个版本和无法识别证券身份；身份来自可识别 source_code 或显式 interpretation 声明，并披露身份的来源资格。所有成员使用同一明确来源日期 D。D 无唯一合格记录的成员为当日缺失/异常，不用其前一日收盘冒充 D 的值。当前成员的历史回顾有选择偏差，不能称历史全市场或无偏行业表现。

默认 `lookback=N=20` 个有记录日期变化，各项采用恰好 N+1 个日期组、含当前 D。各指标有效分母分别报告；不因一个指标缺失而从其他分母默默删除成员。坏/重复组不能跳过补满窗口。

- **N 根动量**：`M=C_D/C_(D-N)-1`，需要 N+1 个合格正价格组。记录实际开始/结束来源日期，不称“一个月收益”，不假装每股起点为同一交易日。
- **N 根波动**：相同 N 个原始 log 收益，`sqrt(sum((r-r_mean)**2)/(N-1))`；明确样本标准差 ddof=1、每来源区间，不随意年化。与单股 EWMA 是两个不同估计，界面名称分开。
- **窗口最大回撤**：在这 N+1 个合格 close 上，从窗口第一根起维护运行峰值；`MDD=min_j(C_j/max_(k<=j)C_k-1)`。不与“当前相对窗口最高价回撤”混名；仅 close 路径，不能声称真实柱内最大回撤。
- **排名**：仅按动量 M 降序，同值采用 competition ranking（例如 1、1、3）；成员身份字典序只用于稳定展示。无混合分数；不含未来截面标准化，不用缺失=0。
- **广度**：`B=count(M>0)/count(M可计算)`，严格大于，等于不计正动量。报告全部所选数、D 有记录数、动量合格数、正/零/负动量数、各指标有效数、无效/缺失数及成员原因。期末覆盖分母始终是全部所选成员；广度同时显示有效/所选覆盖。

观察柱动量与论文 12−1 月动量不同，不声称已复现学术因子。未来有交易日历和复权证据后，再实现 12−1/6−1 月、市场/行业调整与真正历史成员。仅 OHLCV 做的市场/板块残差动量必须标为项目变体，不冒充 FF3 复现。

测试：不同最后日期、相同收益并列、全部恒定、IPO短历史、坏组、成员缺失、各指标分母不同、截止前缀、成员顺序改变不改统计、所有成员都不合格分母零、单成员池拒绝、同版本重复选择。若 M 为成员数，O(MT) 特征生成加 O(MlogM) 排序；单系列上限 20,000 源行，单请求总上限 200,000 行，成员最多 50。按实际 cutoff 范围先预检预算，再加载/计算；超限失败整份请求，不截断状态起点。

## 8. 后续研究路线与真正交易评价门槛

1. **固定训练窗 EG/稳定性**：核查 I(1) 假设、固定回归方向和滞后选择；训练窗估 α/β/尺度并冻结至下一次重估；使用正确残差检验，多候选记完整试验集合及 Holm 等校正。半衰期只在 AR(1) 0<φ<1 且稳定性有支持时给条件估计。高相关或小偏离不是该资格。
2. **收缩相关/PCA**：在同一同步完整收益窗口构建 S，scaled-identity 收缩 `Σ=(1−δ)S+δ*trace(S)/N*I`；核验具体实现和 δ。PCA 只在训练窗拟合，符号与成分切换可审计，测试期不回填。成分描述共同风险，不自动表示领涨或因果。
3. **真正样本外评价**：按日期整体切分跨股数据；嵌套训练/验证/最终留出；训练标签按实际结束/可知时间 purge；全部参数尝试登记；对依赖/重叠收益使用按日期区块 bootstrap 或适当 HAC。White/DSR/PBO 的模型假设、有效试验数及失败情况单独报告。
4. **交易账本**：日收盘后信号从之后可成交时点开始，分别处理原始成交价与公司行动/总收益；佣金、税费、滑点、双腿借券、流动性、停牌、涨跌停、未成交和库存约束都需要数据。OHLCV 触价不能证明队列成交。论文收益不能代替本地执行证据。

规则按品种、板块、日期版本化。当前官方资料为 [上交所交易规则 2026 修订](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml) 与 [深交所交易规则 2026 修订](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)。普通股票新买持仓不能默认当日再卖；双股短腿不能默认可借；全市场不能硬编码一个涨跌幅百分比。首轮无交易账本，因此不需要把这些未解决问题伪装成成交默认值。

## 9. 共同验收与结果用语

- 先写异常输入与独立手算/简单参考，再实现；每个公开参数含严格类型、范围和有限性校验，未知/重复查询参数拒绝。日期严格 ISO 日线；新研究接口不接受 ordinal 窗口，以保持固定递推起点。
- 响应统一 method_id/analysis_id/有序 inputs(snapshot_id、query_id)/parameters/mode=retrospective/limitations/result。analysis_id 绑定方法、输入和参数。固定 snapshot/query/cutoff/参数身份；计算输出与 UI 选择一致，旧请求不覆盖新结果。屏幕精度与原始源字符串分开，估计数字明示近似。
- 固定种子 5,000/20,000 根数据测耗时和 JSON 大小；结果应 O(n) 大小，不能每行携带 O(window) 成员副本。窗口来源可按需查看。
- 全部数学/状态测试、相关回归、前端测试、构建及真实同源交互验证分别记录；缺私有真实样本就写未测，不以合成通过替代真实兼容。
- 完成时分别说“算法计算与截止测试通过”“真实来源已/未验”“决策/预测增量已/未验”。没有真实 OOS 证据，不说去噪成功、识别真实趋势、稳健盈利或超越竞品。

## 实现复审补充（2026-10-11）

首轮集合和双股均要求同一市场兼容组；跨市场日期标签不能证明同时点价格，拒绝混合市场广度。来源行已明确证券身份冲突、复权口径冲突或当前解析规则复权检查失败时，该日期槽禁止参与计算并保留原因；已标记负样本同样不授予研究资格。未知口径与明确失败分开处理。
