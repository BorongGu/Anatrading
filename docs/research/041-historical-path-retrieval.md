## 2. C的最小数学与信息边界

设查询 `Q=(q_0,…,q_m)`，固定 `m=20`，即21个按既有规则保留的来源组。用户选定精确终点，缺失或无效时不回退，界面确认实际起点；不把20来源区间叫一个月。每个历史候选 `W=(w_0,…,w_m)` 必须整体早于 `q_0` 所在来源组，不能共享端点。定义：

- `a_j(Q)=q_j/q_0−1`，`a_j(W)=w_j/w_0−1`；唯一排序值 `d²=Σ(j=1..20)[a_j(Q)−a_j(W)]²/20`。
- 这是本项目的**保留幅度的源比价距离**。保留时间先后、方向和相对幅度；仅去掉价格单位倍数。不除以各窗标准差，不平移/反转/时间扭曲，不学习距离或搜索长度；不称为标准z-normalized Matrix Profile的复现。
- 按距离、再按历史起点先后确定下一候选，选中后排除与其共享任何来源组的候选，最多3次；两条基线分别在同一原始候选池执行同样去重。这是明确的贪心选择，非全局最优三段集合，非独立金融样本。
- 每个结果保留真实起止日期、自然日跨度、原价字符串、归一起点后的全路径、距离、最大逐点差及其位置、端点源变化、区间源路径最大回撤。后者定义为 `max(0, max_(0≤i≤j≤m)(1−w_j/w_i))`，不等于含分红的财富回撤。
- 查询缺组/重复/坏价则拒算；历史坏窗逐项计入无效原因，不能压缩掉坏组后凑21点。保留候选总数、有效/无效/重叠排除/选中数和可定位账本。没有足够候选就少返回；仍须醒目说明“排名最接近不保证足够相似”，不设未经验证的合格阈值或相似百分比。

**来源与因果：** 显示当前保存版本、截止、方法和查询身份；既有未知复权、公司行动、日历完整性、closed/known_at继续未知。缺交易日无法仅从现有序列证明，所以日期跨度必须并列，不填价/补0。只能说来源轨迹近似；连固定比例换单位不变也不能抵消窗内除权。固定截止追加/改动未来数据不得改任何排序；查询内最后一点允许参与描述。历史原件被修订须产生不同来源身份，不能承诺跨版本不变。首片不返回候选后续路径、胜率或收益标签。

**必须有能推翻漂亮叠图的例子：** 以下是待执行验收，本文只给代数见证。

1. 缩短到4区间手算：Q=`100,102,104,106,108`，A=`100,108,108,108,108`，B=`50,51,52,53,54`。三者端点源变化均8%、ER均1，但 `d²(Q,A)=0.0014`，`d²(Q,B)=0`。这是新增路径区分能力的见证，不是预测优势。
2. 平坦/近乎平坦、两个幅度不同但z形状相同、同形错一槽、首价错误污染整个向量、孤立跳变/永久台阶、窗内模拟拆股分别保留其距离代价。100→50可来自拆股，也可来自真实跌价；同样源路径无法判因，不平滑、删跳或自动解释。只测同形正例不通过。
3. 完美匹配与查询重叠、前三名互相重叠、相等距离、没有足够旧历史、坏点位于边缘、不同日历跨度，均有独立预期。强制两条未来不同但前缀相同的序列返回相同报告。
4. 随机/无重复序列也会有最近邻，必须允许全部参照被拒绝。距离对自己定义的基线更低是选择定义内必然，**不能当作业务增量或统计显著性**。相似不推出下一段同向。

数值排序要有独立有理数/高精度oracle；显示舍入不能改变排名。编码前约定须选定精度、并列与数值失败规则、输入/输出上限和资源预算；O(Nm)是算术次数，不假定大整数位成本为常数。先直接穷举，当前规模不建全量两两矩阵、索引平台、近似搜索或新依赖。

## 3. 怎样交付成能操作的功能，并决定停止

最小流程为：**选择查询终点→确认固定20步及日期跨度→点击检索→查看候选与两条基线→点选一个旧区间叠加/逐点核对，或不采用任何参照。** 页面固定显示“历史来源路径检索”，不提供预测箭头、未来延长线或涨跌概率。

已静态核到可复用点：`research_api.py` 的只读预算/来源载入/结果身份，`SingleResearch.tsx` 的单股上下文，`Generation`与AbortController的陈旧响应隔离，`ResearchResults.tsx` 的来源说明和绘图布局，`SourceChart.tsx` 的原记录选择。拟新增一个有界只读入口及局部检索组件，不改变旧single响应、Store或导出。叠图横轴须标“查询第0…20来源步”；两段日期分别显示，不能直接复用旧图只标首序列日期而造成同日错觉。先用日期输入和候选选择即可，不必建设任意绘图选区平台。

按同一功能分层验收，不能把第一层自动写成任务完成：

1. **纯核心**：先冻结异常/反例；独立oracle核全部候选距离、去重、计数、源值和前缀。通过只证明实现定义正确。
2. **只读接入与界面**：继续可运行的单元、HTTP、前端自动测试与合成API→组件桥接；覆盖身份/错误/预算、切换股票与日期、连续点击、过期响应及缺候选。浏览器视觉、键盘/窄屏交互和真人任务分别验收。既有同环境headless浏览器Unix socket路线曾被拒绝，授权证据重试仍失败，当前浏览器验收未完成；不得重试或绕过该拒绝。将来如有不同的正式支持通道，先核实际状态再使用。缺浏览器证据不停止其余开发，也不能用静态组件冒充操作与截图。
3. **任务价值**：冻结几组含明显可比与全部不宜类比的盲测片段，要求人找出最大差异及其日期、辨认幅度/回撤差别、选择或拒绝参照；与现有手动翻图和两条基线比正确率、操作量、耗时。不用人为把相似定义成d²最小来制造赢家。若只多了曲线、误导更多或没有实际省力，就保留实现证据并停止扩张，不调距离/长度追好例。

真实来源接入另行冻结一个只读小范围做逐字段兼容核对，真实私有价格不入git；不默认跑120股、读取胜负结果后选案例。预测与经济收益实验保持独立；**描述性检索界面不必等待预测优势才能实现**。需要DTW、聚类、自动标签或复杂搜索才能产生价值时，应另立问题，不在首片暗加范围。
