## 1. 任务、简单基线与用途

用户的具体方向是明确成员的多股/板块批量研究，并逐步扩大研究能力。此片让同一组的每股并列回答：窗口内最深回撤段、已观察跨度最长段、截止仍未恢复段分别是哪段，各自的深度、来源跨度和原价证据是什么。

现有 `universe_research._evaluate_members` 提供动量、对数变化波动和最大回撤；各股独立取窗，不承诺完整日期数组相同。`UniverseResults` 可回查个股；`SourceChart` 的“恢复视图”调用 fitContent，只恢复图表范围。041提供同股历史路径及原价表，不能据此称任意多股恢复摘要已存在。人工分别看图和逐点数数能完成小例；它是可靠基线。新片增加统一规则的批量可复核读数，没有已测省时、真人判断或竞品优势。

仓库外上一轮任务审查仅证明摘要信息缺口，并因未有具体批量任务而未给编码准入。本次以明确多成员任务重新审查最小功能，不抹去其负结论，也不把“数学能区分”当作预测增量。TradingView已有 equity 回撤持续指标；这里的来源价格、单位和有限观察边界另有定义。

**最小选择：独立有界报告和只读入口，复用现有多股选择器。** 不改旧 universe API、输出、排序、最大回撤标量或首次峰见证；不往既有筛选语法添加字段。不做整段浏览器、排序/排名、自动成员、全市场、组合回撤、事件附件、概率、恢复预测、风险评级或回测。每股只保留三种代表及段数，三种代表可以指向同一段。

## 3. 唯一离散定义

公共来源数组长度 m=lookback+1，窗口位置 i=0…m−1。价格 C_i 为正精确规范十进制；窗口历史峰 M_i=max(C_0…C_i)。下跌段开始条件为 C_(p+1)<C_p=M_p，p取下跌前最后一次达到该峰的位置。持续平峰不产生回撤段。

给定峰 p，首次 r>p 且 C_r≥C_p 为恢复；跳过峰价的上涨也恢复。谷 v 为 p 之后至 r 之前的最低价首次位置；未恢复则取至 cutoff 的最低价首次位置。恢复点可以成为下一段的峰，随后平峰更新为最近一次相等峰。没有将“全历史新高”授予这些窗口峰。

每段深度 d=(C_p−C_v)/C_p，为正精确有理数；本片使用正的“跌幅”，区别于旧 max_drawdown 的非正符号，旧字段完全不改。最深代表比较精确 d，真并列取更早 p。最长已观察代表比较 s=e−p，其中已恢复 e=r，未恢复 e=m−1；并列取更早 p。它没有声称所有未恢复段最终完成后的最长者。当前未恢复代表为唯一开口段，可空。谷价并列取首次 v。

每个代表**独立携带自身** peak/valley/recovery/observed_end、depth_fraction、状态和跨度，不能把最深段深度与最长段跨度拼成一条记录。冻结字段：

- peak、valley、recovery（未恢复为 null）、observed_end：窗口 index、日期、原 source ordinal 十进制字符串、规范 close_exact。index用于跨度；ordinal仅定位，绝不做差。
- depth_fraction：约分非负 numerator/denominator 的十进制整数串；已选代表必有正深度。展示跌幅为固定4位百分数，附“显示舍入”说明，非零舍入至零时写“小于0.0001%”；不能按展示值决定相等。
- peak_to_valley_intervals=v−p；peak_to_recovery_intervals=r−p、valley_to_recovery_intervals=r−v（未恢复均 null）；observed_intervals=e−p；observed_is_lower_bound=(recovery is null)。未恢复文案“截至截止尚未恢复，峰后已观察 s 个来源区间；完整恢复跨度未知”。
- underwater_observations：已恢复 r−p−1，未恢复 m−1−p。它是严格低于该峰的来源观测数，与峰至恢复跨度不同；不声称中间所有真实时刻持续水下。
- episode_count 为已开始段数，recovered_count+open_count=episode_count，open_count∈{0,1}。无回撤时为0，三代表均 null；合格无回撤与不可计算严格区分，不可计算段数亦 null。

只报来源区间，不新增自然日换算，更不能写“交易天数”。首片不报当前点相对峰的跌幅：current_open.depth_fraction 明确是该段至今最深跌幅，避免误读为截止当天跌幅。

## 4. 有界算术与输出

由规范 DECIMAL(38,18) 精确转18位定标整数 P，1≤P<10^38；转换用 tuple 或精确 Fraction，禁止默认 Decimal context 乘法舍入。深度的分子 P_peak−P_valley 和分母 P_peak 均<10^38；约分比较交叉积<10^76<2^253，采用256bit专用上界检查，无LCM/对数/float排序。4位百分数可用整数除法与余数实施 ROUND_HALF_EVEN；乘10^6仍低于256bit。精确值极接近0或1不得被展示舍入变为无回撤或价格归零。

分析扫描理论 O(Nm)、每股只需当前段和两个历史代表；来源规范化排序沿既有开销，不能声称整条管线单遍或性能已测。无新依赖/通用缓存/队列。

报告固定 method=`observed-drawdown-episodes-v1`，规则版本绑定定义、来源规则、排序后的全部版本/batch/query IDs、cutoff、lookback及各股实际日期。成员显示按版本ID稳定排列，无数值排名。保留 source_qualified、window_qualified、comparison_available 三层资格、每成员全部有限原因码和计数。N行始终齐全；有效源数、有效窗口数、新摘要可算数分别以 N 为分母，不用幸存成员缩分母。全组失败时 comparison_available=false、可算0/N，所有代表/段数均 null；已核成员写“本成员已核，整组日期与来源尚未齐全”，不能嫁接别人的具体错误。结构/预算/原件损坏整请求错误不伪造N个计算结果。

整组关闭时仍保留成员自己的身份、来源资格、局部取窗是否成功、实际date_array、实际窗口长度、精确cutoff存在与否、完整自身原因码及已完成核验的异常计数。对自身完整有效的窗口保留原价端点供回查，并标明它们仅是该成员的来源证据；局部失败只保留已可靠核验的事实，不构造合格价格数组。所有成员的episode_count/recovered_count/open_count和三代表统一null，禁止先算好单股摘要再把它们放到失格比较表中。window_qualified只表示本成员自身窗口有效，不意味着跨成员可比；comparison_available全组统一。公共dates仅在整组通过时非null。

新报告仅输出每股≤253个 compact 证据端点（index/date/ordinal字符串/close_exact）、三个代表、完整有界日期数组、完整原因集合与全量异常计数。匿名异常例最多20项并明确 examples_truncated；这只限制例子，绝不截掉成员、失败原因种类、缺失/多余日期或总数。未评估计数保持 null，不能写0。源token不整段复制；既有版本/日期回查可读取原记录。来源ordinal串限制20位（超过则受控新输入错误，旧接口不变）；输出前完整序列化核对 compact UTF-8 JSON ≤2 MiB；最大合法输入不保证报告一定低于此界，超界整请求 `drawdown_result_limit`，禁止缩成员或删失败行凑预算。
