# 014 · 日线相对量与稳健基准

日期：2026-10-08。研究输入，**未授权该功能编码，未运行效果实验**。承接 [003](003-volume-microstructure.md)、[004](004-data-validity-and-evaluation.md)、[国内矩阵](006-domestic-capabilities.md)、[国际矩阵](007-international-capabilities.md) 和 [MC-02 已定案决定](../REVIEW_DECISIONS.md)。本轮只读产品文档、作者文章和三篇原始论文的指定部分；没有请求市场数据、执行 SDK、调整源值或改变现有数据资格。

## 1. 要回答的决策问题

1. 对一个已完成日，数量相对前 N 个可比完整交易日的平均水平有多大？
2. 前窗某个真实巨量日是否显著改变均值，导致均值与中位数比较出现分歧？用户能否直接核对该日与原量？
3. 当前数量离历史中位数有多少个历史 MAD？这里只描述位置与尺度，不赋予正态显著性、主动方向或下一日收益含义。
4. 分钟复盘进一步比较同阶段同槽量与截至该槽累计量；需要独立验证分钟时间边界、闭合与覆盖，不能由日线资格继承。

完整目标仍包括量价状态、同槽量能、换手、实际成交均价、微观结构和样本外决策效用。先解决原始数量的语义与跨日可比性，不能以一个无量纲比替代这些目标。

## 2. 当前证据能走到哪里

[实际日线验收](../qualification/tdx-daily-acquisition.md)记录古越龙山 7,068 条及独立 UInt32 数量对账；该报告明确经济单位、完整交易覆盖、永久证券身份与历史可得性仍 unknown/assumed。精确读出整数证明数值表示链，不能证明每一天代表相同的股数和成交范围。

设文件量为 `X_t = k_t V_t`。若整个窗口及当前日的倍率均为同一正数 k，则 `X_t / mean(X_j) = V_t / mean(V_j)`；共同倍率在中位数比、MAD 标准化距离中也抵消。**这是条件代数事实，固定 k 仍需证据**。若历史倍率变化、送转改变股份单位，或成交覆盖域变化，比例会被这些变化污染。当前缺少证据的实际数据只可保持“源数量及条件文件数值比较／可比性未知”，不能称为可比成交活动度。

MC-02 的首批行为保持：已知且生效的送转／拆并股后重新预热；保留原量，不自动因子调整。缺少可靠事件证据时维持可比性未知；“未发现事件”与“已验证无影响事件”分开。解禁、增发等需逐类研究，不自动套拆股倍率。回顾获得的公告也不能追溯授予当时可得资格。

## 6. 候选公式与精度（待合同反方）

令 `D_t` 为严格先于 t 的固定前 N 个交易所交易日；所有日期、同一证券身份、单位／覆盖、闭合状态及公司行动边界需有匹配证据。首个候选 N=20 沿用003，属于待验初值。不得跳过缺失日、停牌或问题日向更早历史补齐 N。

\[
\mu_t=\frac{\sum_{j\in D_t}V_j}{N},\quad
R_{mean,t}=\frac{N V_t}{\sum_{j\in D_t}V_j},\quad
m_t=\operatorname{median}_{j\in D_t}V_j,
\]
\[
R_{median,t}=\frac{V_t}{m_t},\quad
MAD_t=\operatorname{median}_{j\in D_t}|V_j-m_t|,\quad
D_{MAD,t}=\frac{V_t-m_t}{MAD_t}.
\]

中位数：奇数为中间排序值；偶数为中间两值的算术平均。MAD 使用该同一规则；当前日不入基线和 MAD。`D_MAD` 是带方向的原始 MAD 距离；不乘1.4826，不命名 z-score／几倍标准差，也不自动设3为统计异常阈值。未来若定义高斯校正版本，需单独公式版本、假设与有限样本校正研究。

**对象不同**：均值比较平均数量，中位数比较居中数量，MAD 描述偏离居中数量的尺度。中位数不替换主均值，更不删除巨量观测；极端观测可以是有效事件信息。稳健性仅表明统计对少数极端值较不敏感，不证明过滤掉了无信息量噪声。

**精确候选表示**：以整数和约分有理数保存均值、偶数中位数、MAD和比值（整数分子／正整数分母，JSON字符串）；排序、减法、加法和交叉比较均精确。`1/3` 不能有限十进制精确表示。显示用明确精度／舍入法的近似值，并保留精确分子分母与是否舍入。现有首批合同禁止派生除法、没有上述结果协议，故本页不能直接解冻实现；须先审查最小结果合同及全链API／导出测试。禁止DuckDB浮点除法、先转float再Decimal或把结果强塞进源值 `DECIMAL(38,18)`。

**异常返回**：未知单位／覆盖／股份可比性仍未知；基线不完整、重复标签身份未解、负量、缺失、未闭合当前日均不出可比值。真实零量保留；分母正时当前零量的两个比为0。均量／中位数／MAD分母为0时，各相关比为null并给出各自原因；即使当前也为0，MAD距离不输出0。不能用 epsilon、删零或跨窗补值避开未定义。

## 8. 编码阻断与完整推进顺序

1. **当前未通过的数据门槛**：`.day`股数倍率／成交类型覆盖、历史证券身份和公司行动事件版本；历史首次可得时点缺失。前四项阻断可比日量指标；最后一项限制为回顾研究，不能声称历史动态可得。
2. **当前未通过的方法门槛**：派生有理数结果合同、日历窗口／停牌政策、未知可比性展示与API资格、反方定案、独立异常用例。014只提供研究，未修改源格式合同或业务代码。
3. **下一份数据取证**：已有源文件与真实客户端导出逐日核对量单位、精度、覆盖；寻找官方单位说明及实际送转／拆并股样本。接口权限、时点和许可按各自来源核验，不能以免费下载等同开源或无限再发布权。
4. **可独立推进的功能**：单根源OHLC几何在其最低数据门槛满足后另立合同；它不消除完整量能门槛。分钟复盘和全市场主数据继续保留，不将原目标收缩为单证券图形。
5. **决策价值门槛**：未来冻结量基准／窗口选择、证券池、日期和全部尝试；对比仅价格／区间基准，检验量的增量；报告市场活动共同因子、极端事件、制度状态、停复牌及公司行动分层。依赖处理、多重试验、净成本、成交约束沿用004；单次同样本阈值优化不能关闭此门槛。

结论仅为研究建议：平均量主对照、中位数及原始MAD作为透明敏感性描述，严格因果前窗且不改原量。可比量能资格和预测效用目前均未取得。
