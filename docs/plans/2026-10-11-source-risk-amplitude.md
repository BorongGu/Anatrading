## 1. 为什么当前不值得优先实现

038只增加一个固定的近期高权重核和它的前序误差比较，没有新数据、学习权重或噪声识别能力。现有EWMA已经提供来源变化尺度。新核可能响应较快，也可能更追逐冲击；同平均滞后下，iid幅度世界的平方权重和由匹配EWMA的3/26增加到M的37/180，已有明确的估计噪声代价。此为假设下的代数反例，未运行市场实验。

对股票研究者，幅度估计将来可以帮助比较“哪一种风险参考在变化时更迟钝、平静时更不稳定”。但当前目标没有方向、下行概率、持有期损失或成交代价，无法据此确定追价、止损或仓位。未知复权/公司行动又可能把价格表达变化计入幅度。**目前只有方法审计用途，尚无值得新增功能的具体交易决策用途。**

一股60槽可揭示一个局部反例和冲击代价；赢一次不能建立方法价值，输一次也不能否定多尺度方法家族。没有用户有用差值或足够支持量依据，增加任意百分比门槛不能补上这一点。为它增加接口、测试维护和解释负担，当前收益不足。建议先解决价格及经济收益口径的实际缺口；相关只读研究由负责人另行推进，本文不重复搜索。

该决定只暂停038这个固定核切片，不否定037中风险幅度研究方向；也不修改034/035负结果或036同期解释的边界。

## 2. 保留已经审过的最小方案

| 项目 | 固定内容 |
|---|---|
| 对象/标签 | 单股日线；相邻合格来源组`r_j=log(C_j)−log(C_(j−1))`、`q_j=r_j²`；只预测下一来源区间q，不换horizon |
| 新核M | `(q_j+mean(q_(j−4)..q_j)+mean(q_(j−19)..q_j))/3` |
| 两基线 | B为EWMA，λ=23/29；E为现用半衰期20 EWMA，λ=2^(−1/20)。不恢复MA20，不增加对照或拟合 |
| 因果初始化 | B、E均从同段q1初始化；M在20个q后开始。预测q_(j+1)之前只能使用至q_j的数据；从完整有效前缀递推，不在显示窗或评价起点重置 |
| 主损失 | `L=(q−h)²`；h=q=0合法，负值/非有限为失败；无正地板、截尾、QLIKE或年化 |
| 解释 | q/h单位为来源log变化平方，L及配对差为其四次方；均为float64估计。B只匹配M的稳态平均滞后，不匹配全部记忆特征；初始化仍有暂态 |

来源仍使用既有Store完整前缀、`daily_bars/daily_coverage`及价格范围，不新建资格平台。原始Decimal/token保持不变。明确坏价、重复、身份/复权冲突保留原槽并断链；无定位错误不能借删行取得完整覆盖。无记录的日期不补0，不推断停牌或交易日。未知复权、公司行动、closed、known_at/PIT不自动阻止窄来源算术，也不授予经济收益或历史当时可交易含义。

精度沿既有`log(float(close))`估计边界，三模型使用同一q。相邻源Decimal不同却float或log相同，标明精度丢失，并关闭依赖该段历史的共同评价至显式断链后重新预热；不把舍入零当真实不变。非零量平方/均值下溢到0、溢出或递推失败均留原因，不裁剪救结果。全零链的合法0与数值下溢分开。具体误差界限尚未冻结，不能据当前方案声称所有精度要求已解决。

- 有明确且实际需要的用户判断，说明幅度估计将影响哪一步研究、何种误差有代价，以及现用EWMA为何不够；不能仅以“希望新算法表现更好”重启。

- 负责人接受与该有限用途相称的投入和后续证据要求；不能让一股60槽的输赢决定上线。若实际问题变成多日持有风险、下行损失或跨股组合，应新写对应方案，保留038原结论，不用换目标挽救本核。
