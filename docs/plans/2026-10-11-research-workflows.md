# 股票研究工作流与跨平台实施方案

状态：待独立反方评审，尚未开始产品编码。日期：2026-10-11。

## 长期目标与衡量方式

Anatrading 面向 A 股，并逐步扩展到国际股票。从单股日线、单股分钟线、双股日线、多股日线、明确成员的板块日线中提取可复算的交易研究信息。竞争目标是覆盖并逐项超越国内外同类产品的研究任务完成质量，不能把指标数量、运行成功或漂亮界面当成收益优势。评估分三层：计算与时点正确；同数据同任务的完成时间和解释质量；严格样本外、含成本和执行约束的预测增量。

用户优先级：算法与可验证功能 > 新增基础设施；代码直接、可维护、性能好；界面使用自然中文和清晰字体。真实行情由用户另行提供，合成数据只验证行为。

## 架构决定提案

### 一套跨平台内核

维护一个代码库。文件导入、DuckDB/Parquet、数学分析、HTTP、Web UI 支持 Linux/Windows。数据根锁 Windows 保留 msvcrt，POSIX 用非阻塞 flock；两者均保持进程级互斥，失败安全关闭句柄。Windows 通达信客户端与进程控制保持专用适配器，Linux 显式不可用。不能为了绿灯伪装 Windows 或跳过通用功能测试。结构解析使用明确固定宽度整数，避免 Linux c_ulong 宽度改变 Windows 二进制布局。

### 小模块与稳定边界

保留源 Decimal、原件哈希、错误保留、query_id 和导出协议。不全局更名快照键、不迁移数据库。分析用纯函数；必要的稳定 JSON 标识抽到不依赖存储的模块。新统计估计可用 float64，但必须标注估计与单位、拒绝非有限值；原始价格和金额不转换为浮点保存。

新分析紧凑返回每根柱的值、有效性和原因，不逐行复制所有窗口明细。不引入指标插件平台、任务队列或通用缓存框架。内部读取保持截止/来源身份绑定；原件校验不能被缓存绕开。先下推 SQL 范围条件并保留原语义；大文件上下文优化须明确递推初始化，不能截短 ATR/Kalman 起点后声称同一结果。

## 第一轮业务交付

### A 单股趋势与事件研究

- 因果局部线性 Kalman：对 log(close) 做 level/slope 过滤；固定公开参数，禁止全样本估参、平滑器与自动抹掉冲击；与 EMA 并列作朴素基线。只使用当前及过去柱，缺失/重复/无效价触发明确中断或重置。
- 原始 log 收益 EWMA 波动及标准化预测误差，使用原始收益防止平滑后低估风险；不在缺交易日历时随意年化。分钟版按观测柱而非统一交易分钟解释，隔夜需显式分段或说明。
- 固定前 N 根最高价突破事件（当日 close 大于此前窗口 high），规则不调优。发生时点为柱结束，状态和历史评价分离。
- 后续 h 根来源记录 close 变化作为描述性标签，未成熟标签不参与统计；输出事件数、有效/未成熟/无效、均值/中位数/分位数、正变化占比、全部有效日期基线。绝不称可成交策略收益，不报缺依据 Sharpe。
- 明确时间训练/测试切点；评估默认后段样本，标签越过切点从训练排除。同证券重叠事件按持有跨度去重或保留但清晰披露，不以独立样本标准误伪造置信度。无参数搜索、无买卖建议。

### B 双股关系

仅日线，两个数据版本按精确共同日期对齐，保留各侧缺失/重复计数，不填充。收益相关、滚动 beta、以此前窗口拟合的 log 价格残差偏离、相对强弱。参数至少窗口样本数；当期不进入此前拟合。零方差、几乎完美拟合、非有限、重复日期返回不可计算原因。不得将相关性/偏离称为协整、均值回归或套利。log beta 是弹性而非固定对冲股数。

### C 多股与板块样本

允许用户从已导入日线选择集合并指定同一截止日期，输出动量、波动、回撤与可解释排序，不合成神秘分数。广度分母同时报告所选、可计算和缺失数量；不把最后可用日不同的股票混成同日表现。板块只能是用户明确提供的成员集合/名称，不自动推断行业。当前成员历史回顾存在选择偏差，不宣称历史全市场或真实行业指数。

### D 界面

工作区为个股研究、双股对比、多股研究、数据管理；仅有实际 API 的入口开放。主要结论与图置顶，原始记录、版本标识、计算详情和长说明折叠。保持缺数据原因靠近结果。中文系统字体、13px以上主体、等宽数字、清晰键盘焦点、合理密度、窄屏无横向整页溢出。修复 panel 留白和 checkbox 宽度。前台称行情数据/数据版本、导入记录、计算说明，不更改稳定机器字段。

## 可验证接口约定（评审后冻结）

建议独立 research API 模块挂载到现有同源 FastAPI，复用 owner 执行器及查询权限检查。请求包含数据版本ID、截止、明确有界参数；双股两ID、多股有界ID列表。响应包含 method_id、输入身份、参数、样本计数、单位、限制及紧凑结果。所有公开路由严格拒绝未知字段/无效窗口、限制集合数量和总行数，避免任意大请求。

前端只显示服务端统计，不自行重算预测。新的多数据版本查询必须有一致截止，旧请求不能覆盖新选择。原导入/导出与图形接口保持兼容。

## 反方首轮意见后的参数与边界冻结

以下替换上文有歧义的部分，须独立复核后才编码。

1. 第一轮 Kalman 仅日线，分钟保持既有分钟算法并改善入口，暂不新增分钟 Kalman。观测单位为有记录日期，不承诺交易日等距；没有日历不能识别未记录缺日。显式坏行/重复日期中断状态链，下一有效行重新初始化并标记 reset；不得跳过坏行维持连续状态。参数默认 EMA 半衰期10、EWMA半衰期20、Kalman R=1e-4、Q=diag(1e-6,1e-8)、初始 level=首根log(close)、slope=0、P0=diag(R,R)。单位为 log-price、每观测步斜率；均为公开工程起点，非最优参数。Joseph更新，非有限值拒绝。前20个连续有效观测显示估计但状态为 warming_up，不产生趋势结论。参数边界为正且有限 R，非负且有限Q，半衰期1..252，最多20000行。EMA/Kalman全前缀初始化，不按图形窗口重新开始。
2. EWMA 首个有效收益以 r² 初始化，当前波动输出为当前收益纳入后的估计，冲击标准化使用纳入前的方差；首个收益无前期方差，冲击为空。Kalman标准化创新用本期更新前预测S。零分母结果为空并说明原因。估计不提供概率语义、置信区间或年化率。
3. 单股突破窗默认20、2..252；严格此前high最大值，不含当前柱。OHLC完整性满足low<=open/close<=high且价格为正，重复/坏行导致该窗口无效，不自动去除。历史事件默认观察跨度5、可选1/5/10/20来源记录；结果只统计评价截止前成熟且中间无坏行的标签。收益标签 close[t+h]/close[t]-1 是事后价格变化，并非成交收益。无成本扣除以避免将其伪装成策略。固定规则不搜索阈值。
4. 时间切点由用户显式 test_start 指定；未指定则只输出全段描述性事件研究，不使用样本外字样。训练标签终点>=test_start者标purged；测试决策日期>=test_start。每个h独立按日期贪心保留最早事件，之后事件必须 t_new>t_old+h；未成熟事件不能使用未来成败决定历史选择。统计报告原始/重叠排除/有效/未成熟/坏标签数量。不给独立样本置信区间，基线是相同截止/时间分区/有效标签范围的全部日期描述，明确其重叠依赖。
5. 双股按共同有效日期顺序形成两侧完全相同起止区间log收益，再算相关/beta。重复或坏日期保留为共同时间槽中的无效点，窗口不得跨该点跳接。各侧不相交日期计入对齐遗漏数，不能称每日收益，只称共同日期区间收益。窗口默认20、5..252；当前t的价差拟合仅用[t-W,t)配对log价并用训练残差尺度标准化当前值，相关与收益beta标明当前区间是否纳入；不算协整/半衰期。每根结果包含实际样本数，零尺度/退化回归单列。
6. 多股最多50个明确不同标的数据版本，日线、统一截止，至少2个。缺截止当日价不回退到各自末日；期末覆盖分母=全部所选，指标有效分母分别报告。默认20个有记录日期动量/波动/回撤；只排序某个可复算原始分项，稳定并列，不提供混合评分。用户分组仅称所选板块样本，不推断成员历史。未知复权、日历和历史可得性以结果级使用限制常驻标示，不进入“已验证交易信号”。身份无法判定的版本不得默认为不同股票；明确拒绝同一证券的重复版本。
7. 单请求总分析上限200000源行、单系列20000；拒绝大请求前先计数，不先构造全响应。新路由若加载整个历史超过预算明确返回边界，不承诺已修复旧API所有大文件上下文情形。SQL过滤优化和旧API大文件行为分开验收，保留尚未解决项，避免通过截断递推状态伪造支持。
8. 所有新结果继承 retrospective：前缀不变只证明算法不读取未来柱，不证明导出版本在历史当时已可得。SQL过滤必须保留label=NULL不受cutoff剔除、完整batch_unlocated_rows统计、准确ordinal范围与原件复核。POSIX锁文件不删除，避免不同进程持有不同inode的伪互斥。Windows采集的原生结构测试可按真正的平台依赖分组，但通用存储/API失败必须修复而非skip。

## 评审答复与接口冻结（2026-10-11）

- R1采纳：首根只初始化不二次观测更新，创新为空；固定对角参数不开放HTTP矩阵输入；返回segment_id、warmup和reason。模型与原始收益波动分开。研究数学只能有条件解释冻结来源。
- R2采纳：Decimal判断突破；参与OHLC合法性不被volume/amount缺失阻断。本轮所有标签价要求正数，零端点返回invalid_price而非-100%，与旧020源值算术明确区分。Type-7线性分位；基线只纳入同分区、突破前窗可计算且标签成熟/路径有效的日期，包含事件日期；非随机对照。信号日期与评价截止分开，不使用样本外有效声称。
- R3采纳：Y=left、X=right；窗口W>=5，训练残差尺度sqrt(SSE/(W-2))，残差标准化当尺度<=1e-10（log-price单位）不可算，X样本方差<=1e-12时回归不可算；相关的任一收益样本方差<=1e-16不可算。相关基于截止t的最近W个共同区间收益（含当前），log-price回归仅此前W个共同日期。保留可定义的beta/相关，不因残差退化全体作废。相对强弱=(A_t/A_base)/(B_t/B_base)-1，base为首个共同有效日期，坏组中断后基准可保留但滚动窗口不跨坏组。首轮要求可识别的不同证券与相同市场；未知市场/不同市场明确拒绝或缺资格，不伪称同步。响应保留左右角色。
- R4采纳：N=20默认；动量=C_t/C_(t-N)-1；波动=该N个相邻log收益样本标准差（ddof=1，不年化）；最大回撤=min_j(C_j/max_(k<=j)C_k-1)，窗口N+1个日期组含当前。每指标回显真实起点，命名按来源记录窗口，不称共同日历期间。广度首版是正动量占有效动量数，附有效/所选覆盖。按动量降序、并列同名次（competition ranking）、身份字典序稳定。拒绝同证券多版本与无法识别身份。成员元数据必须来自可识别source_code或显式interpretation声明并披露来源资格，不能伪造真实行业归属。
- R5采纳：沿用同源GET和owner执行器。路径为 GET /api/research/single/{snapshot_id}（cutoff可选、lookback默认20、horizon默认5、test_start可选）；GET /api/research/pair（left/right/cutoff必填、lookback默认20）；GET /api/research/universe（snapshot_ids逗号分隔、cutoff必填、lookback默认20）。不接受ordinal窗口，确保递推固定起点。日期须严格ISO日线，不支持未知参数/重复参数/重复ID。集合最多50、每上下文20000、总200000，按实际截止范围预检，失败整份请求并给简洁错误码。返回统一 envelope：method_id、analysis_id、inputs（有序输入snapshot_id/query_id）、parameters、mode=retrospective、limitations、result（方法专用结果）。analysis_id绑定method_id/inputs/parameters，identity序列化沿用稳定实现。单股result含series与events，双股series与alignment，集合members与breadth；数值估计注明float64，源值不变。研究输出独立于旧大明细API。
- R6采纳：POSIX/Windows锁仅承诺已测试本地文件系统，不承诺跨OS网络共享。SQL/null/计数/原件/身份完全等价。Windows结构固定宽度需回归验证；Linux通用测试不能通过skip掩盖。
