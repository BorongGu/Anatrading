Node 用例覆盖的是实际产品使用的输入转换、身份绑定、结构检查和异步请求控制逻辑。SSR 用例只核对 React 静态输出中的文字、元素、属性、来源与失败证据。局部 CSS 可经源码核查，不能据此声称布局或触屏已验。
