## 3. 源量化与新增舍入是两笔误差

实际单元：`sh688001.lc1` 第 1 条 high，字节偏移 8，原位模式 **`0x4214147b`**，精确值为 **`37.020000457763671875`**，必要 scale=18。位模式先解为 Python float，再用 `Decimal.from_float`，可精确保留这个 binary32 数值；这一步不会恢复上游原来的成交价。[Python Decimal 构造与 from_float](https://docs.python.org/3/library/decimal.html#decimal.Decimal.from_float)

- `源量化误差 = 已存 binary32 值 − 上游真值`：缺少生成链时，上游真值未知。若额外假设原值为 37.02，则差为 `+0.000000457763671875`；该假设不能写成原文件已经证实的事实。
- `系统新增误差 = 进入系统后的值 − 已接收精确值`：若直接改写成 37.02，就新增上述差额的相反数。显示层可以按明确规则格式化，证据值仍须保留。
- 静态可表示性检查显示：把候选分钟 OHLC 放入 scale=16 的列，会使 `.lc1` 的 **8,139** 个、`.lc5` 的 **422** 个单元无法精确表示。scale=18 可容纳本批全部精确展开值；这不是未来保证。人工边界 `0x3f800001` 就是有限 binary32，精确值 `1.00000011920928955078125`，需 23 位小数；它**未出现在本批样本中**。

ULP 描述该数值附近的 binary32 间距，不能自动作为所有源字段的接收容差。只有已证实的最近舍入、单位和生成步骤，才能支持相应量化误差界；上游累计差分、粗量化或跨时段分配需另取证。

## 4. 最小合同选项：留给 G2 定案

官方边界：DuckDB `DECIMAL(p,s)` 当前最大 p=38，s 非负且不超过 p；未写参数的默认值为 `(18,3)`。含 Decimal 的除法返回浮点结果，不能由“输入为 Decimal”推出 VWAP 结果仍精确。[DuckDB Numeric Types](https://duckdb.org/docs/current/sql/data_types/numeric) Arrow decimal128 的精度为 1—38，decimal256 为 1—76，采用缩放整数；Arrow 可表示的类型不自动证明 DuckDB 往返可用。[decimal128](https://arrow.apache.org/docs/python/generated/pyarrow.decimal128.html)、[decimal256](https://arrow.apache.org/docs/python/generated/pyarrow.decimal256.html)

**分钟二进制负例的身份/语义尚未合格，scale=18 只证明其候选解码的表示需求，不能迫使首批正向格式共用该 schema。** 更简单的可选路线是先限定已验格式的明确无损范围，隔离未支持精度并保留原证据；后续数据源通过独立合同加入。范围须有显式依据及越界行为，不能直接采用小样本最大值。

| 候选 | 保真方式 | 尚待决定/验证 |
|---|---|---|
| **A · 原件加显式定点列** | 原字符串/原位及定位保留；先精确解析，再检验是否满足具体字段 `(p,s)` 和整数范围。只有值可无损表示才进入该列。 | p/s 按品类、源字段和用途定案；当前最大值只作验收样本。需实测 Arrow→存储→读回值、空值、边界、溢出及聚合；不得靠默认 Decimal 参数。 |
| **B · 原件加精确十进制文本** | 精确十进制作为可重建的中间证据；Python Decimal/整数完成已定义计算，固定 Decimal 列作为通过范围检查后的派生材料。 | 运算 context、聚合精度、性能和查询代价需验收。它保留数值，不补齐身份、单位和时点；也不要求先引入更复杂的高精度数据库层。 |

**超精度隔离原则**：区分非法/非有限、幅度越界、小数不可无损表示、单位未知四类原因；保留原件、字段定位、目标类型和失败理由。不得通过 Float/Double 中转、截断、自动舍入或改成 0 使其通过；失败单元及依赖输出退出相应分析资格，其他用途另作判定。去掉纯尾零不改变数值，但原 token 的格式证据仍保留。

Arrow `CastOptions` 默认不允许整数溢出和 Decimal 精度截断，可作为候选入口；仍需对实际版本和完整桥接路径实测，不能只凭配置名签署无损保证。[官方 CastOptions](https://arrow.apache.org/docs/python/generated/pyarrow.compute.CastOptions.html) VWAP 等除法的舍入属于派生量合同，应显式给出精度/舍入与误差，而不回写原始金额或数量。**本轮未安装 DuckDB，未执行 DuckDB/Arrow 往返；合同选择保持未定。**
