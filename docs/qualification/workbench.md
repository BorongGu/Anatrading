## 4. 发现的界面缺陷与竞态界限

反方先发现来源合同字段嵌套读取不符、`.day` 复权状态误标及 tooltip 缺单位资格。修订后页头、十字线和固定详情都从当前合同的 `source_semantics.fields` 读取；来源定义、样本适用性与规范单位分别保留，详见 009。

真实图形随后发现零量与异常两套 marker 同处基线，文字向下绘制且被裁剪。最终每条源记录只有一个向上排字的状态标记，0、0 !、∅ !、! 可区分；人工 7 条窗口的 `0 !` 与 `∅ !` 已在截图中可见。Histogram 的 0 与缺量空位保持原状，状态行注明位置不表示数量，未用非零柱伪造零值。

竞态夹具为 `$run/race_server.py`，仅运行在独立人工数据根及 `127.0.0.1:8767`。包装层不改真实 ASGI 状态／头／体，先执行内层查询，再用释放文件延迟响应，最多 60 秒；产品代码未加入测试钩子。

- 第一组：旧 A 成功捕获于 20:28:42 UTC，浏览器切 B 后再切同 A，此时该副本 raw 缺失，最新 A 明确失败。20:29:23 释放旧成功后，错误、无图、无详情、无下载仍保持。
- 第二组：20:30:10 捕获真实 raw_object_missing，恢复 raw 后浏览器切 B 并固定行；20:30:27 释放旧失败，B 的 Q `47735ae9c672b0feb26c366bb99e1375733b7f61924d87fb6c0ee3d7260828fd`、精确详情与可导出状态保留。
- 两组 `events.jsonl` 都在释放前记录 `http.disconnect`。因此实际浏览器结果证明取消与延迟路径隔离；不能只据它将成功归因于 generation 守卫。后者另由 Node 的 ABA、旧成功／失败与错 Q 用例核验。
- 所有暂移 raw 都已恢复，并由独立反方核 SHA。正式个人原件未参与故障操作。

## 5. 性能结果与下一步约束

同机真实 Uvicorn 上顺序 GET，每组 7 次；从请求开始到**完整响应体读取结束**计时，SHA 与 JSON 解码不在计时内。p95 使用最近秩，第 7 个样本即最大值。服务未重新导入材料，无预计算响应缓存。

| 输入 | 全响应字节数 | 优化前 p95 | 优化后有效 p95 | 500ms 条件 |
|---|---:|---:|---:|---|
| 真实日线 4,995 行 | 8,982,005 | 1.130s | **0.464087s** | 本组达到 |
| 真实 1m 15,840 行 | 28,603,209 | 3.553s | **1.372768s** | 未达到 |
| 人工 20,000 行 | 35,512,513 | 4.406s | **1.832988s** | 未达到 |

优化只有两处：直接返回已准备好的 JSONResponse，跳过 FastAPI 重复递归编码；`type(value) is Decimal` 时复用不可变原生 Decimal，子类／其他类型仍走原构造校验。数值上下文、非有限拒绝、类型、范围、精度、Schema、Q 和响应全部内容保持不变。20k 前后响应 SHA 相同：`0fef926561603d0603435fff528e33e66373c43686a239df83af9778ff422de6`。

第一轮优化后 20k 组因一次浏览器日线查询可能重叠，整组排除。上表采用 20:17:51–20:18:07 UTC 独立补测，7 次为 1.8330／1.7644／1.6871／1.6936／1.7073／1.6715／1.7588 秒。保留原记录，补测文件 `http-performance-optimized-20k-rerun.json` 的 SHA 为 `3b0ed4312acafc3e7d2e2d240857bce3ee3727d2374bce7cf0c2ebb11b532eb4`。独立进程内 ASGI 的 1.660502 秒结果另列，未代替真实 HTTP。

剩余开销主要涉及整批 DuckDB 取数、逐行原 token／checks JSON 解码、Decimal 转字符串与完整 35.5 MB 响应序列化。私有 `performance-next-step.md` 提出有限的完整 JSON 生成实验，须另过反方再改内核。不得用少返回字段、缩小 20k 预算、只计首字节、缓存掩盖冷查询，或降低门槛关闭 WB10。首次可交互、浏览器 JSON 解码／绘制及重复次数须独立补测。
