# 条件收益重建纯核心：合成验收

2026-10-11。依据[040研究与实施约定](../research/040-data-gap-next-step.md)，新增 `conditional_return_report` 及两套合成测试。独立设计与实现审查见[复核记录](../reviews/2026-10-11-conditional-return-core-review.md)，冻结版验收与独立终审接受限定纯核心发布。本片只验证显式前提下的条件算术；真实来源兼容、历史当时可得性、预测和交易增量均未验。

## 范围和结果含义

单证券、单币种，从1股、零现金、零应收开始。调用者给定严格有序的原价与普通派现/送转标准事件，显式声明未复权、区间事件完整、全部股份同权及证据引用。输入声明始终标成 `caller_declared_unverified`，函数不认证来源，也不接039原串。

- `fixed_shares_cash`：送转改变持股，现金不再投资。现金权益按每次事件前持股冻结，未付列应收；到期仅该笔由应收转现金。应收按税前面值、零利息、零费用、无违约/修订计值。
- `ex_date_close_reinvestment`：独立股份递推，现金权益按有效日收盘变成碎股，允许提前使用应收；支付日不再增加价值。它是明确的合成约定，没有证明真实成交、自融资或可执行性。
- 每期分别返回股份、股票价值、总价值与累计收益。固定法另给现金/应收，再投法这两字段为 `None`。每事件权益明细提供旧股、现金权益、送转与再投股数；这些字段不能称为可相加的收益归因。
- 100→90派10→99两路径为9%/10%；100→90派10→80再派10→88为8%/10%。除息当天相同价值并不足以验证后续路径。送转后48仍保留−4%价格损失，不强迫事件日收益归零。

没有修改旧源码、旧测试、依赖、Store、CLI、HTTP或界面。新增核心没有I/O；本片未联网取得真实行情、运行真实收益重建、操作真实数据库或公开部署。原价独立核对0/15、037/038和039资格均不改变。

## 最小输入和数值边界

价格与事件仅收list/tuple，最多20,000个价格、19,999个事件。日期仅收 `datetime.date`；价格日期严格递增且首末日等于声明窗口，每一有效事件晚于起点并具有当日收盘。事件ID唯一，每日只接受一个明确合并的普通事件。未知、部分资格、配股、负值、全零事件、缺原价、缺日期或股份延迟生效/交易都整次拒算，不删事件继续报告。

现金大于零时支付日必填，可晚于观察终点；没有现金时支付日须为空。送转大于零时股份生效与可交易日均为有效日，没有送转时两日须为空。先结历史已到期权利，再建本日权利；新事件同日支付直接归入现金。无报价支付日不伪造报价或收益，只在下一观察的现金分类反映，明细保留原支付日。逆序支付先按支付日排序，同日保留有效日顺序；总复杂度O(T+E log E)，归并O(T+E)，空间O(T+E)。未作性能基准或跨平台资源声明。

精确字符串/Decimal沿用 `DECIMAL(38,18)` 输入范围，拒绝int/float/bool及非有限数。所有计算在独立50位、ROUND_HALF_EVEN、Emin=−999999、Emax=999999环境中执行，不继承或修改调用者全局context。股份、权益生成、再投比率和估值可舍入；先冻结每笔 `q旧×D`，再投份额为该金额除以有效日收盘，加入 `q旧×(1+b+c)`。

固定法现金与应收加减必须在50位内保留已冻结金额之和；否则报 `arithmetic_resolution`，不吞小额权益或扩大精度。此边界也适用于累计到账现金。其余无效输入由 `ConditionalReturnError(code, field)` 明确拒绝，不返回部分成功。输出Decimal属于这一有限精度约定，不能称所有值为精确有理数，更不认证金融数据。
