## 实际验证链

30 份原始捕获各 640 行，共 19,200 行，仅向全新隔离 Store 各导入一次，全部提交且未复用旧导入。逐一核对原始字节、清单、封装及既有来源审计；全部 11 个映射 token 字段、源序号、定位、来源/日期标签及原始嵌套对象均保留。

独立参考直接读取原日期/收盘字符串，以 Fraction 精确运算和前缀峰下的连续回撤游程枚举生成结果，先落盘再执行产品；另一个审查者从原捕获逐候选峰枚举，不导入产品或该参考，也不访问 Store。两者核对全部 60 行，包括首个最低谷、精确深度、半偶舍入、代表及并列、恢复/null/下界和跨度。

实际链路覆盖新 Store → 完整及投影纯函数 → 进程内 ASGI API → 运行时 DTO/分析身份校验 → 实际组件静态 SSR。每案保留十个成员，88 次代表回查均使用对应成员的数据版本及该代表的观察结束日期。所有来源先完整计数再加载，无截止物化过滤；不可比较的三案在完整、投影及 API 路径均为零摘要运算，六个摘要字段均为 null。删除成员、破坏计数的变异响应被拒绝。

三个可计算组共观察到 144 段：116 段已恢复、28 段未恢复；四个成员的最深代表与最长代表不同。未观察到真实“无回撤”成员，不为补齐类别制造恒定、重复或损坏捕获。
