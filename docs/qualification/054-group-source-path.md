## 实施范围

- 真实请求expected由既有请求控制器透传；原050 API、校验器、旧身份、窗口和三代表均保持。
- 一套前端BigInt共同分母核，完整父内容Unicode canonical SHA256，全部输出绑定独立附件身份，冻结证据副本，取消和每8日期合作让出。
- 全组不可算无曲线/深度；合格无正回撤保留曲线及0深度，峰谷/贡献null。所有成员同一见证下的正、负及零项保留。
- 完整曲线子面板也默认折叠，只有展开才计算显示分数并挂载全部日期行；关闭卸载表格，新附件重置子面板。没有截取数据、分页、额外图形框架或依赖。
- 原起点/共同峰/共同谷均保留原版本、日期、序号和收盘价；按钮准确打开原版本截至该日，不承诺按源序号聚焦。

## 测试历史与真实缺陷

1. 编码前先写异常父DTO、真实请求不符、取消、输入突变、负微值及预算测试。首次运行缺少尚未实现的模块，Node报告1文件失败；这是预期RED，不计产品失败数量为零。
2. 首轮扩展产品算术检查34通过、1失败：有效050近零深度包含中文“小于0.0001%”，原filter canonical仅接受ASCII，无法hash完整父报告。保留050旧身份核；054单独使用递归稳定键序、Unicode原样JSON及有限数值的完整canonical，追加真父Unicode/键序/拒绝不合法字段回归。未改数学预期、价格资格或既有来源规则。
3. 首个完整回归792项通过、构建通过；独立代码检查随后发现闭合的完整曲线details仍在渲染253行并做约分。改为局部toggle延迟挂载。此为避免无用工作的改进，没有测得响应性能失败，也未增加性能承诺。最终代码再次运行相同受影响及完整回归。
4. 更早概念测试首轮125算术断言通过，但T7重置夹具把原序号2/3变成1/2，独立来源证据审查失败；仅修夹具保留原行后126断言通过。此历史保留，126不与产品测试相加。

`tests/group_source_path_fixture_bridge.py`只生成合成来源DTO，不实例化Store、不读取行情/数据库、不联网。数学期望从原价用独立Fraction逐项求平均，并枚举全部严格峰谷对；全界样本用已知共同高/低的解析见证。所有期望均独立于候选。

- T1–T7及协议修订：T2为2/21；同段1/7和−1/21；T3最早谷/此前最后同峰；起点、整列倍率、输入置换、固定截止后合法价不变量；两点重置5/72属于公式对照，真实入口拒绝1区间。
- 实际050来源纯函数合成失败：缺中间行、合法独立序号重复日、零价、未知行、未来全局反证、源拒绝及同首尾中间网格不同。全部保留原失败/null，没有幸存子组。
- 1e−18近峰/近深度、极小负抵消、四身份复制、每个T3合法前缀、最大/最小DECIMAL价、50成员253点、大于256bit共同分母及所有精确贡献加总。
- 完整父内容/输出hash、相同analysis_id下自洽改价/序号/资格、键序等价、有效中文近零摘要、非法Unicode原因仍被050拒绝、输入和旧结果冻结/不漂移、开始/批间取消、准确8日期批次。
- 元数据16KiB和最终2MiB的UTF-8边界及边界+1拒绝；所有成员/日期完整；有符号四位半偶舍入、零与微值。
- SSR默认折叠、缺真实请求不计算、同段文案、全ID/date按钮、无正段与不可算、完整50成员及展开表的253行。SSR没有执行浏览器DOM生命周期。
