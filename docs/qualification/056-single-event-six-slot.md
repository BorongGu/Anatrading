## 保留的失败与修复

首轮 `2efadc0fbe064670357270f0edef698a19d9083c` 不通过最终验收。普通58项流程通过后，独立继续攻击发现两项真实所有权缺陷：

1. 同query_id上下文A→B→A恢复旧展开；四种版本/截止/序号变化均复现。
2. 原响应保留的Close/Escape/toggle能关闭新响应明细；三种回调均复现。

首轮7项失败随后扩展为12项失败：新增未完成请求的旧成功/失败，以及同代次旧事件A的Close/Escape/行点击影响事件B。它们属于上述两类根因，不能用原普通流程通过覆盖。最终修复完整上下文永久失效和当前选择身份守卫，12项全部转绿。保留原失败，不更改合格定义。
