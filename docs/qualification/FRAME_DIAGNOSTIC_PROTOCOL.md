# D01 · 单次帧结构诊断

日期：2026-10-04。前置事实：原[自动取数协议](AUTOMATIC_ACQUISITION_PROTOCOL.md)的首轮已停止，证据目录`artifacts/qualification/baostock-acquisition/20261003T183357030285Z/P01/`，status SHA-256 `5a90f2831f8f9d033ec63929cc6bbf022d9f9228c4867157f1f85475fd319086`。仅1次行情请求、0页保存，P02/P03未执行。

## 原因仍待证实

受限传输将压缩帧长度写成`21 + 声明体长 + 13字节尾标`。官方SDK只切出`[21:21+N]`解压、等待末尾标记，未验证中间尾段。纯内存构造额外分隔数值尾段可复现两者差别，但真实失败没有记录类型/长度/分支，尚不能认定实际尾段为CRC。

## 只允许一次追加观察

反方建议并条件接受独立D01，主方采用如下固定边界；离线负例通过、反方核读后才运行。

1. 仅P01原参数的第一页：`sh.601577`，2021-01-04—2021-03-31，5m、adjustflag=3、固定10字段、页1/2000；最多发送1次行情请求。禁止next/get_data、后续案例、自动重试、换参数/端点或切换凭据。
2. 独立子进程，socket最多8秒、每交换绝对10秒、父进程45秒；发送和接收的UTF-8/线路字节合计最多5MiB。先限量取得21字节头；仅在固定行情请求、合法96头且声明体长在预算内时，观察声明体后最多64字节或完整尾标（先到即止）。声明超限/EOF/期限耗尽立即失败。不得为了寻找尾标继续无界读取。
3. 登录/登出仍用原受限传输，不保存或输出其载荷。对01/03/其他未知包只留固定安全码。行情观察也不保存头/体/尾原文、hex/repr/base64、载荷哈希或原异常文本；不解码或归档行情记录。
4. 固定允许的诊断字段：解析后且形状受限的协议版本/类型、声明压缩长度、累计已收字节数、原判定分支枚举、尾标出现/位于缓冲末端、声明体后至标记的字节数、尾段形状枚举`empty/decimal/soh_decimal/other`、数字串长度、是否达到64字节观察限额。实际尾数字不保存。
5. 只预先指定一个CRC候选：若尾段严格为可选SOH加1—10位ASCII十进制且数值为uint32，则在内存比较其与`zlib.crc32(头21字节 + 声明压缩体)`是否相等，仅保存匹配布尔。依据是官方SDK请求端对head+body的CRC32计算；响应是否同域仍是假设。禁止现场遍历算法、候选区间或编码直到命中。
6. 原strict transport及业务接收判定保持不变。D01无论观测是否完整，最终均为`diagnostic_incomplete`、pages=0；不标获取成功、不写产品数据库、不运行P02/P03。新的诊断目录关联原run与本协议/代码哈希，不覆盖原失败证据。
7. 结束后关闭连接；父进程确认worker退出。只有观测足以明确机制时才提出最小修复，修复和下一次实测范围须单独复核。

## 必需离线证明

尾标拆包、额外尾段、声明超限、尾段达到64字节仍无标记、EOF/绝对期限/累计wire限额；控制包含唯一敏感标记时所有保存输出均无标记；行情发送计数最多1，后续SDK分页方法不能触发网络；全流程无page原文文件。诊断元数据严格使用上述固定键和值域。
