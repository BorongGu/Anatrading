# G1 · 数据资格验证协议

日期：2026-10-04。依据已通过反驳的 [总方案](../MASTER_PLAN.md)、[架构](../ARCHITECTURE.md) 与 [门禁记录](../REVIEW_DECISIONS.md)。本阶段只进行只读采样、独立解码和对账；原型继续冻结。

## 本轮有限任务

1. 独立复算现有通达信公开历史文件，比较同股票的完整 1m→5m 窗口；记录原始哈希、量额总数、逐字段差异及严格均价边界。精度解释与纠错分开，不能通过放宽阈值消除异常。
2. 使用官方 BaoStock 0.9.4、匿名公共服务探测少量未复权数据：`sz.000001` 的 2021-05-13～14 日线、`sh.601577` 的 2021-02-26 五分钟、同股票的 2026-09-30 五分钟。后两项分别验证旧区间可取性和较近盘后数据；不代表实时能力。
3. 核对当前官方文档与 SDK 的单位、复权、分页、错误行为；记录支持、未知和实际失败。真实客户端导出、沪深京覆盖分母、盘中观察仍单列未完成。

首轮三组成功后，只给同一银行的两个已取得分钟日期各补一条日线，检验日/分钟量额守恒。通过固定案例选择单独执行，避免重取已有请求；累计五组仍属于小样本探测。

## 采集约束与停止条件

- 官方安装包固定版本；记录本机 Python 与关键 SDK 文件哈希。每个探测在独立进程运行，socket 等待上限 8 秒、单次进程上限 35 秒；不自动重试、不更换服务器、不使用 Key、VIP 或账户权限。
- 每个查询最多两日或一日 5m，远小于 SDK 单页 2,000 条。只调用 `login`、`query_history_k_data_plus` 与 `logout`；行情保存时只截取查询响应，认证/控制响应不归档。
- 保留 SDK 解压/解码后的行情响应及其哈希、字段与字符串单元格；该响应明确标作 SDK decoded response，不能称为网络原始包。原始字节级证据另行验证。
- SDK 错误、空结果、字段变化、非字符串数值、分页达到上限或进程超时均不能计作合格源。部分数据保留为未完成证据，不悄悄当作完整区间。
- 登录失败时停止该轮后续行情查询；实际发生的 socket 异常和 SDK 错误码分开记录。证据不足以区分本机网络、服务端或 SDK 原因时保留未知。
- SDK 输出仅在子进程内捕获；公开报告只使用明确筛选后的非敏感结果。个人数据、行情载荷和运行产物留在忽略目录，不进入公开仓库。

## 成功标准与结论等级

| 结论 | 必需证据 | 本轮限制 |
|---|---|---|
| 可连接/可返回 | 当前环境的请求时间、版本、状态、实际返回行数 | 一次成功不代表持续稳定 |
| 样本格式可解释 | 源字段字符串、单位证据、结构/时间/数量检查 | 同名字段不自动拥有同一语义 |
| 样本对账一致 | 同证券、日期、复权、阶段与单位，逐字段比较 | 历史来源相同不构成独立市场真值 |
| 可用于研究 | 数值/时间合同、覆盖、质量、历史可得性资格 | 本轮不能自动获得此级别 |
| 当前软件兼容 | 指定客户端版本实际导出和接口对照 | 第三方历史文件不能替代 |

每次运行记录实际失败和未完成项。G1 全部验收尚未通过前，不能将这份采样结果用作 G2 全部开工许可；合格子范围需要独立合同与对应门槛。
