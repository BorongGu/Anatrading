# 首轮有限任务与验收清单

版本：v1.0。当前只冻结首轮任务和后续分解规则；**所有实现验收均未通过**。总体方案定案与产品完成分开。对应工程阶段为 G0–G7，研究方法验收另用 004 的 R0–R5。

## 任务清单

每项实际开工前绑定 `产品全名/版本/接口版本 + 叶子功能 + 用户任务 + 输入快照 + 数据资格 + 验收预期`；当前未取得的版本/样本明确待填，不能凭软件品牌补齐。

| ID / 阶段 | 有限用户任务 | 比较对象与输入要求 | 独立验收产物 |
|---|---|---|---|
| T01 / G1 | 从通达信本地接口取得指定股票与日期的未复权日线 | 支持TQ的实际客户端版本；相同股票/范围的真实导出 | 请求/源单位/逐字段对账、错误路径、权限与费用记录 |
| T02 / G1 | 读取同花顺普通客户端一份真实日线和一份分钟导出 | 当前客户端版本、实际导出路径和字段说明 | 原文件哈希、列映射、价格/量额/时区/闭合状态对照；取得前保持未验收 |
| T03 / G1 | 自动取得指定证券的历史1m/5m与盘后当日分钟 | 各源单独资格；不得用5m声称1m已支持 | 首末覆盖、逐字段对账、缺口与交易阶段表 |
| T04 / G1/G3 | 判断盘中最新闭合分钟是否确实到达 | 实际盘中源；完整交易日观察；客户端时钟与源时点证据 | 到达/修订/断线回补记录；旧数据轮询不能通过 |

| T12 / G2 | 从日线定位并联动到指定分钟区间 | 同证券同口径；实际数据与产品版本 | 浏览器操作、OHLC原值提示、量单位、阶段/午休、缩放和导出一致 |

| T17 / G4 | 复算一组含交易限制和公司行动的模拟成交 | 日期/品种适用规则、成本、不可成交情形 | 现金/证券账本手算、费用/股份变化、柱内顺序上下界、净值一致 |

## 使用规则

1. T01/T02等当前版本未填或真实文件未取得，状态保持未验收。第三方公开历史样本在 [005](research/005-sample-evidence.md) 中单列，只覆盖其实际字节。
2. 同任务对比先冻结软件版本、数据快照、设备、负载、冷/热缓存、后台更新情况、资源上限和重复次数。网络源延迟与本地处理耗时分开；未定负载时仅记录测量，不先判通过。
3. 几何实现、流程效率、统计增量、成本后价值为四个独立结果。T14公式正确不能替代T16；T16完成负面研究不构成有效性通过；T18不能代表全市场扫描性能。
4. 功能族F01–F17的全部细项尚未分解/调研，不能依据此首轮清单宣布完整项目完成。G5逐笔/盘口、G6组合/中长期、G7竞品全量对照必须先各自冻结新增叶子任务。
5. 对完整竞品清单逐个补齐版本、公开高级功能、所需数据和可复现任务。无法取得算法/数据的功能保留限制与未完成状态，不从通过率分母删除。
6. 每次迭代的验收对象有限、可复现；新增软件/功能进入显式变更清单。终验必须对原始目标及当期冻结总清单逐项核对，不能把版本冻结作为删掉原需求的理由。
