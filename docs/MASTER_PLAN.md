# Anatrading 总体方案

状态：v0.1，反方评审草案，**尚未通过编码门禁**。2026-10-03。

## 1. 用户目标与产品定位

建立个人 A 股交易研究与决策工作台。基于免费、可合法取得的数据，自动收集并精确处理价格、成交量等信息，形成可复核的量价解释和交易研究证据。覆盖日线波段、分钟级日内研究、中长期择时与组合管理。优先顺序已确认：**日线判断波段，分钟选择时机与复盘**；优先同花顺与通达信；真实软件数据验收必需；公开 GitHub 仓库。

用户要求“调研国内外常用软件的高级功能，复刻并超过”。该要求保留为完整项目目标。落实为：逐产品、逐功能建立对照清单，独立实现功能，并在相同数据和任务下比较准确性、透明度、操作效率和决策证据。不能用首版完成、指标数量或一条回测曲线代替完整目标。

## 2. 三种产品结果

| 结果 | 用户得到什么 | 证据要求 |
|---|---|---|
| 描述事实 | 价格结构、量能相对位置、波动、交易时段、异常与数据缺口 | 原始字段、公式、单位、来源、可用时点可追溯 |
| 研究假设 | 形态、事件、市场状态与后续收益/风险的关系 | 冻结定义、样本外检验、基准、区间估计、多重试验记录 |
| 交易方案评估 | 考虑仓位、成本、交易制度、不可成交情形后的组合结果 | 成交仿真、风险归因、稳健性、纸面验证 |

一个条件可以是可用的描述工具，同时缺乏预测证据。界面必须允许显示“未检验”“证据不足”“失效”，不能把所有统计压成一个买卖评分。

## 4. 竞品研究的完整组织方式

首轮已建立 13 个产品/终端的初步对照，详见 [001](research/001-data-and-price-volume.md)。下一轮覆盖 Wind、iFinD、Choice、同花顺普通/L2、通达信普通/研究接口、东方财富、大智慧、富途、文华、博易、券商 QMT/PTrade；海外覆盖 TradingView、StockCharts、AmiBroker、MetaTrader、MultiCharts、TradeStation、thinkorswim、Sierra、NinjaTrader、Bookmap、ATAS、Quantower、QuantConnect/LEAN。

该名单是初始研究样本框，不声称囊括全部常用软件。后续按用户使用和市场证据扩充；同一底层软件的券商包装版单独记录差异，无差异者合并测试。

每项功能记录：产品/版本、功能定义、所需数据、算法公开程度、免费/收费边界、重绘/未来信息风险、可复现基准、实现与验证状态、尚未覆盖差异。商业软件黑盒输出可用作对照，不能在缺少算法定义时宣称数学上完全一致。

“超过”分别验收：

1. **数据正确性**：单位、数值、时间、修订与复权误差可解释。
2. **可追溯性**：每个结论可回到源字段、方法与数据版本。
3. **用户任务效率**：自动更新与可复现研究减少重复导出/操作；同任务计时实测。
4. **决策价值**：相对明确基准在留出样本的净效用与风险；没有改善也保存结论。
5. **功能覆盖**：按 F01–F17 的可用细项对照；数据受限功能标记条件未满足，保留在总范围中。

## 5. 数据战略与自动取数

优先顺序：用户已能合法使用的官方本地接口 → 官方公开服务 → 原始本地行情文件 → 手工导出基准；开源第三方适配器作有边界的补充。开源许可、免费额度、行情使用权分别核验。

同花顺与通达信的接口候选、费用/账号、频率与历史覆盖由 [002](research/002-data-access.md) 决定。接口存在不等于已可用；历史分钟、实时分钟、分笔快照、逐笔、盘口分别评级。任何自动取数适配器都必须与实际软件导出逐字段对账后晋级。

不在源失效时悄悄切换供应商。不自动填平缺口，不将盘后接口显示为实时，不用 OHLCV 生成真实买卖方向。优先保存未复权值；不同复权锚点/交易类型覆盖/时区的数据分开版本化。

## 6. 架构与技术选择

详细模块与数据契约见 [ARCHITECTURE](ARCHITECTURE.md)。草案选择本地优先的模块化单体：Python 研究内核和本机服务；React + TypeScript 工作台；DuckDB 目录与查询、不可变 Parquet 数据段、原始证据文件；单写入者。成熟 K 线渲染库负责绘图，指标真值和研究计算属于后端。

用户已确认个人 Windows 本机优先、全市场日线加自选股票分钟数据。远程服务、多用户、分布式计算等在实际需要与容量实测触发后再评审。

## 7. 研究先行与编码门禁

每项功能先有研究卡，至少包括：要回答的决策问题；竞品定义；实际阅读的论文/作者博客范围；数据可识别性；公式/时点/参数；失效条件；基准与验收。阅读篇数不能替代证据相关性，摘要不能记成全文。

总体编码启动条件：总方案、架构、数据能力矩阵、首阶段验收已经成文；3 个子 agent 独立反驳；主 agent 逐项回应并修改；未解决 P0 为零；P1 有明确边界和进入该模块前的关闭条件；评审记录引用最终文档版本。已有实验代码不自动获得采纳。

单功能编码启动条件：研究卡与数据前提通过；清楚知道输入、输出和错误行为；复杂度与已有模块一致；已有原始真实样本或先列明数据资格验证工作。新指标未取得有效性证据时只能作为描述/研究功能发布。

## 8. 实施阶段与可交付门槛

| 阶段 | 内容与依赖 | 交付及门槛 |
|---|---|---|
| G0 方案冻结 | 本文、架构、002–004、反方评审 | 争议与决策可审计；无未关闭 P0；实验原型逐项处置 |
| G1 数据资格验证 | 官方/本地接口探测，同花顺与通达信的日/分钟样本，标准契约 | 能力与单位确定；真实文件/API对账；停牌/复权/集合竞价/盘后覆盖可解释；失败源隔离 |
| G2 数据与复盘工作台 | G1 合格源，数据版本、质量报告、图表、因果回放、描述量价 | 源至图表全链路；重采样守恒；缺失可见；前缀及真实软件对账；备份恢复 |
| G3 波段与分钟研究 | G2 + 时点主数据，同槽量能、VWAP/结构/事件、扫描 | 每个方法具备研究卡和独立验证；形态确认延迟记录；跨周期截止一致 |
| G4 决策证据与策略 | G3 + 历史交易制度/成本/证券池 | 冻结协议；有效留出样本；净成本后比较；不可成交场景；多重试验与失败记录 |
| G5 日内与高阶量价 | G2/G4 + 逐笔/报价/盘口来源 | 对齐与方向误差有界；缺少字段时功能不可启用；实际回放可对照 |
| G6 中长期与组合 | G4 + 时点基本面/成分/持仓 | 历史可得性；退市与公司行动；风险、成本、再平衡及归因验收 |
| G7 全面对标与可用性 | 全部能力族的功能清单 | 对照覆盖、性能、恢复能力、真实用户任务、证据强度逐项审计 |

各阶段按可运行的完整链路推进，允许 G3/G6 的独立研究提前进行；实现仍遵守前置数据门槛。G2 完成只说明基础工作台成立。

## 9. 规模、费用与性能预算

以下均为设计目标和容量估算，未实测。用户已确认：个人 Windows 本机、全市场日线、自选池分钟。软件依赖优先开源，数据费按 0 元基线选型；不把免费接口当作永久供应承诺，付费源只列选项。

用 6,000 只股票、每年 250 个交易日、每天 240 根常规 1 分钟柱作为**容量估算变量**：日线约 150 万行/年，分钟约 3.6 亿行/年。若单行有效负载 128–256 字节，分钟原始未压缩列负载约 46–92 GB/年，尚不含原始响应、索引、复本和修订；实际交易时段与证券数按主数据决定。50 只股票五年的相同分钟估算为 1,500 万行。存储压缩率和真实字节量必须实测，不能从此推断采购容量。

G1/G2 在记录了 CPU、内存、磁盘和样本的环境测试：单证券 20,000 柱的本地查询 p95 ≤ 500 ms；首次可交互图表 ≤ 2 s；全量导入吞吐、峰值内存、源限速和失败恢复单独记录。先测量再定批量 SLA，不对互联网源承诺延迟。未达标时先定位 I/O/算法/载荷，不直接引入分布式架构。

## 10. 风险与止损条件

| 风险 | 触发条件 | 行动 |
|---|---|---|
| 免费源缺少所需信息 | 无历史 1 分钟/逐笔/盘口或许可不明 | 保留对应需求，停止该源集成；使用明确覆盖的其他源或列为待数据条件 |
| 口径冲突 | 股手倍率、金额量纲、交易类型或复权无法解释 | 隔离数据；禁止进入依赖该口径的分析 |
| 漂亮但无效的指标 | 样本外不能超过基准/结果对参数脆弱 | 降级为描述工具或淘汰；记录全部尝试 |
| 非因果处理 | 居中滤波、未来枢轴、事后修订、当前成分参与历史选择 | 修订方法与时点模型；重新跑受影响实验 |
| 范围失控 | 只增加指标数量、模块重复、无对应用户任务 | 回到 F01–F17 与验收；拆去重复职责 |
| 工程过重 | 无容量证据就引入集群、消息平台、多数据库或插件框架 | 回到单机可运行链路；新增依赖必须有测量依据 |

## 11. 当前事实与未完成项

项目刚建立，已做第一轮调研和小规模实验。现有 `src/`、`tests/`、`web/package*` 在本方案之前创建；用户新指令后停止业务编码。26 项实验测试通过不代表总体方案、真实软件全面兼容或收益有效性验收。

已找到公开仓库中的通达信原生日线与带原始标题/页脚的分钟导出；同花顺真实客户端文件/API对账尚未完成；公开样本也存在量价口径冲突，需保留负面证据。完整样本资格、总方案评审、正式架构实现和 GitHub 发布仍待推进。
